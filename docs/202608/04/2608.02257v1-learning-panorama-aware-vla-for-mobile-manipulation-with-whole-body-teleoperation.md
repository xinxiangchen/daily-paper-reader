## 摘要
移动操作是具身智能的关键能力，使机器人能够在开放世界环境中完成复杂的多阶段任务。然而，移动操作对视觉-语言-动作（VLA）策略提出了两个关键挑战：在数据层面，高效采集高质量的全身演示需要移动基座和机械臂的协调控制；在模型层面，现有的VLA模型主要依赖局部相机观测，其有限的视野阻碍了全局空间理解。为了解决这些挑战，我们开发了一套全身遥操作系统和一个全景感知的VLA策略。该系统通过单一VR接口实现对轮式双臂机器人的协调控制，并支持采集包含5.5小时多模态演示的真实世界移动操作数据集。在此数据集基础上，我们提出了PanoVLA，一种用于移动双臂操作的全景感知视觉-语言-动作策略。基于混合Transformer架构，PanoVLA通过专门的全景编码和融合模块引入全局空间上下文，使全景观测能够与语言指令和机器人状态有效整合以生成动作。在四个真实世界移动操作任务上的评估表明，PanoVLA实现了91.3%的平均阶段完成率和73.4%的端到端成功率，显著优于局部视角基线。这些结果表明，融入全景空间上下文能够提升移动机器人的空间理解和闭环操作性能。

## Abstract
Mobile manipulation is a key capability for embodied intelligence, enabling robots to accomplish complex multi-stage tasks in open-world environments. However, mobile manipulation poses two key challenges for vision-language-action (VLA) policies: At the data level, the efficient collection of high-quality whole-body demonstrations demands the coordinated control of both the mobile base and the robotic arms; at the model level, existing VLA models predominantly rely on local camera observations, whose limited field of view hinders global spatial understanding. To address these challenges, we develop a whole-body teleoperation system and a panoramic-aware VLA policy. The system enables coordinated control of a wheeled bimanual robot through a single VR interface and supports the acquisition of a real-world mobile manipulation dataset comprising 5.5 hours of multimodal demonstrations. Building upon this dataset, we propose PanoVLA, a panorama-aware vision-language-action policy for mobile bimanual manipulation. Built upon a Mixture-of-Transformers architecture, PanoVLA introduces global spatial context through dedicated panorama encoding and fusion modules, enabling effective integration of panoramic observations with language instructions and robot states for action generation. Evaluation on four real-world mobile manipulation tasks demonstrates that PanoVLA achieves an average stage completion rate of 91.3\% and an end-to-end success rate of 73.4\%, substantially outperforming local-view baselines. These results demonstrate that incorporating panoramic spatial context improves spatial understanding and closed-loop manipulation performance in mobile robots.

### 2. 方法论

**核心思想：**
通过**通用运动重定向（GMR）**实现高效全身遥操作数据采集，并在模型中引入**机器人中心的360°全景表示**，利用全景专精编码器与专家模块将全局空间上下文注入动作生成过程，弥补局部视图的感知盲区。

**技术细节与关键组件：**

- **全身遥操作系统**：
  - 操作员仅需佩戴VR头显 + 双手柄 + 3个体感追踪器（腰部、双踝），实现稀疏运动捕捉。
  - 实时重建SMPL人体模型，提取骨盆位姿、双手位姿、下肢线索。
  - 通过GMR优化将人体运动映射到轮式双手机器人（RANGER MINI底盘 + 双6自由度PIPER机械臂 + 平行夹爪）。

  - 机器人配置参数化：`q = (x_b, y_b, θ_b, q_L, q_R)`，优化目标为加权最小化：
    `q* = argmin_q λ_pos·L_pos + λ_rot·L_rot + λ_base·L_base + λ_reg·L_reg`
    - `L_pos`：对齐手部与夹爪位置；`L_rot`：对齐手部与末端朝向；`L_base`：将底盘平面运动与操作员骨盆位移和朝向耦合；`L_reg`：防止关节超限。
  - 移动底盘采用**成本驱动的模式切换策略**，在自旋、阿克曼转向和斜向平移三种模式间动态选择，以最优匹配重定向的3-DoF速度指令。

- **PanoVLA模型架构**：
  - 基于 **Mixture-of-Transformers (MoT)** 的双专家π0.5骨干扩展为三个专家块：**VLM专家、全景专家、动作专家**。
  - 采用**块级因果注意力掩码**：块内双向注意力，跨块只允许后续块关注先验块。
  - 融合机制采用 **Transformer键值（KV）缓存**：VLM专家生成VLM缓存 `C_vlm`，全景专家处理全景token并结合VLM缓存产出全景缓存 `C_pano`，动作专家基于拼接缓存 `C_t = [C_vlm; C_pano]` 生成动作。
  - **全景编码器**：支持双鱼眼 → 球面重投影 → ERP图像；使用全景基础模型 **MTPano**提取语义+深度双分支特征并拼接；轻量token适配器（自适应平均池化 + MLP）映射到专家隐藏维度。
  - **训练目标**：采用**条件流匹配**，学习从噪声动作到真实动作的velocity field，损失函数为：
    `L = E[||v_θ(x_τ, τ | C_t) − u(x_τ | a)||²]`

- **数据集**：采集800条成功轨迹（每任务200条）、约5.5小时、约50万同步帧，涵盖前视RGB、双腕部RGB、360°全景、本体感觉状态（17维）和全身动作（17维：14维手臂+夹爪+3维底盘速度）。

### 3. 实验设计

**任务基准（Benchmark）：** 4个真实世界移动双手机器人任务，空间布局多样、均需跨视角空间推理：
- **Move Pen**：将笔放入笔筒（目标在前/左/右）。
- **Move Block**：将积木转移到前方区域（左/右/双侧）。
- **Open Curtain**：打开双侧窗帘（左/右）。
- **Wipe Table**：沿长桌擦拭污渍并将毛巾归位（多阶段大空间任务）。

**评估指标：**
- **成功率（SR）**：二进制端到端任务是否整体完成。
- **阶段完成率（SCR）**：各适用阶段完成比例的平均值。

**对比基线（均为π0.5变体，控制变量）：**
1. **π0.5**：仅局部视图（SigLIP编码）。
2. **π0.5 w/ Pano**：原始ERP全景图直接作为额外SigLIP输入，无专门全景分支。
3. **π0.5 w/ Stacked Pano**：全景重投影为3个视角（光轴间隔120°）拼接，作为额外图像输入。
4. **PanoVLA**：MTPano全景编码 + 全景专家融合。

**评测规模：** 每方法、每任务15次闭环真实机器人试验（无人工干预），严禁中途人工重置失败阶段，共约240次闭环试验（4方法×4任务×15次）。

### 6. 主要结论与发现

- PanoVLA在四项任务上均取得最高性能：平均**SCR 91.3%**，平均**SR 73.4%**；而纯局部视图基线π0.5仅为SCR 58.6%、SR 30.0%。
- **全景信息有效，但表示方式至关重要**：直接输入ERP全景图（w/ Pano，SR 56.7%）和透视重投影拼接（w/ Stacked Pano，SR 38.3%）均无法完全释放全景的潜力，专精全景编码器 + 专家融合机制才是关键。
- 全景感知带来的增益在**多阶段、长时程任务**（Open Curtain、Wipe Table）上尤为明显；在较简单的Move Pen任务上，PanoVLA与直接输入全景的基线持平，说明其优势来自任务状态跟踪与全局空间一致性维护。
- 全景编码器方面，MTPano（专用全景模型）显著优于SigLIP（基于透视图像预训练），验证了**全景几何建模的必要性**，直接使用透视视觉编码器处理ERP图像存在严重域偏移。
- 全景专家规模存在"甜点"：100M参数最优，过小（50M）容量不足，过大（200M/300M）在有限数据下反而带来轻微退化。

### 7. 优点

- **系统性方案设计**：从遥操作系统、数据集到模型架构形成完整闭环，三个贡献互为支撑，不是孤立的方法改进。
- **遥操作界面创新性强**：仅凭稀疏追踪和GMR公式将移动底盘建模为虚拟浮动基座，实现"移动+操作"的单界面协同控制，避免分离式操纵杆控制的非自然动作，有效保证了数据质量。
- **数据集资源稀缺且有价值**：提供带有时间同步全景、局部视图、本体状态和全身动作的真实移动双手机器人数据集，为后续社区研究提供数据基础。
- **模型设计思路清晰**：
  - 利用KV缓存作为模块间融合接口，计算开销低、架构简洁；
  - 全景专家与VLM上下文通过联合自注意力实现任务条件下的空间编码，能动态聚焦任务相关区域；
  - 引入深度+语义双分支全景特征，兼顾几何和理解需求。
- **基线对比严谨**：三个基线均围绕"全景如何接入"这一变量展开，控制良好，结论有针对性，同时指出直接堆叠视角和直接输入ERP图像各自的缺陷。
- **任务设计合理**：任务空间布局和复杂度具备梯度（单目标、双目标、多阶段长程），便于刻画不同维度下方法优势的边界。

### 8. 不足与局限

- **实验规模有限**：
  - 每任务15次试次统计功效较弱，缺乏置信区间和显著性检验；
  - 消融仅在一个较简单任务（Move Pen）上执行，结论外推受限；
  - 未与近年其他移动操作VLA方法（如MoManipVLA、AC-DiT、SG-VLA等）进行横向对比，影响相对优势的判断力。
- **训练-部署范式偏"窄"**：
  - 策略按任务独立微调，没有验证单模型跨任务多技能的泛化能力；
  - 无跨物体/跨场景泛化测试，仅覆盖训练中出现的物体和布局，距离"开放世界"目标仍有距离。
- **全景优势的任务依赖性强**：Wipe Table任务的SR相对提升并非特别大（46.7% vs 20.0%），且复杂任务仍然面临较大的失败率；在简单任务上优势不显著，说明方法的价值场景有边界。
- **硬件门槛较高**：需要顶部360°全景相机、VR全身追踪套件、多块A100训练、RTX 4090推理，对算力和设备要求较高。
- **数据规模偏小且单一平台**：数据集仅来自单一机器人（RANGER MINI + PIPER）和单一实验室环境，领域漂移风险大；5.5小时对比其他大规模机器人基础模型数据量有量级差距。
- **全景编码器冻结**：预训练MTPano冻结，未与策略进行端到端联合优化，可能限制了全景特征与任务动作之间的自适应对齐能力。
- **未讨论失败模式细节**：对失败案例缺乏定性分析（如全景专家失效的具体场景），影响对方法局限的深入理解。
