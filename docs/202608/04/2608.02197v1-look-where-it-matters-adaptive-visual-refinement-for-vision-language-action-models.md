## 摘要
VLA模型的视觉表示在空间精确的机器人操作中仍不可靠。我们发现VLA中的视觉编码器也表现出先前在通用视觉Transformer中记录到的注意力伪影，并进一步表明，在具身策略中，这些伪影与后训练期间获得的空间感知能力密切相关。当编码器学习任务相关信息（如对象位置、深度顺序和局部几何）时，有限的全局令牌容量导致部分信息溢出到低信息补丁令牌中。我们引入了AtVLA，这是一个将可学习注册令牌插入视觉编码器的框架。仅使用具身数据和原始动作目标进行端到端训练，这些注册令牌成为具身空间信息的专用载体，而剩余的补丁令牌恢复干净且空间上忠实的注意力分布，这对于精确目标定位和细粒度接触至关重要。干净的注意力恢复了可靠的定位，但无法恢复低分辨率观察中丢失的几何细节。因此，AtVLA将注意力校正与不确定性门控的局部细化相结合。动作专家对多个动作块进行采样，并根据它们之间的不一致性估计不确定性；仅对于不确定的预测，动作条件下的注意力展开识别出任务相关区域，该区域被裁剪、以高分辨率重新编码，并附加到缓存的前缀中以生成精细动作。在LIBERO、SimplerEnv和一个具有挑战性的单视图真实世界基准测试中，AtVLA将平均LIBERO成功率从94.2%提高到98.4%，真实世界成功率从46.5%提高到69.0%。在代表性的部署设置下，裁剪在约30%的重新规划步骤中被触发，总计算量仅为基础模型的1.4-1.6倍。

## Abstract
Visual representations of VLA models remain unreliable for spatially precise robotic manipulation. We uncover that vision encoders in VLAs also exhibit attention artifacts previously documented in generic Vision Transformers, and further show that, in embodied policies, these artifacts are closely associated with spatial perception capabilities acquired during post-training. As the encoder learns task-relevant information such as object location, depth ordering, and local geometry, limited global-token capacity causes part of this information to spill into low-information patch tokens. We introduce AtVLA, a framework that inserts learnable register tokens into the visual encoder. Trained end-to-end using only embodied data and the original action objective, these registers emerge as dedicated carriers of embodied spatial information, while the remaining patch tokens recover clean and spatially faithful attention distributions crucial for precise target localization and fine-grained contact. Clean attention restores reliable localization, but cannot recover geometric details lost in low-resolution observations. AtVLA therefore couples attention rectification with uncertainty-gated local refinement. The action expert samples multiple action chunks and estimates uncertainty from their disagreement; only for uncertain predictions, action-conditioned attention rollout identifies the task-relevant region, which is cropped, re-encoded at high resolution, and appended to the cached prefix for refined action generation. Across LIBERO, SimplerEnv, and a challenging single-view real-world benchmark, AtVLA improves the average LIBERO success rate from 94.2% to 98.4% and real-world success from 46.5% to 69.0%. The cropping is triggered on approximately 30% of replanning steps, resulting in only 1.4-1.6x the total computation of the base model under the representative deployment setting.

## 2. 论文提出的方法论：AtVLA

### 2.1 核心思想

AtVLA 由两个互补机制组成：

1. **注册增强视觉编码（Register-Enhanced Visual Prefix）**：在视觉编码器中插入可学习注册 token，作为全局“信息仓库”，使 patch token 恢复干净的空间注意力。
2. **不确定性门控局部细化（Uncertainty-Gated Local Refinement）**：动作专家采样多个动作块估计不确定性；仅在预测不确定时，通过注意力展开定位任务相关区域，以高分辨率裁剪重编码后附加到前缀中，生成精细化动作。

### 2.2 关键技术细节

**(1) 注册 token 插入：**

- 在 SigLIP 编码器中插入 Nr = 4 个可学习注册嵌入，位于 class token 之后：
  - Xt = [x_cls; r1, ..., rNr; p1, ..., pNb]
- 与原始仅作为内部工作空间的用法不同，AtVLA **保留** Rt 并通过 PaliGemma 视觉投影器输出给下游策略，构成多槽全局上下文。

**(2) 不确定性估计：**

- 基于同一视觉和语言前缀，动作专家从独立高斯初始化生成 K 个动作块。
- 在平移动作维度 D_tr 和即将执行的前 h 个动作上计算跨样本标准差作为不确定性 U_t。
- 仅对近端平移动作计算，以直接反映与空间歧义相关的末端执行器运动分歧。

**(3) 注意力引导裁剪：**

- 当 U_t > τ 时，从动作生成过程中已产生的注意力矩阵中聚合任务条件空间图。
- 通过注意力展开（attention rollout）跨层传播，生成 16×16 显著性图。
- 采用**对比式窗口搜索**：选择内部注意力与周围环带差异最大的区域，避免全图扩散或孤立峰值。
- 裁剪区域重编码至 224×224，并通过 MLP 注入位置编码后附加到缓存前缀。

**(4) 三阶段训练策略：**

| 阶段 | 内容 | 步数 |
|------|------|------|
| Stage 0 | 注册 token 适应（4K 步仅训练注册 token，16K 步解冻视觉编码器最后4层） | 20K |
| Stage 1 | 真值裁剪对齐（冻结视觉编码器，训练裁剪位置编码器和 LoRA） | 10K |
| Stage 2 | 联合精炼（从真值裁剪逐步过渡到模型自身注意力裁剪，裁剪丢弃率最高0.3） | 40K |

最终目标函数：L = L_π0 + λ_cp·L_cp + λ_ag·L_ag（λ_cp=0.1，λ_ag=1.0）

## 6. 论文的主要结论与发现

1. **注意力伪影与具身后训练相关**：VLA 编码器在获取空间操作信息时，由于全局 token 容量限制，信息溢入 patch token，产生注意力伪影。
2. **注册 token 有效修复注意力**：仅使用具身数据和动作目标训练，注册 token 自发成为具身空间信息的专用载体，patch token 恢复干净的空间注意力分布。
3. **注册 token 编码丰富空间信息**：线性探针证实注册 token 在对象定位、深度、表面法线预测上优于 CLS token 和池化 patch 特征。
4. **不确定性门控有效**：仅约 30% 的重新规划步骤需要裁剪细化，说明大多数情况下基础注意力已足够。
5. **裁剪细化对长时任务也有帮助**：额外视觉上下文不仅提升局部精度，还改善长序列多阶段任务的规划一致性。
6. **裁剪质量至关重要**：外部 VLM 生成的裁剪（无具身预训练）效果明显较差，说明具身监督对学习决策相关视觉定位的必要性。
7. **注册 token 数量存在最优值**：过少无法完全吸收伪影，4 个即达到性能饱和。

## 7. 优点

**方法设计亮点：**

1. **问题洞察深刻**：首次将 ViT 中的注意力伪影问题与 VLA 的具身后训练建立联系，解释空间信息泄漏机制。
2. **方案轻量优雅**：仅添加 4 个注册 token（4608 参数）即显著改善视觉表征，未增加额外感知设备或 3D 建模。
3. **自适应性**：不确定性门控使高分辨率细化只在需要时触发，计算开销可控（1.4-1.6×）。

5. **训练策略严谨**：三阶段课程学习逐步对齐新组件，从真值裁剪过渡到模型自身生成裁剪，消除训练-推理分布偏移。
6. **多个视角的验证**：线性探针、注意力可视化、消融实验、真实世界部署等多维度验证方法有效性。

## 8. 不足与局限

**实验覆盖方面：**

1. **真实世界基准自建，缺乏标准性**：无法与外部已有真实机器人结果直接公平对比。
2. **SimplerEnv 覆盖不完整**：跳过 WidowX 套件（虽有理由，但减少了对另一具身平台的验证）。
3. **单一基座模型**：所有实验基于 π0 初始化，未验证 AtVLA 机制在 OpenVLA、RT-2 等其他 VLA 架构上的可迁移性。

**技术局限：**

4. **触发率依赖经验阈值**：约 30% 的触发率是人为设定的预算，不同任务可能最优触发率不同。
5. **单视角限制**：真实世界采用单第三人称相机，虽然这也是基准的挑战性所在，但多视角/腕部相机可能进一步改善效果。
6. **裁剪窗口形状固定**：仅搜索正方形窗口，对细长物体或非方形交互区域可能不是最优。
7. **低分辨率的天花板**：裁剪虽然恢复局部细节，但本质上是改善现有低分辨率观测的利用方式，不产生新的物理信息。

**方法论局限：**

8. **两阶段误差累积**：定位错误和裁剪质量直接影响细化效果；注册 token 吸收不完全时可能引入干扰（如 1-2 个注册 token 反而造成性能下降）。
9. **对注意力质量的依赖**：当注意力本身不可靠时，引导裁剪的信号同样不可靠（作者通过 L_ag 辅助损失缓解，但问题仍存在）。
