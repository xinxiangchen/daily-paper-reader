## 摘要
视觉-语言-动作（VLA）模型在机器人操作中表现出色，但当规范指令被简单改写时，其性能会急剧下降。尽管这种脆弱性通常通过昂贵的数据扩展来解决，但我们的探测揭示，根本原因在于架构而非缺乏语义理解。具体而言，我们证明当前VLA模型在内部成功保留了正确的任务身份。失败实际上源于动态视觉观察和文本的联合编码，这引入了系统性的特征偏移。由于下游动作策略对这些变化高度敏感，它无法将保留的语义转化为正确的控制命令。为了解决这一结构性瓶颈，我们提出了接地语义重绑定（GSR），一种优雅的干预措施，通过将独立提取的任务语义与原生视觉特征显式融合，从零开始训练一个完全重新初始化的动作专家，从而绕过不稳定的联合路由。这种针对性的干预仅使用规范演示即可显著恢复释义不变性。在LIBERO-Para基准上，GSR将成功率提高了高达44.6%。它使轻量级模型能够与大规模扩展的基线相媲美，并将最先进模型的PRIDE分数推至新的纪录70.4，在指令生成能力上优于最近引入的大规模预训练模型Xiaomi-Robotics-0。基于这些见解，我们还引入了ParaVLA，一个原生解耦的0.33B参数模型，对指令改写表现出近乎完美的鲁棒性。最终，我们的工作证明，通过优雅的结构设计可以实现鲁棒的语义接地，从而绕过低效的暴力数据扩展范式。

## Abstract
Vision-Language-Action (VLA) models excel in robotic manipulation but suffer catastrophic performance drops when canonical instructions are simply paraphrased. Although this brittleness is typically addressed through costly data scaling, our probing reveals that the root cause is architectural rather than a lack of semantic understanding. Specifically, we demonstrate that current VLAs successfully retain the correct task identity internally. The failure actually stems from the joint encoding of dynamic visual observations and text, which introduces systematic feature shifts. Because the downstream action policy is highly vulnerable to these variations, it fails to translate the preserved semantics into correct control commands. To resolve this structural bottleneck, we propose Grounded Semantic Re-binding (GSR), an elegant intervention that bypasses unstable joint routing by explicitly fusing independently extracted task semantics with native visual features to train a completely re-initialized action expert from scratch. This targeted intervention dramatically restores paraphrastic invariance using only canonical demonstrations. On the LIBERO-Para benchmark, GSR improves success rates by up to 44.6 percent. It enables lightweight models to rival massively scaled baselines and pushes state-of-the-art models to a new record PRIDE score of 70.4, outperforming the recently introduced large-scale pretrained model Xiaomi-Robotics-0 in instruction generation capabilities. Building on these insights, we also introduce ParaVLA, a natively decoupled 0.33B-parameter model exhibiting near-perfect robustness to instruction rewording. Ultimately, our work proves that robust semantic grounding can be achieved through elegant structural design, bypassing the inefficient brute-force data scaling paradigm.

## 1. 论文的核心问题与整体含义

视觉-语言-动作（VLA）模型将视觉感知与语言指令映射为机器人动作，在多种操作任务上表现优异。然而，这类模型高度依赖标准基准中固定的规范指令模板，一旦指令被简单改写（如"打开柜子中间抽屉"变为"滑动打开柜子的中央抽屉"），其成功率会出现灾难性下降（最高达 67.53%）。这暴露了 VLA 模型在处理语义等价的多样化语言表达时的严重脆弱性。该问题通常被视为数据覆盖不足，但本文通过受控探针实验证明：**根因是架构性缺陷而非语义理解缺失**。模型内部实际上保留了正确的任务身份，问题出在联合编码动态视觉与文本所引入的系统性特征偏移，导致下游动作策略无法将保留的语义转化为正确的控制指令。这一发现将"指令泛化"问题从数据规模视角重新定义为结构设计问题，提出通过优雅的架构干预而非暴力数据扩展来修复语义通路。

## 2. 论文提出的方法论

### 2.1 核心思想
GSR 提取任务语义（与当前图像独立）、通过模型的原生多模态计算将它们接地，并重新学习其到机器人动作的映射，从而绕过不稳定的联合路由。

### 2.2 关键机制

- **稳定的语义提取源**：使用冻结的 T5-large 编码真实任务指令，T5 不接收图像或机器人状态输入，保证提取的语义表示完全不受动态视觉干扰，且对等价措辞变化具有稳定性。
- **架构感知的接地策略**：GSR 不是固定注入点，而是识别不同 VLA 架构中执行多模态融合的特定阶段，将投影后的 T5 语义注入该原生集成点，使其与视觉、状态深度交互。具体地：
  - **VLA-Adapter**：将 T5 输出的 token 特征投影到 Bridge-Attention 动作头的宽度，作为每块的侧车 K/V 源，与 Qwen 的视觉/状态条件保持独立可寻址；
  - **SmolVLA**：将 T5 特征投影到 960 维，通过 8 头接地注意力与 SmolVLM 的原生语言槽交互，随后继续经过原生多模态处理；
  - **π0.5**：因 PaliGemma 原生路线已经可靠泛化，保留真实指令作为主控制源，T5 作为补充语义信号在检测到的任务 token 位置注入。
- **重新初始化动作专家**：丢弃预训练的动作映射，从头训练全新的动作策略，使其学习 T5 条件、视觉特征与机器人状态如何共同决定动作，而非沿用对原语言输入过拟合的映射。
- **原生语言输入的中和策略**：对 VLA-Adapter 和 SmolVLA（原生语言路径脆弱）用固定中性语句"perform the task"替换真实指令，强制依赖 T5 语义；对 π0.5（原生路径已可靠）则保留真实指令以提供互补信息。

### 2.3 诊断方法

- **语义保持得分 R**：通过对比释义指令与错误任务指令到规范指令输出的距离，量化模型内部保留任务语义的程度，R = (Δwrong − Δpara)/(Δwrong + Δpara)。
- **Retrieval@1**：判断释义指令产生的动作在所有任务候选规范动作中是否与真实任务的规范动作最接近。
- **因果替换干预**：用规范指令运行的 Qwen 特征替换释义指令运行中进入 Bridge-Attention 的特征，使配对成功率从 60% 升至 96%，验证正确任务信息确实存活于语言编码中。
- **视觉/措辞消融**：替换辅助 Qwen 分支中的动态图像为固定图像（Para 成功率 +14.76 点）；用 5 折任务无关交叉验证估计 32 个措辞方向并移除（动作差距从 0.4361 降至 0.2282）。
- **层干预量化**：系统逐层替换释义运行的特征为规范运行的特征，计算动作恢复率，发现 VLA-Adapter 有严格单点瓶颈（最后一层恢复 96.8%），而 SmolVLA、π0.5 语义分布式纠缠。

### 2.4 原生解耦模型 ParaVLA
进一步验证语义稳定性可从架构上实现：语言由冻结 T5 编码、视觉由 DINOv2 编码，两者仅在最终动作专家中融合。视觉-语言融合门全程禁用，避免联合编码对语言表示的污染。

## 6. 论文的主要结论与发现

1. **VLA 释义失败根因是架构缺陷**：三种 VLA 模型在被改写指令导致执行失败时，内部仍保留可检测的任务身份（Retrieval@1 为 0.516-0.941，R 为 0.303-0.604）；因果替换实验证实正确信息存活但被下游动作策略误处理。
2. **联合视觉-语言编码引入系统性特征偏移**：动态图像输入加剧特征变异（替换为固定图像 +14.76 点）；措辞变化产生可分离的特征方向（移除后动作差距减半），下游动作策略对这些变化高度敏感。
3. **GSR 仅用规范演示即可恢复释义不变性**：VLA-Adapter Full Para 成功率 46.82%→70.94%（+24.12 点）；SmolVLA 4.47%→49.12%（+44.65 点）；π0.5 73.60%→75.59%，PRIDE 达到新纪录 70.4。
4. **架构感知的原则至关重要**：SmolVLA 若采用 VLA-Adapter 式旁路注入会失败（释义仅 13.49%），因为需要视觉接地；VLA-Adapter 若不中和脆弱原生指令，T5 语义会被 Qwen 路径"劫持"（冲突测试显示错误原生指令使成功率从 47.31% 骤降至 5.11%）。
5. **原生解耦是极端鲁棒的结构路线**：ParaVLA（0.33B）实现 92.0%/91.0% 的规范/释义成功率，差距仅 1 点，显著优于同规模模型如 VLA-Adapter（94/56 差距 38）和 SmolVLA（92/7 差距 85）。
6. **VLM 会污染语言表示**：在 ParaVLA 架构中，将 T5 替换为 SmolVLM 后释义成功率从 41.0% 崩溃，证明需要完全解耦而非仅换解码器。

## 7. 优点

- **问题定位精准**：通过多种互证手段（探针得分、因果替换、层干预、字空间消融）精准将失败定位在"语义→动作翻译"环节而非语义理解，挑战了主流的"数据不足"假设。
- **干预优雅高效**：仅用规范演示训练即实现大幅提升，无需任何释义数据，直接反驳了暴力数据扩展的范式；GSR 的设计本质上是"从架构上修复"，而非从数据上补充。
- **架构感知的通用指导原则**：不是固定补丁，而是给出识别多模态融合点、测试原生语言可靠性、据此决定中和或保留的清晰方法论，对三种异构架构均有效。
- **实验严谨客观**：与大型预训练模型 Xiaomi-Robotics-0 的对比公平透明；如实报告了 π0.5 规范性能的临时下降及其恢复方案；提供了完整的超参、配对控制、统计检验和代码开源。
- **双路验证**：仿真实验与真实机器人初步验证相结合，且真实场景设计为共享视觉布局，有效考验语言区分能力。

## 8. 不足与局限

- **可扩展性瓶颈**：解耦架构（ParaVLA）在增大视觉基础模型（如升级 DINO 变体）时未呈现 VLM 式扩展能力，限制了该范式的规模发展前景；作者承认这是核心挑战。
- **经验性判断成分偏高**："检测原生语言路径可靠性并决定中和或保留"的操作依赖于评估者的基准测试设置，若在部署环境中无配对改写数据，难以精确判断原生路径的可靠程度。
- **真实机器人验证规模有限**：6 个任务中 GSR 仅在 3 个任务上取得正成功率（50%/40%），任务 3、5、6 为 0%，每次条件仅 5 次试验，统计功效不足，部署可靠性结论需谨慎外推。
- **对大模型规范能力的代价未完全解决**：π0.5 GSR 在匹配训练时长下规范成功率从 97.6% 报告值降至 91.0%，虽可通过延长训练恢复，但增大计算开销；对大型动作专家更高效的初始化策略仍是待解问题。
- **分析工具的局限性**：层干预只能证明特征替换与动作恢复的相关性，无法完全排除其他隐藏变量；聚合指标（Retrieval@1、R）不能保证每一个失败 episode 都保留语义。
- **评估范围相对狭窄**：主要基于 LIBERO-Goal/Para 的桌面操作设定，未覆盖移动操作、多臂协同、灵巧手或开放式物体类别等更复杂场景。
