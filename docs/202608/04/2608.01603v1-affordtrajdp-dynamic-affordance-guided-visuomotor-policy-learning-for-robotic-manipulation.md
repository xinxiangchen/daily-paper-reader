## 摘要
感知引导的模仿学习通过将视觉感知压缩为任务特定的几何约束（例如固定的接触点），在机器人操作任务中展现出了显著的性能。然而，常用的静态感知在精度关键任务或物体位置扰动下可能变得不一致，导致接触后轨迹漂移。为解决这一问题，我们提出了AffordTrajDP，一种通过以物体为中心的时序传播构建感知轨迹的动态框架，以指导渐进式操作过程。具体而言，给定RGB-D观测，我们的核心见解是：检索到的锚定感知（捕捉末端执行器与目标物体之间的期望接触点）可以通过感知传播，利用物体的SE(3)姿态作为自然传播媒介，向前传播生成一条感知轨迹，在整个执行过程中提供时序一致、状态感知的指导。AffordTrajDP在ManiSkill3上达到了70.0%的平均成功率，比强基线高出最多17.8%。在Galaxea A1和UR7e机械臂上的真实世界实验，涵盖StackCube、PickCup、AdapterInsertion、Ring-on-Peg、Put-in-Bowl和USB Insertion，进一步验证了在物体位置变化和外观变化下的鲁棒性，其中在Galaxea A1上评估了已见和未见物体实例，消融实验确认了每个提出组件的贡献。

## Abstract
Affordance-guided imitation learning has shown impressive performance in robotic manipulation tasks by compressing visual perception into task-specific geometric constraints (e.g., fixed contact points). However, the commonly used static affordances can become inconsistent in precision-critical tasks or under object location perturbations, leading to post-contact trajectory drift. To address this issue, we propose AffordTrajDP, a dynamic framework that constructs affordance trajectories via object-centric temporal propagation to guide the progressive manipulation process. Specifically, given an RGB-D observation, our core insight is that a retrieved anchor affordance, which captures the desired contact point between the end-effector and the target object, can be propagated forward via affordance propagation, using the object's SE(3) pose as a natural propagation medium, to yield an affordance trajectory that provides temporally consistent, state-aware guidance throughout execution. AffordTrajDP achieves 70.0% average success rate on ManiSkill3, outperforming strong baselines by up to 17.8%. Real-world experiments on Galaxea A1 and UR7e robotic arms, covering StackCube, PickCup, AdapterInsertion, Ring-on-Peg, Put-in-Bowl, and USB Insertion, further validate robustness under object placement variations and appearance changes, with seen and unseen object instances evaluated on Galaxea A1, and ablations confirm the contribution of each proposed component.

# AffordTrajDP 论文详细总结

## 1. 核心问题与整体含义（研究动机和背景）

- **背景**：基于视觉运动策略的机器人操作模仿学习（如 Diffusion Policy）依赖密集视觉观测，容易受物体外观、背景布局等环境扰动影响，导致在新场景或未见实例上性能下降。为此，近年工作引入物体中心表示（如 SE(3) 位姿、3D 点流）作为先验，以提升泛化性。
- **存在的缺陷**：现有 affordance 引导方法（如 AffordDP）将接触点等先验视为**静态**——一旦通过刚性变换从参考演示迁移到目标场景，整个执行过程中不再更新。在精度关键任务（如适配器插入）中，物体接触后位姿发生变化，静态先验会逐渐与物体实际状态失配，造成轨迹漂移、振荡或失败。
- **核心诊断**：作者指出，已有方法只捕获“在物体何处接触”（语义接触点）或“接触如何随位姿演化”（位姿轨迹）两者之一，缺少一个**同时保留两者且随时间更新**的单一条件信号。这正是精度关键任务失败的根源。
- **本文目标**：提出 **AffordTrajDP**，通过物体 SE(3) 位姿作为传播媒介，将检索到的锚定 affordance 前向传播为**动态 affordance 轨迹**，为策略提供时序一致、状态感知的渐进式操作指导。

## 2. 方法论：核心思想、关键技术细节

### 2.1 总体框架

- 输入：RGB-D 观测。
- 三个模块：
  1. **锚定 affordance 生成**：从对象记忆库中检索语义相似的源实例，并通过密集视觉对应转移接触点到目标物体。
  2. **未来位姿预测**：利用轨迹扩散模型预测目标物体未来 SE(3) 位姿轨迹。
  3. **动态 affordance 传播**：将锚定接触点沿预测位姿轨迹进行刚性变换，生成时变 affordance 轨迹，作为扩散策略的条件信号。

### 2.2 锚定 Affordance 生成

- 3D affordance 表示为 Φ = (c, τ)，其中 c ∈ R³ 是静态接触点，τ ∈ R^{3×H} 是对应动态轨迹。
- 通过检索而非回归获得接触点：使用 Grounded-SAM 裁剪物体区域，CLIP 提取外观特征，在记忆库 M = {(ℓ, c, z, T)} 中按余弦相似度检索同一任务标签下的最近邻源实例。
- 通过源/目标裁剪图像间的密集视觉对应，将源接触点转移为目标接触点 c_tgt ∈ R³，作为锚定 affordance。

### 2.3 动态 Affordance 传播

- **相对位姿预测**：为消除绝对场景布局影响，预测源物体在目标物体坐标系下的位姿 T_src_tgt(t) = (T_tgt_W(t))⁻¹ T_src_W(t)，实现跨实例泛化。
- **轨迹扩散模型**：使用 DDIM 对向量化位姿 x(t) = [t(t); q(t)] ∈ R⁷（平移 + 四元数）建模，条件为位姿历史 h_t，训练目标为噪声预测 MSE。
- **传播公式**：由模型采样得到未来位姿序列 {T_{t+k}}，将锚定接触点乘以齐次变换得到动态轨迹：p_{t+k} = T_{t+k} · c̃，从而获得 Φ_tgt = (c_tgt, τ_tgt)。

### 2.4 动作生成

- 静态接触点由 MLP 编码，动态轨迹由 Transformer 编码器（含 [CLS] token）编码，与观测特征结合形成条件特征 f_t。
- 动作策略同样采用 DDIM 扩散模型，从高斯噪声迭代去噪得到动作序列，使用标准噪声预测损失训练。

- DP3：无任何额外条件。

- DP3+Trajectory：仅使用预测位姿轨迹（无语义锚定）。

## 6. 主要结论与发现

1. **动态 affordance 显著优于静态方法**：ManiSkill3 上平均成功率 70.0%，比 DP3（52.2%）、AffordDP（57.8%）、SPOT（62.1%）分别提升 17.8、12.2、7.9 个百分点。
2. **精度关键任务提升最大**：PegInsertion（46.0% vs. 23.3%）和 PlugCharger（24.7% vs. 11.3%）等需要持续位姿跟踪的任务改善最显著。
3. **真实世界表现**：Galaxea A1 上平均成功率 66.1%，远超 DP3（35.0%）、+Center（38.9%）、+Contact（47.2%）、+Traj（40.6%）；UR7e 上平均 72.5%，超过 DP3（40.8%）、AffordDP（55.8%）、SPOT（54.2%）。
4. **必要性与充分性**：消融证明，语义接触点检索和位姿轨迹传播**缺一不可**——单独使用接触点提升有限，单独使用轨迹甚至可能伤害性能（StackCube 未见实例从 40% 降至 20%），只有组合才能带来稳定大增益。
5. **动态先验优于静态先验**：在 AdapterInsertion 等接触后容易漂移的任务中，时变 affordance 轨迹提供了状态一致的引导，显著减少后接触失误。
6. **误差非累积（初步证据）**：在 StackCube 上，位姿预测误差随预测步长线性增长但在一段时间内不随 episode 步数累积；FoundationPose 的跟踪误差在接触后升高，可能是主要噪声源（但作者强调这是相关性观察，非对照实验）。
