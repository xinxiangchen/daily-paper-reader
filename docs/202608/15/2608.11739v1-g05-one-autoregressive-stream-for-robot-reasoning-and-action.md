## 摘要
视觉-语言-动作（VLA）模型的现行方案是将预训练的VLM与单独训练的条件流匹配动作专家相结合。这使VLM成为上下文编码器而非决策者。我们提出了G0.5，一个预训练的自回归VLA，其中单个Transformer解码器在单一目标下同时生成推理token和动作token。三个组件使其在基础模型规模下可行：一个可学习的跨具身动作分词器，将异构机器人动作映射到共享词汇表；一个原生思维链流，将任务分解、对象接地和动作提示与动作token交错排列；以及一个视觉记忆模块，通过视觉编码器注入多秒历史信息。由于推理和动作共享同一组权重，预训练VLM的能力得以迁移到物理行为中：模型紧密遵循指令，且提示可直接引导动作粒度、任务范围和分布外场景处理，无需进一步训练。G0.5在大型机器人数据集集合以及VQA样本上预训练，在7个独立领域超越了最先进的模型：在R1lite和R1pro机器人上的真实世界微调（76.7% vs. π₀.₅的53.3%和GR00T-N1.7的24.4%）；2025年BEHAVIOR挑战赛，使用通用策略完成50个长时程家庭移动操作任务（31.4% vs. π₀.₅的26.3%和挑战赛冠军的26.1%）；DROID后训练后零样本迁移到未见环境和物体（82.5%）；语言跟随的抓取与放置基准；LIBERO（98.9%）；RoboTwin 2.0（93.3%）；以及SimplerEnv-Bridge（87.3%）。

## Abstract
The prevailing recipe for Vision-Language-Action (VLA) models couples a pretrained VLM with a separately trained flow-matching action expert. This makes the VLM a context encoder rather than a decision-maker. We introduce G0.5, a pretrained autoregressive VLA in which a single transformer decoder emits reasoning and action tokens under a single objective. Three components make this tractable at foundation-model scale: a learnable cross-embodiment action tokenizer that maps heterogeneous robot actions into a shared vocabulary; a native chain-of-thought stream interleaving task decomposition, object grounding, and action hints with action tokens; and a visual memory module that injects multi-second history through the vision encoder. Because reasoning and action share a single set of weights, the pretrained VLM's capabilities carry over to physical behavior: the model follows instructions closely, and prompts directly steer action granularity, task horizon, and out-of-distribution scene handling without further training. Pretrained on a large collection of robot datasets together with VQA samples, G0.5 surpasses state-of-the-art models across 7 independent regimes: real-world fine-tuning on R1lite and R1pro robots (76.7\% vs.\ 53.3\% for $π_{0.5}$ and 24.4\% for GR00T-N1.7), the 2025 BEHAVIOR Challenge on 50 long-horizon household mobile manipulation tasks using a generalist policy (31.4\% vs.\ 26.3\% for $π_{0.5}$ and 26.1\% for the challenge winner), DROID post-training followed by zero-shot transfer to an unseen environment and objects (82.5\%), a language-following Pick-and-Place benchmark, LIBERO (98.9\%), RoboTwin 2.0 (93.3\%), and SimplerEnv-Bridge (87.3\%).

## 论文总结：G0.5——用于机器人推理与动作的单一自回归流

### 1. 核心问题与研究动机

- **背景**：视觉-语言-动作（VLA）模型的当前主流范式是将预训练 VLM 与单独训练的流匹配（flow-matching）/扩散动作专家耦合，形成"VLM-as-encoder"架构。
- **核心问题**：这种架构将 VLM 降级为"上下文编码器"而非真正的"决策者"，导致 VLM 的生成能力（思维链推理、上下文学习、提示驱动的行为引导）只能通过压缩的条件瓶颈间接影响动作，无法原生参与动作生成过程。
- **论文主张**：VLA 的前进方向不应是在"未充分利用的 VLM"之上堆叠日益复杂的动作专家，而应让 VLM 保持其预训练的本质——一个自回归推理器，同时具备行动、记忆和上下文自适应能力。
- **研究含义**：通过解决自回归 VLA 范式原有的效率瓶颈（动作 token 过多、高频控制慢），证明统一自回归流可以在基础模型规模上成为 VLA 的实用范式，并在一系列基准上达成 SOTA。

### 2. 方法论

论文提出 **G0.5**，一个预训练的自回归 VLA 模型，系统性地将感知、推理与动作统一到一个自回归过程中。核心设计包含三个组件：

- **单一目标、单一解码器（核心思想）**：G0.5 从一个预训练 VLM（Qwen3.5 2B）初始化，所有输入输出被序列化为单一 token 序列（条件段 + 生成段），仅使用一个标准的下一 token 交叉熵损失：
  > ℒ(θ) = − Σᵢ∈𝒢 log p_θ(xᵢ | x<ᵢ)
  
  损失仅作用于生成段（CoT 与动作 token），因此 CoT 推理与动作生成共享解码器、上下文和目标，"推理即 token，动作即 token"。

- **① 跨具身动作编码器（Cross-embodiment ActionCodec）**——
  1. 将异构机器人动作按语义对齐的运动部件（左臂、右臂、下体、夹具）分解，每部分填充到共享最大维度；
  2. 采用**残差向量量化（RVQ）** 对分组动作进行压缩编码（4 级残差逐级细化），并引入**时间对比学习目标**提升相邻时间步动作的 token 一致性；
  3. 所有机器人映射到同一 27 维统一动作空间：`<left_control>(9) | <left_gripper>(1) | <right_control>(9) | <right_gripper>(1) | <lower_body>(7)`；
  4. token 序列中显式注入结构特殊 token（如 `<left_control_r>`、`<right_control_r>`），并采用**R 轮残差细化**（每轮每个活动组 8 个动作代码），只生成当前活跃自由度组的 token，未激活组完全跳过，实现稀疏动作预测。

- **② 原生思维链（Native Chain-of-Thought）**——
  1. 四个自描述推理目标：任务分解（Subtask:）、关键物体定位（BBox:）、2D 夹爪轨迹（Trace:）、动作提示（ActionHint:），可自由组合（8 种组合，含无 CoT 基线），每种组合在训练时按权重随机采样；
  2. 推理 token 与动作 token 在同一流中交错生成，共享注意力，而非像 CoT-VLA、DualCoT-VLA 等那样将推理模块外挂到 VLM-as-encoder 骨干上；
  3. 这种设计使 CoT 在测试时可作为提示条件开关，无需重新训练即可控制是否启用推理。

- **③ 视觉记忆模块（Visual Memory）**——
  1. 借鉴 π0.7 和 MEM 的设计，在 Vision Transformer 中每隔 4 层插入**分解的空间-时间注意力模块**，分别沿时间步和空间 patch 混合信息；
  2. 严格限制计算延迟：最终层丢弃所有历史 token；训练时随机丢弃历史帧（30% 概率）防过拟合；
  3. 连续的 proprioceptive 状态嵌入替代离散文本 tokenizer，与对应视觉帧精确同步。

- **预训练策略**：单阶段预训练，混合 14 种具身的真实/仿真机器人数据 + 网络级 VQA + 自动标注数据。机器人样本经自动标注流水线（规则分割 + Gemini 3 / Doubao Seed 2.0 生成语言标注 + SAM3 生成 bbox/掩码 + 正运动学投影 2D 轨迹）生成多粒度监督信号。

### 6. 主要结论与发现

1. **自回归 VLA 范式优于 VLM-as-encoder 范式**：在同种微调设置下，G0.5 在真实世界、模拟、长时程任务上全面超越 π0.5/GR00T-N1.7 等代表模型，表明 AR 并非此前认为的性能瓶颈。
2. **AR 监督保护而非损害 VLM 能力**：PP Bench 上 G0.5 零样本语言跟随率超过 π0.5 后训练后的表现，说明 AR 动作监督信号有助于
