## 摘要
通用机器人策略旨在将多模态观测和语言任务指令映射到跨不同任务的动作。然而，现有方法通常将未来表示为固定的、短视频动作块。这种短期未来捕获局部场景演化以执行动作，但它没有明确描述指定任务应如何从当前阶段推进到下一阶段的阶段级未来。因此，我们区分了机器人操作的两种互补未来：用于捕获局部场景演化的短期物理未来和用于表示任务进度的阶段级语义未来。我们引入JEPA-WAM，它通过Stage-JEPA（一种目标条件的联合嵌入预测架构（JEPA）预测器）增强了基于Motus的世界动作模型（WAM）。给定当前观测和任务指令，Stage-JEPA使用冻结的V-JEPA2编码器提取当前状态表示，并预测下一推断阶段的潜在目标。在干净和随机化环境中的50个RoboTwin 2.0任务中，JEPA-WAM实现了90.25%的总体成功率，并将成功推出中的平均执行步骤数相对于最强基线减少了5.97%。

## Abstract
Generalist robot policies aim to map multimodal observations and linguistic task instructions to actions across diverse tasks. However, existing methods typically represent the future as a fixed, short video-action chunk. This short-term future captures local scene evolution for action execution, but it does not explicitly describe the stage-level future that specifies how a task should progress from its current stage to the next. We therefore distinguish two complementary futures for robot manipulation: a short-term physical future to capture local scene evolution and a stage-level semantic future to represent task progress. We introduce JEPA-WAM, which augments a Motus-based World Action Model (WAM) with Stage-JEPA, a goal-conditioned Joint-Embedding Predictive Architecture (JEPA) predictor. Given the current observation and task instruction, Stage-JEPA uses a frozen V-JEPA2 encoder to extract the current-state representation and predicts the latent target of the next inferred stage. Across 50 RoboTwin 2.0 tasks in clean and randomized environments, JEPA-WAM achieves 90.25% overall success and reduces the mean number of execution steps in successful rollouts by 5.97% relative to the strongest baseline.

# JEPA-WAM：机器人操作中世界-动作模型的阶段级联合嵌入预测——论文总结

## 1. 论文的核心问题与整体含义

- **研究背景**：通用机器人策略（如视觉-语言-动作模型 VLA 和世界-动作模型 WAM）在跨任务操作中取得了显著进步，但现有方法通常将未来表示为一个*固定、短时的视频-动作块*。
- **核心问题**：现有方法只显式建模了“短期物理未来”（局部场景如何演化、动作如何执行），却**没有显式描述“阶段级语义未来”**——即任务应如何从当前阶段推进到下一个有意义的任务状态（如物体所有权转移、物体-目标对齐、容器收纳等）。
- **关键洞察**：预测一条合理的视频-动作轨迹，并不等同于策略理解了“当前任务下一个应达到的状态是什么”。像素级的目标图像预测会偏向外观细节而非任务完成度。
- **本文方案**：区分两种互补的未来——短期物理未来（局部场景演化）和阶段级语义未来（任务进度）。提出 **JEPA-WAM**，将目标条件的 JEPA 预测器（Stage-JEPA）与 Motus 世界-动作模型耦合，以潜在表征形式预测“下一任务阶段目标”，并将其作为内部条件注入 WAM 的视频与动作生成。

## 2. 论文提出的方法论

### 2.1 核心思想
- 采用**两阶段训练**：阶段 I 训练目标条件 JEPA 预测器（Stage-JEPA），推断下一阶段的潜在目标表征；阶段 II 冻结该预测器，训练 WAM 在该阶段条件引导下生成短时视觉未来与动作块。
- Stage-JEPA 在**表征空间**进行预测（而非像素空间），保留任务相关的语义与物理结构，对低级外观不敏感；预测的潜伏目标作为“内部进度目标”引导 WAM 生成，而非作为生成的未来观测。

### 2.2 阶段 I：训练 Stage-JEPA 预测器
- **自动阶段对构建**（无需人工阶段标签）：
  1. 对每条演示轨迹，每 8 帧采样候选中心，用冻结 V-JEPA2 编码居中的 64 帧片段。
  2. 计算 clip 级与 token 级表征变化得分（V-JEPA2 特征距离，含局部窗口比较与逐 episode 归一化）。
  3. 使用时间 NMS（半径 r=3，最多 K=5）选出转换关键帧，加上首尾帧构成阶段边界序列 B=(b₀,…,b_L)。
  4. 对每个阶段 [bᵢ, bᵢ₊₁) 内的每一帧 t，与下一边界 bᵢ₊₁ 形成稠密配对 (t, bᵢ₊₁)——关键帧只定义边界，训练对是稠密的。
- **目标条件阶段预测**：
  - 使用冻结 V-JEPA2 编码器分别提取当前片段 St 与目标片段 S_target 的潜在表征 z_t 与 z_target。
  - 可训练的预测器（从 V-JEPA2 predictor 初始化）+ 任务指令交叉注意力适配器，预测 token 级下一阶段表征，经池化与归一化后与真实目标表征做余弦相似度对齐。
  - 损失函数（cosine loss）：
    \[
    \mathcal{L}_{stage} = \frac{1}{B}\sum_{i=1}^{B} \left(1 - (\hat{z}_i^{target})^\top z_i^{target}\right)
    \]

### 2.3 阶段 II：训练阶段条件化的 WAM
- **基座模型**：Motus，多层 Transformer 混合架构（Mixture-of-Transformers），含视频生成专家（Wan2.2 初始化）、动作专家、视觉-语言理解专家（Qwen3-VL），三者经 Tri-modal Joint Attention 交互。
- **条件注入方式**：
  1. 将 Stage-JEPA 输出的 256 个目标 token 进行平均池化。
  2. 经 MLP P_ψ 映射到 Wan 视频 token 维度，得条件向量 h_t。
  3. 通过**全局有界标量门控** α = 0.2σ(β) 控制注入强度（β 为可训练标量，初始化为使 α≈0.02）：
     \[
     \tilde{X}_t^v = X_t^v + \alpha h_t
     \]
  4. h_t 样本特异、广播到该样本的所有视频 token；α 跨样本、层、token、通道共享。
- **训练损失**：L = L_video + L_action + L_reg，其中 L_reg 为门控正则项：
  \[
  \mathcal{L}_{reg} = \lambda_g \alpha^2 + \lambda_\rho (\rho - \rho_0)^2,\quad \rho = \frac{\|\alpha h_t\|}{\|X_t^v\|}
  \]
  使门控偏小且注入相对幅度接近目标比例 ρ₀=0.08。

### 2.4 闭环推理
- 维护因果 64 帧观测缓冲（不足 64 帧时重复最早帧填充）。
- 推理时：Stage-JEPA 从缓冲与指令预测阶段潜伏 → WAM 据此预测有限视界视频未来与动作块 → 环境执行动作块后追加新观测，滚动规划。
- 阶段边界与目标切片**仅训练时使用**，推理不依赖。

## 6. 论文的主要结论与发现

- **主结果**：JEPA-WAM 在干净/随机化配置下分别达到 91.42% / 89.08% 成功率，总体 90.25%，优于 Motus（88.66% / 87.02%）。
- **类别差异**：在交接、目标放置、容器收纳、排列与堆叠、工具使用与动态操作等**依赖明确任务阶段转换**的类别上提升最明显；获取与举起、铰接/设备交互提升有限。
- **消融发现**：
  - 去除 JEPA 退化最大（87.23% 总体）→ 阶段条件通路提供超越 WAM 的增量信息。
  - 不注入未来潜伏（仅当前帧表征使用）也下降 → 直接注入 WAM 视频流比只改当前表征更有效。
  - 不训练 Stage-I 仍有一定竞争力（预训练 V-JEPA2 提供通用视觉结构），但加入阶段监督最佳。
  - 去除门控正则影响最小，说明 sigmoid 有界门控本身已较稳定。
- **执行效率**：JEPA-WAM 将全部 rollout 平均 episode 长度从 156.28 降至 132.80（-15.02%）；成功 rollout 平均长度从 79.57 降至 74.82（**-5.97%**），即阶段引导减少冗余修正动作。
- **真实机器人**：平均任务进度评分 48.00 vs π0.5 的 41.50（Cube_Grasp 45.00 vs 33.50；Power_Strip 51.00 vs 49.50）。

## 7. 优点

- **问题建模创新**：明确区分“短期物理未来”与“阶段级语义未来”，这一双尺度分解在概念上清晰、在实践中有验证价值。
- **免人工标注的阶段检测**：基于 V-JEPA2 表征变化的自动关键帧检测 + NMS，无需人工阶段标签即可构建稠密监督，可扩展性强。
- **JEPA 表征空间预测**：避免像素级重建的细节偏置，直接对齐任务相关的语义表征，与 WAM 的生成式建模分工互补。
- **轻量注入设计**：全局标量门控 + 样本特异性条件向量，以最小干预方式让阶段信息引导 WAM；门控正则使注入幅度可控制。
- **实验证据链完整**：大规模模拟基准 + 多种消融 + 真实机器人验证 + 执行效率与轨迹分析，多层次验证了方法有效性。
- **代码透明度较好**：实现细节（阶段检测参数、训练超参、门控机制、诊断统计）公开充分，可复现性较好。

## 8. 不足与局限

- **部分任务类别提升有限**：获取与举起类任务主要依赖即时抓取几何与接触稳定性，阶段结构信息较少；铰接/设备交互需要机制特定接触与精确时序，仅靠间接注入的阶段信号可能不足。
- **存在个别退化的任务**：附录每任务结果显示，个别任务（如 Put Object Cabinet：Motus 干净/随机化 88%/71% vs JEPA-WAM 65%/54%；Place Object Basket、Move Mouse Pad 等）JEPA-WAM 明显低于 Motus，说明阶段条件引导并非对所有操作语义都有益。
- **阶段检测依赖启发式**：V-JEPA2 特征变化 + NMS 自动生成边界，无语义标注；虽免人工但可能出现与真实“语义阶段”不对齐的情况。诊断显示 81.72% 的阶段区间短于 64 帧 V-JEPA2 窗口，包含跨边界信息与切片重叠（86% 左右），这意味着学习的是一段时间上下文的“情境化表示”而非严格的目标外推。
- **推理延迟未解决**：作者自述未来工作之一是降低 WAM 推理延迟以支持更高频闭环控制——当前方法对实时控制仍存在速度瓶颈。
- **训练算力消耗较高**：大规模 V-JEPA2 编码 + Motus WAM 训练，资源需求较大，但论文未提供训练时长，难以评估部署门槛。

- **真实机器人验证规模小**：仅两个简单任务、共计 170 条训练轨迹、各 20 次评估，且只与 π0.5 对比，未在真实场景中验证更复杂的长程操作。
