## 摘要
视觉-语言-动作模型（VLA）正快速走向作为通用操作策略的部署，但我们目前缺乏基本工具来理解这些模型内部表征什么或在运行时对其进行监控。借鉴机械可解释性的思想，我们探测了$\pi_{0.5}$的残差流，发现任务进度（轨迹中归一化的剩余时间）可以从激活中线性读取。我们发现，该信号存在于预训练的PaliGemma骨干中，早于任何机器人特定数据的训练。单个线性探针可以泛化到未见过的任务，并在多提示数据上训练时随语言反事实而变化，但无法实现对策略的有意义引导。这些属性使该信号直接可用于监测已部署的VLA。我们将该探针用作简单的无标签OOD检测器，用于检测停滞的任务进度，并发现它与最先进的方法相比具有竞争力。我们的结果表明，VLA具有对任务进度等语义量的丰富、线性可读的内部表征，学习读取这些信号为监测已部署的视觉运动策略提供了一条轻量级、可解释的途径。

## Abstract
Vision-language-action models (VLAs) are moving rapidly towards deployment as general-purpose manipulation policies, but we currently lack basic tools for understanding what these models represent internally or for monitoring them at runtime. Leveraging ideas from mechanistic interpretability, we probe the residual stream of $π_{0.5}$ and find that task progress, the normalized time remaining in a trajectory, is linearly readable from the activations. We find that this signal is present in the pretrained PaliGemma backbone prior to training on any robot-specific data. A single linear probe generalizes to unseen tasks and varies under language counterfactuals when trained on multi-prompt data, but does not enable meaningful steering of the policy. These properties make the signal directly useful for instrumenting deployed VLAs. We use the probe as a simple label-free OOD detector, which detects stalled task progress, and find it competitive with state-of-the-art methods. Our results suggest that VLAs have rich, linearly readable internal representations of semantic quantities like task progress, and that learning to read these signals offers a lightweight, interpretable path toward monitoring deployed visuomotor policies.

## 2. 论文提出的方法论

### 2.1 核心思想

借鉴机械可解释性中"线性表征假说"（Linear Representation Hypothesis，即高层语义概念在激活空间中倾向线性编码），论文在π0.5的残差流上训练**线性探针**来解码"任务进度"这一标量特征。

### 2.2 关键定义：三个递进的概念

论文将"网络表征某特征"的论断强度分为三个层次：

| 概念 | 定义 | 检验方式 |
|------|------|----------|
| **弱可解码性** | 线性信号可从分布内激活提取 | 在训练分布上的测试损失低（L1损失） |
| **强可解码性** | 同一探针在反事实变换输入上仍泛化 | 对输入施加变换 T（如语言名词替换）后，探针输出跟随真实反事实值 |
| **可引导性** | 通过编辑激活可以因果地改变模型行为 | 沿探针方向注入偏移量后，模型动作分布接近真实反事实下动作分布 |

### 2.3 任务进度特征定义

对于轨迹 ξ = (x₀, x₁, ..., x_T)，任务进度定义为：

```
τ(x_t) = 1 − t / T ∈ [0, 1]
```

即归一化的剩余时间，在轨迹起点为1（完全未开始）、终点为0（接近成功）。

### 2.4 线性探针

对于层 i 的嵌入 zⁱ，探针形式为 φ(zⁱ) = wᵀzⁱ + b，通过最小化 L1 损失训练：

```
R(φ; D) = (1/K) Σ L(φ(zⁱ_k); ζ_k)
```

论文对嵌入进行 token 维度上的均值池化。

### 2.5 OOD 检测算法

1. 从 ID 轨迹估计期望任务完成时间 E[T|ℓ]。
2. 运行时每个 replan 步骤，解码预测进度 τ_pred。
3. 计算残差：

```
Vτ(t) = τ_pred − (1 − t / E[T|ℓ])
```

4. 首次出现 Vτ(t) > δ 时标记为 OOD。

该方法的直观逻辑：若策略进入 OOD 状态，任务进度停滞，预测进度将明显偏离预期进度曲线。

### 2.6 对比探针训练（用于强可解码性）

朴素反事实增强方案效果不佳（探针可通过平移输出来拟合常数标签），因此采用**成对内 hinge 损失**，配合进度相关间隔和 BCE 锚定损失，迫使探针学到区分原始提示与交换提示的相对方向。

## 6. 论文的主要结论与发现

1. **任务进度可从 π0.5 激活中线性读取**：弱可解码性在早期视觉层和前几个 Gemma 层显著（R² = 0.95），shuffled-label 对照确认该信号非数据拟合的伪影。

2. **信号由大规模机器人预训练建立，而非微调**：Base π0.5 与微调 π0/π0.5 表现相当且远优于 PaliGemma；该信号甚至存在于 PaliGemma 中（较弱），表明基础表征已有此倾向。

3. **朴素探针缺乏语言敏感性，对比训练可恢复**：基于视觉的朴素探针在名词交换反事实下输出几乎不变；经对比目标训练的探针在交换提示下预测 τ≈1.0（视为零进度），同时保持原始提示下的正常进度追踪。

4. **任务进度可观测但不可引导**：沿探针方向注入 τ_boost=0.2 后，后续层进度读数不变，动作轨迹与真实反事实动作差距无改善——特征存在但策略未因果使用。

5. **任务进度可作为无标签 OOD 检测器**：
   - 跨任务泛化：per-episode AUROC 0.851（未见任务），接近监督 SOTA 的 SAFE-MLP（0.917），且在模态泛化上超过 SAFE：unseen per-episode AUROC 0.960 vs SAFE-MLP 0.894。
   - **不依赖任何 OOD 标签**，可检测策略进入扰动状态时任务停滞。

6. **VLA 内部存在丰富的线性可读语义信号**，读取这些信号为监控部署策略提供了轻量级替代方案。

## 7. 优点

1. **概念体系清晰**：将"可解码性"拆分为弱/强可解码性与可引导性三个强度递进的层次，为可解释性研究提供了可比较的框架。

5. **诚实披露负面结果**：明确报告"不可引导"的负面发现，以及对比训练的性能代价（ID R² 大幅下降），没有选择性修饰。

## 8. 不足与局限

1. **模型与场景覆盖有限**：所有实验基于 π0.x 模型家族与 VLABench 模拟环境，未涉及真实机器人部署、其他 VLA 架构（如 OpenVLA）或其他仿真环境。跨架构/跨真实的普适性未验证。

2. **任务进度定义的语义歧义**：τ 定义为归一化时间剩余，天然混淆了"时间流逝"与"语义完成程度"。论文通过强可解码性实验部分缓解了该问题，但缺乏真正的完成标签来完全区分两者。

3. **对比标签为代理值**：强可解码性实验中，交换指令的反事实标签设为 τ=1.0 是代理——真实的交换任务进度难以定义且无法不通过独立 rollout 采集，模型可能在拟合代理而非真实语义。

4. **可引导性的结论范围窄**：仅测试了单层（layer 0）注入、单一方向（正向进度）和固定幅度（0.2），更强的注入策略或多层联合编辑可能产生不同结果。因此"不可引导"应理解为"该线性探针在此设置下不可引导"，而非绝对结论。

5. **OOD 检测的粒度依赖**：Vτ 在 per-replan 级别上对颜色偏移和遮挡模态的检测弱于 SAFE-MLP，仅在 per-episode 聚合后反超；对于需要实时 replan 级别报警的场景，其可靠性受限。

6. **训练分布依赖 E[T|ℓ]**：检测器需要估计每类任务的期望完成时间，在不熟悉的任务语义下（如零样本开放词汇任务），该估计可能不准确。

7. **语言敏感性测试局限**：语言反事实仅覆盖目标名词交换，未测试句式变化、介词变化、多指令排序等更多样化语言扰动。
