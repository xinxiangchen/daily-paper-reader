## 摘要
零样本物体目标导航（ZSON）要求机器人在从未进入过的建筑中找到指定类别的物体。现有主流方法使用视觉-语言价值图对前沿进行评分：每一步都对当前地图进行又一次argmax操作，而支撑该分数的证据在做出决策的那一刻就被丢弃了。将大型视觉-语言模型置于感知-动作循环中的系统，通常仅从当前视角按固定计划进行查询；机器人几分钟前走过的房间永远不会被重新考虑，一次失败的调用也没有明确的回退机制。我们将机器人已经看到的内容转化为推理的对象。我们的层级快速-慢速智能体在每一步都保持价值图控制器的运行，并在移动过程中写入坐标锚定记忆：一个包含房间类型和已确认物体实例的语义网格，以及一个有界的位姿标记关键帧存储。视觉语言模型在每次候选检测写入之前对其进行筛选。一个深思层在有界的推理-检索-行动循环中读取这个记忆。它会在反应层计算出的结构事件发生时被唤醒，首先基于文本进行推理，并且仅对文本无法区分的候选对象调用第一人称视图。每次调用和每次运行的上限约束了其调用次数，一个无调用的第一层解决了最常见的停顿，任何失败都会将控制权返回给反应控制器。我们的系统在HM3D v1验证集上达到68.75%的成功率，在MP3D验证集上达到47.29%，是这里比较的零样本方法中最高的成功率。在所有2000个HM3D场景的配对比较中，通过argmax而非深思来选择远方前沿损失了3.40个成功率点（95%置信区间[1.70, 5.05]）；而对每个前沿进行深思并不能挽回这些损失。

## Abstract
Zero-shot object-goal navigation (ZSON) requires a robot to find a named object category in a building it has never entered. The prevailing approach scores frontiers with a vision--language \emph{value map}: every decision is another argmax over the map as it currently stands, and the evidence behind that score is discarded the moment it is taken. Systems that place a large vision--language model inside the perception--action loop typically query it on a fixed schedule from the current view alone; a room the robot walked through minutes earlier is never reconsidered, and a failed call has no defined fallback. We turn what the robot has already seen into the object of deliberation. Our hierarchical fast--slow agent leaves the value-map controller running at every step and writes a \emph{coordinate-anchored memory} as it moves: a semantic grid of room types and confirmed object instances, together with a bounded store of pose-tagged keyframes. A VLM screens each candidate detection before it is written. A deliberative layer reads this memory in a bounded reason--retrieve--act loop. It wakes on structural events the reactive layer computes, reasons first over text, and recalls a first-person view only for candidates that text alone cannot separate. Per-invocation and per-run caps bound its calls, a call-free first tier resolves the most frequent stall, and any failure returns control to the reactive controller. Our system reaches 68.75% SR on HM3D v1 \texttt{val} and 47.29% on MP3D \texttt{val}, the highest success rate among the zero-shot methods compared here. Choosing among far frontiers by argmax instead of deliberating costs 3.40 SR points in a paired comparison over all 2000 HM3D episodes (95\% CI [1.70, 5.05]); deliberating over every frontier does not recover them.

## 1. 论文的核心问题与整体含义

- **研究背景**：零样本物体目标导航（ZSON）要求机器人在从未见过的室内建筑中，根据语义类别（如“床”、“马桶”、“植物”）找到目标物体，且不能针对该类别进行任何训练。
- **现有方法的缺陷**：
  - 主流方案（如 VLFM、ASCENT）每一步都基于当前视觉-语言价值图对前沿进行“argmax”贪心选择，决策后立即丢弃支撑该决策的证据。
  - 将大模型嵌入感知-动作循环的系统（如 CogNav、SG-Nav）按固定时间表调用模型，且只基于当前视角，无法重新审视机器人之前经过的房间。
  - 当机器人遇到结构性僵局（如被卡住、远处前沿无法区分、前沿耗尽、需要跨楼层）时，贪心控制器缺乏推理与回退机制。
- **核心思想**：将机器人“已经看到的东西”变成推理对象——保留快速的反应式控制器持续执行，同时引入一个慢速的深思层，基于坐标锚定的记忆进行有界推理，仅在必要时调用视觉证据，从而提升 ZSON 的成功率。

## 2. 论文提出的方法论

- **总体架构：层级快速-慢速智能体**
  - **反应式控制器（快速层）**：基于 ASCENT 的价值图控制器，每一步持续运行，负责感知、建图、运动规划与避障。
  - **深思式控制器（慢速层）**：仅在结构性事件触发时启动，执行有界的“推理-检索-行动”（ReAct）循环，返回类型化指令，不参与每一步的底层运动控制。
- **坐标锚定记忆**：
  - **语义网格**：以 0.4m 分辨率聚合 8×8 占用像素，每个单元存储房间类型投票直方图、覆盖该单元的关键帧索引、以及稀疏的物体实例表（类别、位置、观测次数、支持关键帧）。物体至少被观测两次才被确认为可检索，抑制单次误检。
  - **关键帧存储**：有界的低分辨率关键帧缩略图，按平移/旋转阈值采样，携带位姿、楼层、步数、房间标签与可见物体；采用按楼层逐层淘汰策略，防止新楼层挤掉旧记忆。
  - **检索接口**：给定查询位置，返回房间估计、附近确认实例、覆盖统计和排序后的候选关键帧；图像召回遵循严格的回退阶梯（精确足迹 → 放宽足迹 → 前沿发现帧 → 纯文本），检索永远不会中断控制。
- **事件触发深思**：四种结构性僵局触发慢速层：
  - **接触停顿**：通过碰撞计数和非位移检测判定机器人被卡住；先使用零调用（抑制目标、重新规划）的一级恢复，失败后调用 VLM 请求逃逸方向。
  - **远处前沿**：最近前沿超过距离门限时，先基于文本描述与房间亲和度推理，文本无法区分时，最多检索两个候选的关键帧图像作为第二轮证据。
  - **前沿耗尽**：当前楼层前沿为空时，将已存储关键帧构成索引蒙太奇，询问模型是否有被忽略的通道；找到则生成持久目标并重新启用附近探索目标。
  - **楼层切换**：本楼层探索停滞且已知其他楼层时，让 VLM 基于纯文本楼层摘要决策，失败则回退。
- **预算与仲裁**：
  - 每次调用最多 3 轮推理，任何单次调用最多 2 张图像，有墙钟限制；
  - 每轮运行最多 20 次模型调用，其中图像调用最多 10 次；同循环重新触发至少间隔 15 步；每次扫描每个楼层最多 2 次，蒙太奇不超过 8 个关键帧；
  - 单步决策超过 180 秒则禁用模型调用；连续失败触发熔断；
  - 所有失败路径（空记忆、服务故障、不可解析回复、预算耗尽）都确定性回退到反应式控制器，保证智能体始终有控制器可执行。
- **检测验证门**：目标候选在融合进对象地图前，必须经过 VLM 逐检测验证；被拒绝的候选不会进入可授权停止的地图，从而避免不可逆的错误融合。

## 3. 实验设计

## 6. 论文的主要结论与发现

- 有界深思优于贪心：在远前沿选择上用 argmax 而非深思会损失 3.40 个 SR 点（95% CI [1.70, 5.05]）；而“对每个前沿都深思”不但不提升，反而低于贪心（64.80% vs 65.35%），说明**“何时调用模型”比“调用多少”更重要**。
- 按需获取视觉证据比一次性提供所有图像更有效：One-Shot 消融损失 3.70 SR 点，证明“只在文本无法区分时进行图像召回”是关键。
- 语义网格贡献集中于“防止过早停止”：去掉语义网格后，3.35 点损失中有 2.55 点来自“无前沿”类失败。
- 验证门在融合前拦截了 16.7% 的候选检测，避免错误永久写入可授权停止的对象地图。
- 深思的收益分散在多个失败类别（假阳性、无前沿、假阴性），不是仅靠单一机制达成。
- 系统的整体成功率在 HM3D v1 val 和 MP3D val 上达到最高，且 SPL 同时领先，说明新增成功并非靠走更长的路。

## 7. 优点

- **架构设计清晰**：快速反应层与慢速深思层解耦，深思层不干涉每一步运动，只在结构性僵局时介入，工程上稳健且易部署。
- **记忆设计巧妙**：坐标锚定记忆同时包含抽象层（语义网格）和字面层（关键帧），支持“先文本推理、后按需图像检索”，降低了模型调用成本。
- **预算与失败回退完备**：调用次数、图像数、运行时间都有硬性上限，所有失败路径都确定性回退到反应层，不会出现“无控制器”状态。
