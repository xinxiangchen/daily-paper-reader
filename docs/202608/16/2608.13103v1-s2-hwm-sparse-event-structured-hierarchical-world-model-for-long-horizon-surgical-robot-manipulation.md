## 摘要
长时程手术机器人操作具有挑战性，因为任务奖励稀疏，而有意义的交互变化以不规则的间隔发生。现有的世界模型智能体通常以原始步长分辨率进行想象，使得可变时长的任务进展隐含不清。手动指定的阶段可以提供中间结构，但其任务特定的边界难以与状态相关的交互转换对齐。我们提出了S2-HWM，一种稀疏事件结构化的层次世界模型，它从原始潜在轨迹中学习稀疏事件证据，以协调事件级管理器和原始步长工作者。事件证据调度管理器目标更新，每个选中的潜在目标条件化工作者的原始动作，直到下一次更新。学习到的事件证据还为事件转换模型（ETM）形成可变时长的分段，该模型预测下一个边界随机状态、分段持续时间和累积分段奖励。将这些事件级预测链接起来，提供了超出原始想象视野的可变时长延续，用于管理器学习，而工作者保留原始步长的演员-评论家学习。在基于SurRoL的PegTransfer任务中，S2-HWM达到了98.7%的成功率，比平坦的GAS DreamerV3基线高出22.7个百分点。

## Abstract
Long-horizon surgical robot manipulation is challenging because task rewards are sparse, while meaningful interaction changes occur at irregular intervals. Existing world-model agents typically imagine at primitive-step resolution, leaving variable-duration task progress implicit. Manually specified stages can provide intermediate structure, but their task specific boundaries are difficult to align with state-dependent interaction transitions. We propose S2-HWM, a Sparse Event-Structured Hierarchical World Model that learns sparse event evidence from primitive latent trajectories to coordinate an event-level manager and a primitive-step worker. The event evidence schedules manager goal updates, and each selected latent goal conditions the worker's primitive actions until the next update. The learned event evidence also forms variable-duration segments for an Event Transition Model (ETM), which predicts the next?boundary stochastic state, segment duration, and accumulated segment reward. Chaining these event-level predictions provides a variable-duration continuation beyond the primitive imagination horizon for manager learning, while the worker retains primitive-step actor-critic learning. On a SurRoL-based PegTransfer task, S2-HWM achieves a success rate of 98.7%, outperforming the flat GAS DreamerV3 baseline by 22.7 percentage points.

## 1. 核心问题与研究动机

- **问题根源**：长时程手术机器人操作面临两大核心挑战——**奖励稀疏**（仅在任务完成时提供学习信号）和**有意义的交互变化发生间隔不规则**。这两个因素使得策略学习中的信用分配（credit assignment）极为困难。
- **现有方法的不足**：
  - **平面世界模型**（如 Dreamer 系列）以"原始步长"（primitive-step）分辨率进行想象，无法显式表达可变时长的交互事件何时结束、持续多久、积累了多少奖励；
  - **手动指定阶段**（如逐阶段奖励）虽然提供中间结构，但其任务特定的固定边界难以与状态依赖的交互转换对齐，容易出现错误的状态归属。
- **核心洞察**：事件边界应从智能体实际经历的交互动力学中推断，而非由人工预先设定。这构成了本文提出 S2-HWM 的根本出发点。

## 2. 方法论

### 2.1 总体框架

S2-HWM 构建了一个**双层层次架构**：
- **事件级管理器（Manager）**：在稀疏的事件边界上选择潜在目标（latent goal），决定"做什么"；
- **原始步长工作者（Worker）**：在每一原始步根据当前潜在状态和管理器目标执行动作，决定"怎么做"。

核心创新在于：**从原始潜在轨迹中学习稀疏事件证据（sparse event evidence）**，该证据同时用于调度管理器目标更新和构建事件转换模型（ETM）的训练分段。

### 2.2 关键组件与技术细节

**（1）原始世界模型（Primitive World Model）**
- 采用 DreamerV3 的循环状态空间模型（RSSM）作为原始层世界模型；
- 潜在特征 `ft = [zt, ht, mt]` 包含随机状态 zt、确定性记忆 ht 和持久交互上下文 mt，支持部分可观测环境下的历史依赖建模。

**（2）稀疏上下文动力学（Sparse Context Dynamics）**
- 通过上下文模型 Φctx 预测候选更新 `m̃t` 和软门控 ρt；
- 上下文更新：`mt = ρt ⊙ m̃t + (1 - ρt) ⊙ mt-1`，配合直通式二值化产生稀疏维度级激活 `gt`；
- `gt` 作为**事件证据**（而非直接作为边界），通过聚合和接受规则生成事件边界 {τi}。

**（3）事件对齐的层次策略**
- 在接受的更新点 τi，管理器从边界特征 Fi = fτi 采样离散码 ci，映射到潜在目标 ηi = E(ci)；
- 该目标在 [τi, τi+1) 段内条件化工作者的原始动作（公式1）；
- 管理器更新调度由学习到的事件证据驱动，而非固定周期。

**（4）事件转换模型（ETM）**
- 以事件边界之间的可变时长分段 ei = [τi, τi+1) 为训练单位；
- 预测下一个边界随机状态、分段持续时间和累积分段奖励；
- 引入内部分类转换模式 `ui`（后验 qθ(ui | xei, zei+1) 与先验 pθ(ui | xei) 对齐），表达相同起始状态到不同结局的变异性；
- **优势**：直接跨事件预测，避免递归展开中间原始状态，减少误差累积。

**（5）事件扩展的管理器引导（Event-Extended Manager Bootstrap）**
- 管理器目标结合两个分支（图2）：
  - **短期估计 Bshort**：原始步想象轨迹终点处管理器值函数 VM(f̃H)；
  - **事件级延续 Bevent**：从同一终点出发，经 K 次 ETM 递归预测未来的边界状态、分段奖励（带时长折扣 γ^Δj）和最终特征引导；

## 6. 主要结论

- S2-HWM 在单次转移上达到 **98.7% ± 2.3%** 成功率，比 GASDreamerV3（76.0%）**高出 22.7 个百分点**；
- 在重复转移（91.3% vs 77.3%）和扰动测试（88.0% vs 65.3%）中也保持显著优势；
- **消融结论**：
  - 去掉层次策略（w/o Hierarchical Policy）退化最严重（68.0%），说明事件证据必须通过管理器转化为持久目标才有效；

- 多事件预测分析显示 ETM 的误差增长比 RSSM 更慢，支持其作为扩展管理器引导的有效性；
- 策略行为分析表明，管理器代码分组与不同语义阶段呈现结构化对应关系（如抓取附近竖直调节+夹爪、抬升阶段向上运动、放置阶段横向校正），尽管这些语义标签从未用于训练。

## 7. 优点

- **统一的事件证据接口**：同一事件证据同时驱动管理器更新调度和 ETM 分段构建，形成了从世界模型到层次控制的自然桥梁；
- **无需语义标注**：事件边界完全从潜在轨迹学习，避免了手工阶段划分与状态依赖交互转换的错位问题；
- **可变时长的层次抽象**：管理器目标在变长段内保持active，更符合半马尔可夫/选项框架的语义，且自适应交互事件的实际时长；
- **ETM 的设计巧妙**：通过类别转换模式表达结局的多变性，直接预测"边界状态+时长+奖励"三元组，避免逐原始步递归带来的误差累积；
- **实验诊断深入**：不仅报告成功率，还通过预测误差分析和行为动作倾向分析验证了内部机制与设计意图的一致性；
- **与最强基线 GASDreamerV3 严格对齐**：共享视觉前端、动作接口和骨干，构成干净的主对照。
