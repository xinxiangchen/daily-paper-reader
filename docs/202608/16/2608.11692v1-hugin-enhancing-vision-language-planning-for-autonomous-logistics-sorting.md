## 摘要
自主物流分拣系统（ALSS）是具身智能的重要工业应用，需要对空间上分离的摄像头视图进行联合规划。我们将此设定形式化为联合多场景理解（JMSU）。凭借开放世界的视觉理解和任务规划能力，视觉-语言模型（VLM）是JMSU的有力候选。然而，由于跨场景监督稀缺以及JMSU中长视觉上下文导致的注意力分散，将现有VLM直接应用于JMSU并非易事。为应对这些挑战，我们提出了HUGIN，一个包含两个互补组件的训练框架。内生数据增强在操作约束下重组已验证的原子事实，而全局上下文排名则使指令表示与完整视觉上下文的关联强于与部分视觉上下文的关联。为支持持续研究，我们从四种自主物流分拣系统布局构建了高质量工业分拣数据集及基准SortingBench。在五个开放VLM上，HUGIN始终优于匹配的基线；例如，Qwen3-VL-8B在SortingBench上的准确率从63.6%提升至78.8%。额外实验验证了各组件的有效性以及JMSU在具身任务中的溢出收益。涉及超过15,000个包裹的部署测试支持了基于VLM的规划在自主物流分拣中的实际可行性。

## Abstract
Autonomous logistics sorting systems (ALSS) are an important industrial application of embodied AI, which requires joint planning over spatially disjoint camera views. We formulate this setting as Joint Multi-Scene Understanding (JMSU). With open-world visual understanding and task-planning capabilities, vision-language models (VLMs) are promising candidates for JMSU. However, directly applying existing VLMs to JMSU is non-trivial due to scarce cross-scene supervision and attention dispersion caused by long visual context in JMSU. To address these challenges, we propose HUGIN, a training framework with two complementary components. Endogenous Data Augmentation recombines verified atomic facts under operating constraints, while Global Context Ranking aligns the instruction representation more strongly with the complete visual context than with a partial visual context. To support ongoing research, we construct a high-quality industrial sorting dataset and benchmark named SortingBench from four layouts of autonomous logistics sorting systems. Across five open VLMs, HUGIN consistently outperforms matched baselines; for example, the accuracy on SortingBench of Qwen3-VL-8B increases from 63.6% to 78.8%. Additional experiments verify the effectiveness of each component and JMSU's spillover benefits in embodied tasks. Deployment tests involving more than 15,000 packages support the practical viability of VLM-based planning for autonomous logistics sorting.

## 1. 核心问题与研究动机

- **研究背景**：自主物流分拣系统（ALSS）是具身智能的重要工业落地场景，系统由机械臂、目的地笼、分布式 RGB-D 相机和底层控制器组成，需要在物理上分离、视野几乎不重叠的多个相机视角之间进行联合规划，完成“选择源隔间→定位包裹→选择目标笼→生成操作序列”的任务。
- **关键问题**：论文将这种设定抽象为 **联合多场景理解（JMSU, Joint Multi-Scene Understanding）**，其两个核心特征是：
  - **空间分布性**：多个摄像头覆盖物理上不相交的区域，视野重叠极小；
  - **决策级相互依赖**：不同视角提供互补证据，删除任一关键视角都可能导致规划失效。
- **现有 VLM 的缺陷**：尽管 VLM 具备开放世界理解和任务规划能力，但直接用于 JMSU 面临两大瓶颈：
  - **跨场景监督稀缺**：工业数据噪声大、标注成本高，且常规图像/文本增强会破坏跨场景的物理一致性和动作标签合法性；
  - **长视觉上下文下的注意力分散**：大量高分辨率视觉 token 使注意力被稀释，模型难以识别关键证据并整合完整系统状态。
- **论文目标**：提出 Hugin 训练框架，在不改变推理架构、不增加推理时开销的前提下，提升 VLM 在 JMSU 上的规划能力，并配套构建工业级评测基准 SortingBench。

## 2. 方法论与关键技术

Hugin 包含两个互补组件，分别对应数据层和模型层：

- **内生数据增强（EDA, Endogenous Data Augmentation）**
  - 核心思想：将复杂 JMSU 任务分解为可验证的“原子事实”，再在操作约束下重新组合，从而以多项式级规模扩充有效训练分布，且不依赖教师 VLM 生成（避免幻觉）。
  - 分为三个阶段：
    1. **解耦（Decoupling）**：LLM 解析每个标注样本，抽取包裹数量、离隔间出口最近的包裹、笼占用率、空间定位等原子事实，并生成对应的原子问题；
    2. **组合（Combination）**：脚本化合成器从事实池中采样，根据业务规则（如“选择包裹最多的隔间、FIFO 取件、选择剩余容量最大的笼”）重新计算完整计划，生成可审计的合成样本；
    3. **增强（Augmentation）**：额外生成目标检测、区域识别、笼状态识别等辅助感知任务（D_aux），并混入通用 VQA 数据 D_general 以缓解灾难性遗忘。
  - 最终训练集为 D = D_origin ∪ D_atomic ∪ D_syn ∪ D_aux ∪ D_general。

- **全局上下文排名（GCR, Global Context Ranking）**
  - 核心思想：利用 decoder-only VLM 的因果注意力机制，提取三个关键隐藏状态作为“语义锚点”：
    - 局部视觉上下文 e_n（第 n 个 `<|vision_end|>` 边界，只覆盖前 n 张图）；
    - 全局视觉上下文 e_N（最后一个视觉边界，覆盖全部 N 张图）；
    - 指令意图 q（回答 token 前一个位置的隐藏状态，聚合全部视觉与文本信息）。
  - 优化目标：要求 q 与 e_N 的余弦相似度高于 q 与 e_n 的相似度，使用 margin-based Hinge loss：
    \[
    L_{GCR} = \mathbb{E}_{n\sim U\{1,N-1\}}\left[\max\left(0, \alpha + \text{SG}(\tilde{e}_n)^\top \tilde{q} - \tilde{e}_N^\top \tilde{q}\right)\right]
    \]
    - 其中 SG 表示 stop-gradient，防止模型通过退化局部特征来偷懒；
    - α=0.1，λ=0.01，仅在多图样本（N≥2）时激活；
    - 最终损失：\(L_{total} = L_{CE} + \lambda \cdot \mathbb{I}(N \ge 2) \cdot L_{GCR}\)。
  - 训练完成后移除 GCR，推理接口与成本不变。

## 3. 实验设计

- **真实数据与基准**：从 4 个 ALSS 工作站收集 3 个月数据；D_origin 含 2,000 个训练样本（布局 1–2），SortingBench 含 1,000 个测试样本（4 种布局，含未见布局 3–4 和不同光照条件），每样本要求模型联合输出源隔间、包裹定位（IoU≥85%）、目标笼和完整操作序列。
- **Hugin 训练数据规模**：EDA 解析出 6,000 个原子事实；训练约 20,000 额外样本 = 13,954 原子/辅助感知任务 + 2,000 合成 JMSU + 4,000 通用 VQA（LLaVA-1.5）。
- **对比方法与基线**：
  - 开放 VLM：Ovis2.5-2B、Gemma3-4B、MiniCPM-V4.5、Qwen3-VL-4B/8B；
  - 闭源 VLM：GPT-5.5、GPT-5-nano-high；
  - 具身专用模型：RoboBrain2.5-8B-NV（12.4M 具身样本训练）、Ego3D-VLM；
  - 匹配基线：SFT（仅用 D_origin）作为主要对照，还有 +Ego3D 变体。
- **评测维度**：
  - SortingBench（分 L1–L4 布局及总体）；
  - 通用 VQA：MMBench/EN、MMBench/CN、MME；
  - 具身相关多图任务：BLINK 的 Object-Localization (OL)、Visual-Similarity (VS)、Counting (Co.)，以及 MUIR-Bench 的 Scene-Understanding (SU)；
  - 附加压力测试：图像顺序打乱、增加 6/12 干扰图、移除关键图等。

## 6. 主要结论与发现

- Hugin 在所有 5 个开源 VLM 上一致优于匹配 SFT 基线，提升幅度分别为 +9.2%、+29.8%、+22.5%、+5.1%、+15.2%；Qwen3-VL-8B 从 63.6% 提升至 78.8%。
- 在训练未见的布局 3–4 上仍有 17.7% 和 16.6% 的提升，说明具备一定场景泛化能力。
- 关键图移除实验符合 JMSU 的最小充分集定义：SFT 从 63.6% 降至 35.6%，Hugin 从 78.8% 降至 41.6%，均落入理论预期区间。
- GCR 单独在 D_origin 上也能带来 5.2%–6.1% 的提升；EDA 的合成数据扩展成效显著（前 2,000 样本即 +11.6%）。
- 训练不仅提升 SortingBench，还在 BLINK/VS 从 75.6% 提升到 88.2%（跨图像比较能力），并基本保持 MMBench/EN、MME 等通用能力，甚至 MME 从 1699 增至 1743。
- 部署测试（15,000+ 包裹）达到 73.1% 预测准确率，验证了 VLM 规划在实际 ALSS 中的可行性。
- 结论：JMSU 的瓶颈是“跨场景监督稀疏”和“长上下文注意力分散”，Hugin 通过约束保持的数据增强 + 全局上下文对齐目标，可以在不改变推理结构的情况下显著提升多视图联合规划能力。

## 7. 优点与亮点

- **问题定义清晰**：首次将 ALSS 规划抽象为 JMSU，并用数学公式（式 1–4）严格刻画“空间分布性”和“决策级依赖”，为后续研究提供可复用的形式化基础。
- **数据增强可审计**：EDA 基于结构化事实重组，而非教师模型生成，标签可追溯、可验证，避免 VLM 幻觉污染训练数据。
- **模型层目标简洁高效**：GCR 利用因果注意力天然的 token 拓扑包含关系，通过隐藏状态相似度排序强化全局上下文对齐，训练后可完全移除，推理零开销。
- **实验体系完备**：既有跨模型泛化、又有跨布局泛化、压力测试、消融、真实部署，覆盖面广，且对“改进来自何处”有机制性验证（顺序扰动、干扰图、关键图移除）。
- **工业价值突出**：真实 70m² 系统、15,000+ 包裹部署，体现从论文到实际系统的闭环。

## 8. 不足与局限

- **数据规模有限**：D_origin 仅 2,000 样本，SortingBench 仅 1,000 测试样本，虽经合成扩展但场景数量仍有限；
- **布局泛化局限于同一应用域**：L3–L4 虽未见，但仍在同构的物流分拣系统中，跨领域泛化（如仓储、家庭、户外自主作业）未验证；
- **评测指标单一**：主指标为“整个动作序列是否正确 + 边界框 IoU≥85%”，未对部分正确、感知误差、执行失败的鲁棒性做细粒度分析；
- **部署环境受限**：仅 1 个真实 ALSS 场景（2 个隔间、10 个笼），且未报告对硬件误差、动态障碍、极端光照的鲁棒性；
- **GCR 的负样本仅来自局部上下文**：stop-gradient 虽避免退化，但未与其他对比学习变体（如利用随机图像、跨样本负样本）比较；
- **闭源模型对比不充分**：GPT-5.5/GPT-5-nano-high 未做 SFT 适配，只能体现零样本差距，不能说明其适配后上限；
- **灾难性遗忘问题**：通用 VQA 仅使用 LLaVA-1.5 的 4,000 样本，且某些模型（如 MiniCPM-V4.5）在 MMBench 上仍有小幅下降，长期稳定性未知。
