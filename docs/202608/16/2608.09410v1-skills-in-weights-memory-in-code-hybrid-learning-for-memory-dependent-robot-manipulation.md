## 摘要
现代视觉-语言-动作（VLA）策略已获得广泛的操作技能，但通常从当前观测或较短固定长度历史中生成每个动作块。然而，现实世界中的操作往往是非马尔可夫的，要求机器人从长时程交互历史中保留并推理任务相关信息以决定下一步动作。为应对这一挑战，我们提出HyMeS，一种多重学习框架，利用编码代理的推理和记忆管理能力来引导一个马尔可夫VLA进行记忆依赖型操作。具体而言，HyMeS通过基于梯度的模仿学习学习低级运动技能，而编码代理通过启发式学习获取高级记忆管理策略，即通过从迭代中更新可执行的启发式系统，并使用展开反馈。此外，我们通过多模态阶段完成验证来闭环引导与执行，使用本体感觉信号和多帧VLM判断更新记忆。与端到端记忆增强型VLA相比，HyMeS仅需要针对可复用运动技能的演示，而非每个历史依赖型任务配置，从而实现了数据高效的组合泛化。在RoboMemArena上，HyMeS将平均累计成功率从52.5%提高到66.2%，平均任务成功率从41.3%提高到60.1%，相比pi0.5，并在累计成功率上超过PrediMem 4.5个百分点，在任务成功率上超过14.5个百分点。

## Abstract
Modern vision-language-action (VLA) policies have acquired broad manipulation skills, but typically generate each action chunk from the current observation or a short fixed-length history. However, real-world manipulation is often non-Markovian, requiring robots to retain and reason over task-relevant information from long-horizon interaction histories to determine the next action. To address this challenge, we propose HyMeS, a hybrid learning framework that leverages the reasoning and memory-management capabilities of coding agents to steer a Markovian VLA for memory-dependent manipulation. Specifically, HyMeS learns low-level motor skills through gradient-based imitation learning, while a coding agent acquires high-level memory-management strategies through heuristic learning by iteratively updating an executable heuristic system from rollout feedback. Furthermore, we close the loop between steering and execution through multimodal stage-completion verification, which updates memory using proprioceptive signals and multi-frame VLM judgments. Compared with end-to-end memory-augmented VLAs, HyMeS requires demonstrations only for reusable motor skills rather than for every history-dependent task configuration, enabling data-efficient compositional generalization. On RoboMemArena, HyMeS improves mean cumulative success from 52.5% to 66.2% and mean task success from 41.3% to 60.1% over pi0.5, while outperforming PrediMem by 4.5 points in cumulative success and 14.5 points in task success.

**背景问题：**
- 现代VLA（视觉-语言-动作）模型（如π0.5、π0.6）已具备广泛的低级运动技能，但从架构上本质是**马尔可夫**的——每次仅依据当前观测或短窗口历史生成动作块。
- 现实机器人操作常是**非马尔可夫（memory-dependent）**的：需要保留并推理长时程交互历史（如早期出现后消失的线索、已完成的重复次数）才能正确决策。

**核心矛盾：**
- 记忆依赖型任务中，不同的历史状态可以对应相同的当前观测但要求互不相容的动作（观测别名问题），马尔可夫策略无法区分。
- 现有记忆增强型VLA通过扩展上下文或添加记忆模块，端到端地从示范中学习历史条件策略，但将记忆获取与运动学习绑定，需要覆盖组合性的记忆配置的示范数据，且隐式记忆缓冲难以检查和干预。

**核心问题：** 如何在保持VLA马尔可夫架构不变的前提下，赋予其长时程记忆推理能力，同时避免为每个历史依赖配置收集示范？

## 2. 方法论：HyMeS框架

### 2.1 核心思想

**将运动技能学习与记忆策略学习完全分离：**
- **权重空间（Weight Space）**：VLA通过基于梯度的模仿学习获取低级运动技能；
- **代码空间（Code Space）**：编码代理（coding agent）通过启发式学习获取高层记忆管理策略——用可执行程序作为符号记忆。

### 2.2 系统组成

系统由两个互补组件构成：

1. **运动组件**：一个马尔可夫流匹配VLA策略（πθ），权重在微调后完全冻结；
2. **记忆组件**：可执行启发式程序 `P = (C, V, U)`，包含：
   - **约束选择规则 C**：根据当前符号状态选择可微约束
   - **事件验证规则 V**：多模态阶段完成验证
   - **记忆更新规则 U**：更新符号内存状态

### 2.3 符号记忆状态

符号状态 `s_t = (plan, ρ_t, B_t, N_t, F_t)` 包含：任务计划、当前阶段、对象绑定、重复计数、持久交互状态——直接可解释，可由先前观测的信息更新。

### 2.4 权重空间学习（运动技能）

- 初始化自预训练VLA（如π0.5），在专家示范集上微调流匹配目标。
- 流程：噪声与专家动作块插值 `a_τ = (1-τ)ε + τa`，优化速度场：
  - `θ* = argmin E[||vθ(a_τ, τ|o, ℓ) - (a - ε)||²]`
- 微调完成后，权重固定，记忆获取不修改权重。

### 2.5 代码空间学习（记忆策略）

- 编码代理从展开轨迹反馈中迭代修订程序：

- 保留开发展开中性能最佳的程序作为 `P*`；评估时冻结并关闭修订。

### 2.6 记忆条件动作引导

- 当前阶段和符号状态选择可微约束（如到达目标约束）：
  - `R_reach = -||ee(a) - Γ(target(s_t), o_t)||²`
- 将约束梯度注入流匹配速度场：
  - `v̂ = vθ*(a_τ, τ|o_t, ℓ) + λ_t ∇R_ρt(a_τ, o_t; s_t)`
- 引导衰减调度（sigmoid式）：早期全局记忆引导占主导，接近接触区域时减弱，让运动策略主导精确操作。

## 7. 优点与亮点

- **方法论新颖**：将非马尔可夫控制问题重组为“权重空间学技能 + 代码空间学记忆”的混合学习问题，将连续动作与离散逻辑分离处理，与真实任务结构（连续运动 + 离散状态）更匹配。
- **数据效率**：无需为每种历史依赖配置收集示范，只需可复用技能演示即可组合泛化到新配置，避免组合爆炸。
- **可解释性与可干预性**：符号记忆是显式、可读的程序状态，失败可直接定位，可编辑、可调试。
- **双向闭环**：不仅用记忆引导VLA的生成过程，还通过多模态PACE验证将执行反馈（本体感觉 + 视觉）读回更新记忆，构成闭环而非单向推理。
- **引导衰减调度**：在策略接近接触区时自动衰减引导，保留VLA的精细运动能力，避免干扰接触类操作。
- **实验严谨**：修正协议检查、公平对比（相同权重和任务）、消融设计合理，并做了真实硬件验证。

## 8. 不足与局限

- **应用范围有限**：仅适用于可被紧凑符号状态表示的记忆依赖任务，是否适用于更开放的语义记忆或隐式历史表征值得商榷。
- **受底层VLA能力瓶颈约束**：即使记忆正确、约束恰当，仍可能失败于运动执行（如瞄准偏差导致抓取失败）；操作能力上限取决于π0.5等因素。
- **潜在偏差风险**：任务选择依赖π0.5行为判定（需具备运动技能），可能偏向于π0.5技能库覆盖的任务类型。
- **视觉验证在遮挡下仍不可靠**：遮挡类是HyMeS提升最小的类别，说明多帧VLM在目标隐藏时判断受限。
- **推理开销**：周期性VLM查询和编码代理调用增加每episode的推理延迟和成本，论文提到但未量化。
- **对比基线有限**：未与更多近期记忆增强VLA方法（如MemoryVLA、EventVLA等）对比，外部效度受限。
- **算力与成本信息缺失**：未报告GPU资源消耗、训练时间、编码代理迭代次数等，难以评估工程成本与复现难度。
