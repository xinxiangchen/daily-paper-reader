## 摘要
机器人操作需要能够识别可操作部件（如手柄、轮缘、扳机、工具尖端）的感知系统，而不仅仅是物体类别或点云。本文提出 RoboSeg，一种部件级语义重建系统，将视觉语言模型（VLM）的功能部件发现、异步在线 RGB-D 语义重建和任务导向的抓取生成联系起来，无需 CAD 模型或预扫描网格。RoboSeg 在初始 RGB 观测上查询 VLM 以获得紧凑的功能部件提示，然后通过两个异步流进行扫描：用于 RGB-D 里程计和截断符号距离函数（TSDF）融合的高频几何线程，以及用于 SAM3 部件掩码的关键帧触发式语义线程。投影掩码通过体素级时间投票融合为持久的部分标记点云；RoboSeg 使用此地图将 AnyGrasp 6-DoF 候选分配给语义部件，并选择与任务相关部件标签一致的抓取。RoboSeg 在手动标注对象上达到 83.4% 的平均部件交并比（mIoU）；在跨四个对象和八项任务的 24 次物理试验中，所选抓取在所有试验中均接触到所请求的部件，并实现了 21/24 的综合任务成功。这些结果将 RoboSeg 定性为任务条件操作的语义索引层，AnyGrasp 保留为提议生成器。

## Abstract
Robotic manipulation requires perception systemsthat identify actionable parts such as handles, rims, triggers,and tool tips, not merely object categories or point clouds. This paper presents RoboSeg, a part-level semantic reconstructionsystem that links vision-language model (VLM) functional-partdiscovery, asynchronous online RGB-D semantic reconstruc-tion, and task-oriented grasp generation without requiring CAD models or pre-scanned meshes. RoboSeg queries a VLM onthe initial RGB observation to obtain compact functional part prompts, then scans with two asynchronous streams: a high-frequency geometry thread for RGB-D odometry and truncated signed distance function (TSDF) fusion, and a keyframe-triggered semantic thread for SAM3 part masks. Projectedmasks are fused by voxel-level temporal voting into a persistentpart-labeled point cloud; RoboSeg uses this map to assign AnyGrasp 6-DoF candidates to semantic parts and select grasps consistent with the task-relevant part label. RoboSeg reaches 83.4% mean part intersection-over-union (mIoU) over manually labeled objects; in a 24-trial physical pilot across fourobjects and eight tasks, the selected grasp contacts the requestedpart in all trials and achieves 21/24 combined task successes.These results characterize RoboSeg as a semantic indexing layerfor task-conditioned manipulation, with AnyGrasp retained asthe proposal generator.

## 1. 论文的核心问题与整体含义

- **核心问题**：机器人操作需要的是对"可操作部件"（如杯柄、壶嘴、刀刃、工具尖端）的识别与定位，而非仅仅物体类别或整体点云。现有感知系统在两方面的能力存在割裂：
  - 离线3D部件分割方法（如PartSLIP、PartSTAD、ZeroPS）假设已有完整的CAD模型或预扫描网格，缺乏在线闭环能力；
  - 开放词汇语义映射系统（如ConceptFusion、ConceptGraphs）多面向房间级或物体级理解，未细化到可操作的部件级，且缺少与抓取生成的直接衔接。
- **核心研究问题**：构建一个无需CAD模型、无需预扫描网格、由眼在手相机在线扫描即可生成部件级语义地图，并直接支持任务导向抓取选择的系统。
- **整体含义**：作者将RoboSeg定位为"任务条件操作（task-conditioned manipulation）的语义索引层"，即把通用抓取候选与语义部件关联，使机器人能按自然语言指令选择与任务相关的抓取位置。其目标不是取代抓取生成器，而是为现有强抓取模型（AnyGrasp）提供语义路由能力。

## 2. 论文提出的方法论

### 核心思想
将"理解该抓哪里"（VLM功能部件推理）与"重建物体并找到可行抓取位姿"（TSDF重建+AnyGrasp）解耦为三个模块，以异步方式结合高频率几何重建与低频率语义推理，在避免互相拖累的前提下逐帧累积出稳定的部件级语义点云。

### 关键技术细节

**模块A：VLM驱动的功能部件发现**
- 在扫描开始前，仅使用初始RGB图像查询Qwen3-VL，要求其返回：物体名称、1~3个自包含的功能部件名称（如"watering can handle"而非含糊的"handle"）、以及推理理由。
- 输出格式为`{object: o, parts: [p1, ..., pn], cot: r}`；只有parts字段被转发给SAM3作为提示词，推理理由不参与下游计算。
- 设计意图：将SAM3的语义搜索空间从"所有可见区域"压缩到"紧凑的操纵相关部件集"，避免SAM3在"segment everything"模式下按纹理、颜色、阴影、接缝等外观边界产生杂散掩码。

**模块B：异步在线语义重建**
- 双线程架构共用同一体素坐标系：
  - **几何线程（高频）**：每个RGB-D帧执行位姿估计（可用机器人正运动学正则化），并将深度图融合进TSDF体素。
  - **语义线程（低频）**：按可配置的关键帧间隔触发SAM3，执行部件掩码分割，将有效掩码像素反投影到当前TSDF体素坐标。
- **体素投票张量**：每个占据体素存储top-K（K=3）候选实例ID及其票数：
  - $S(v) = \{(i_1(v), s_1(v)), \ldots, (i_K(v), s_K(v))\}, K=3$
  - 新掩码投影到体素集后，先在该体素集中查找同类标签的已有实例ID，若无则分配新ID，被选中的ID在该掩码覆盖的所有体素各得1票。
  - 查询时取最高票实例：$\hat{i}(v) = \arg\max_k s_k(v)$
- 作用：抑制视角变化引起的掩码边界抖动和标签闪烁，使反复观测的部件区收敛为稳定标签，瞬时2D噪声因票数不足而被淘汰。

**模块C：任务导向抓取候选选择**
- 对重建点云运行AnyGrasp生成稠密6-DoF抓取候选。
- 对每个候选，查询夹爪闭合区域内的点，将该候选分配给其中占主导的语义实例。
- 自然语言任务指令通过实例表映射为部件标签集合L，选择器保留标签∈L的候选并按AnyGrasp评分排序，取最高分执行。
- 该模块**不修改AnyGrasp的置信度**，只对候选进行语义索引，以便按任务约束筛选。

### 算法流程（Algorithm 1）
输入初始RGB帧 → VLM生成部件提示 → 初始化TSDF与投票张量 → 逐帧执行几何线程（位姿估计+TSDF融合）→ 按间隔在语义线程执行SAM3掩码反投影和投票 → 扫描完成后导出点云和实例表 → AnyGrasp生成候选 → 为每个候选分配语义实例 → 从任务解析部件标签 → 筛选出最高分的匹配候选并执行。

## 3. 实验设计

- **硬件平台**：UR5机械臂 + 眼在手Intel RealSense D435i相机，NVIDIA RTX 3090 GPU工作站。
- **对象集**：日常与工坊物品——杯子、碗、水壶、工具、瓶子、锅、喷壶等，涵盖BigPot、DoubleHandlePot、Hammer、KitchenKnife、WateringCan等关键对象。
- **离线对比**：与PartSLIP和PartField对比。这些baseline接受完整的mesh/点云输入（对baseline极为有利），RoboSeg仅使用在线扫描数据。定性对比展示于Fig. 3。
- **定量评估**：在可用对齐标签下，用Blender材质标注作为GT，忽略离GT表面5mm以上的预测点，评估点级IoU。

### 具体评估组
1. **部件发现与语义质量**：5个对象的点级IoU评估（RoboSeg），以及4个对齐对象上与PartField的标签对齐对比。
2. **几何精度**：将RGB-D里程计与机器人正运动学作为TSDF融合的位姿来源进行配对比较，指标包括Chamfer距离、重建→GT精度、GT→重建完整度、F1@5mm和F1@10mm。
3. **物理任务-部件抓取验证**：4个对象×8个任务条件，每个条件3次，共24次物理试验。
4. **候选分配覆盖率**：跨21个重建场景，统计AnyGrasp候选能否被分配已知部件标签。

## 4. 资源与算力

- 文中仅提及使用**NVIDIA RTX 3090 GPU**工作站进行推理和映射，未说明GPU数量。

## 5. 实验数量与充分性

- **语义IoU评估**：5个手动标注对象，规模较小但包含薄壁、突出部件等具有挑战性的几何。
- **物理试验**：24次试验（4对象×8任务×3重复），作者明确称其为"pilot"（试验性验证），结果应视为可行性证据而非精确统计估计。
- **几何评估**：仅对具有CAD/数据集参考模型的代表性对象进行配对比较。
- **候选分配分析**：21个重建场景、883个AnyGrasp提案。

### 评估的充分性与客观性评价
- **优点**：评估策略合理——每个实验隔离流水线中的一环，分别回答"部件发现是否准确"、"几何是否够用"、"语义路由是否有效"三个问题，而非用一个综合分数掩盖组件缺陷。
- **不足**：试验次数有限（尤其物理试验），初始视角标准化，未涵盖遮挡和任意位姿的鲁棒性；PartSLIP未能在统一指标框架下参与定量对比；离线baseline在输入数据上享有显著优势，而RoboSeg仅获得部分观测。

## 6. 论文的主要结论与发现

- RoboSeg在5个标注对象上达到**83.4% mIoU**；在4个可对齐对象上与PartField的对比中，RoboSeg达**86.7% mIoU** vs PartField的83.2%，即不使用完整网格输入的在线系统可比肩甚至超越离线方法。
- 物理试验中：**24/24次试验正确接触到请求的部件**（任务-部件正确率100%），物理抓取成功21/24，综合任务成功21/24。三次失败均发生在部件接触正确但提升不稳定的情况，说明失败源于抓取执行而非语义选择。
- 提案分析：目标部件候选在所有8/8条件下存在且被语义过滤选中；而未经过滤的AnyGrasp top-1候选仅在4/8条件下匹配目标部件。
- 候选分配覆盖率为**89.7%**（792/883提案成功分配到已知部件）。
- 作者的定位性结论：RoboSeg是**可用的语义索引接口**，连接部件级地图与任务条件抓取执行；AnyGrasp保留为提议生成器，RoboSeg不试图改进其置信度。

## 7. 优点

- **端到端在线能力**：不依赖CAD模型、物体模板或预扫描网格，直接从原始RGB-D流构建可用的部件级语义地图，显著降低部署门槛。
- **异步架构设计巧妙**：将高频几何重建与低频语义分割解耦，避免SAM3推理延迟阻塞TSDF融合，兼顾实时性与语义精度。
- **体素投票机制轻量有效**：以top-K投票张量（K=3）替代简单的标签覆盖，在极小存储开销下抑制了跨帧标签闪烁，是一个实用且可推广的工程方案。
- **VLM约束分割的思路清晰**：用VLM推理选择"该分割什么"，而非让SAM3无约束分割"所有可见区域"，既提高了部件语义的操纵相关性，又减少了3D融合的掩码数量。
- **系统定位务实**：不声称取代AnyGrasp，而是作为其语义索引层，职责边界清晰，实验设计也相应地逐环节隔离验证。
- **评估中考虑公平性**：明确说明离线baseline获得完整网格输入的优势，并在受约束的共享标签框架下进行定量对比，避免误导性结论。

## 8. 不足与局限

- **物理试验规模过小**：24次试验不足以给出可靠的统计成功率估计，作者也承认这一局限。
- **初始视角标准化**：试验假设"信息丰富的初始视角"，未评估物体随机位姿、极限视角或严重遮挡下的性能退化。
- **对象类别有限**：标注对象仅5个，缺乏跨类别泛化证据；薄型部件（如锅柄、喷壶嘴）得分明显偏低（DoubleHandlePot仅61.9% mIoU）。
- **离线基线对比不完整**：PartSLIP因度量框架不对齐而只能定性比较；PartField在完整网格输入下仍只在4/5对象上可比。
- **缺少消融实验**：未量化体素投票的贡献（如对比简单多数标签覆盖）、未评估VLM部件发现失败的传播影响、未分析关键帧间隔τ的敏感度。
- **缺少运行时剖析**：未提供各模块延迟、帧率、GPU内存占用等工程关键指标，实际部署可行性证据不足。
- **任务规划能力有限**：将任务映射到部件标签的过程较简单，未涉及复杂多步骤任务或部件之间的交互约束（如ReKep中的关键点约束）。
- **泛化风险**：依赖Qwen3-VL和SAM3的预训练分布，对未见过的物体类型或非标准功能部件的泛化能力未经检验。
