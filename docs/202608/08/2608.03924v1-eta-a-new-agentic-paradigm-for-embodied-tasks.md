## 摘要
机器人何时会迎来它们的ChatGPT时刻？这样的突破需要一个通用型机器人，它能够处理陌生环境中的不熟悉任务，在长时间交互中保持可控，并从经验中学习。如今的具身系统大多遵循端到端的观察-行动路径。尽管进展迅速，它们仍远未达到这一目标：其泛化能力高度依赖于机器人训练数据的覆盖范围，而长时间的任务执行则难以控制和检查。为实现这一目标，我们引入了具身任务代理（ETA），这是一种将数字代理扩展至物理世界的新范式，并发布了其开源实现OpenETA。ETA以规划器（Planner）为核心，每次选择一个工具调用；接口（Interface）控制执行；世界（World）返回结果和新的观察。这一循环使代理能够验证结果、调整计划，并将成功与失败的交互转化为可重用的经验。OpenETA提供了可替换的规划器、可组合的工具和技能、可审计的记忆、可重放的轨迹，以及用于仿真和真实机器人的通用接口。对于Codex，OpenETA可作为轻量级插件运行，仅暴露observe、mark_point和move_to功能。

## Abstract
When will robots have their ChatGPT moment? Such a breakthrough requires a general-purpose robot that can handle unfamiliar tasks in unfamiliar environments, remain controllable over long interactions, and learn from experience.   Today's embodied systems largely follow an end-to-end observation-to-action path. Despite rapid progress, they remain far from this goal: their generalization depends heavily on the coverage of robot training data, while long task execution remains difficult to control and inspect. To realize this goal, we introduce the Embodied Task Agent (ETA), a new paradigm for extending digital agents into the physical world, and release OpenETA as its open-source implementation. ETA centers the robot around a Planner that chooses one Tool call at a time, an Interface that controls execution, and a World that returns the result and a fresh observation. This loop allows the agent to verify outcomes, adapt its plan, and turn successful and failed interactions into reusable experience. OpenETA provides replaceable Planners, composable Tools and Skills, auditable memory, replayable trajectories, and common interfaces for simulation and real robots. For Codex, OpenETA can operate as a lightweight plugin that exposes only observe, mark_point, and move_to.

## 2. 方法论：核心思想、关键技术细节与算法流程

- **核心思想**：ETA 将机器人的行为组织为**“感知-规划-执行-验证”循环**，核心是让机器人在每个时间步**只选择一个工具调用（Tool call）**，而不是一次性输出完整的动作序列或低层控制指令。
- **系统组成（三要素）**：
  - **Planner（规划器）**：系统的决策核心。它在每个步骤观察当前世界状态，决定调用哪一个工具、传入什么参数，相当于“大脑”。
  - **Interface（接口）**：负责将规划器的高层指令翻译并**控制实际执行**——既可是仿真器中的 API 调用，也可是真实机器人的底层控制命令。
  - **World（世界）**：执行工具调用后返回**执行结果与全新的观察**（如新的视觉图像、状态信息），供规划器进行下一步决策。
- **闭环流程（以文字描述算法过程）**：
  1. Planner 接收当前任务目标与最新的 World 观察；
  2. Planner 选择一个工具并生成一次调用；
  3. Interface 执行该工具调用；
  4. World 返回执行结果与新观察；
  5. 回到步骤 1，直至任务完成。
- **经验积累机制**：该闭环使代理能够验证每一步的**结果是否符合预期**，进而调整后续计划；成功与失败的交互记录都可以被转化为**可重用的经验**，供未来类似任务参考。
- **开源实现 OpenETA 的关键设计**：
  - **可替换的 Planners**：支持接入不同的大语言模型/规划器；
  - **可组合的 Tools 与 Skills**：工具和能力可以模块化组合，灵活适配不同任务；
  - **可审计记忆（auditable memory）**：记忆内容可被检查与追溯；
  - **可回放轨迹（replayable trajectories）**：完整记录任务执行轨迹，便于复盘与学习；
  - **通用接口**：同时支持仿真环境与真实机器人。

  - 未见**长期学习曲线**的量化展示：经验库从零到大的累积过程中成功率如何渐进提升，论文未给出足够证据。
  - 对失败分类（规划失败、执行失败、感知失败）缺乏细粒度分析。
- **对比公平性风险**：
  - 与基线方法的对比中，未详细说明是否在**相同提示词结构、相同视觉输入处理、相同解码策略**下进行，存在一定的比较偏差风险。
  - 未报告**重复实验次数及方差**，统计显著性不明。
- **应用限制**：
  - 单步工具调用的串行决策模式在**长时任务中会累积延迟**，对实时性要求高的场景可能不适用；
