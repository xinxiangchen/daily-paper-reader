## 摘要
视觉-语言-行动（VLA）模型为连接视觉感知、语言理解和机器人控制提供了统一范式。然而，现有的VLA模型在长期任务中仍面临重大挑战：稀疏的专家演示限制了跨任务的组合泛化；长期任务的非马尔可夫性质使得仅以当前观测为条件的策略难以保持时间一致性；有限的闭环纠错能力导致执行误差累积；端到端的动作微调可能削弱视觉-语言模型（VLM）骨干网络的高层语义表示。为解决这些问题，我们提出了一种带有显式语言记忆模块的层次化长期VLA架构。核心思想是将离散的时间观测转换为具有时间逻辑的连贯文本记忆序列。该系统被解耦为高层VLM和低层VLA：高层VLM通过视觉问答训练范式进行语义推理，而低层VLA在子任务指令和视觉观测的条件下执行精确的连续控制。高层VLM以前一个记忆作为上下文锚点，递归更新语言记忆和子任务指令，从而在长期执行过程中实现持续的时间跟踪和动态纠正。我们在多个仿真环境中评估了所提出的方法，并在真实机器人平台上进行了仿真到现实的实验。结果表明，显式语言记忆提高了VLA模型在复杂长期任务中的成功率和鲁棒性，同时为决策过程提供了可解释的语义描述。

## Abstract
Vision-language-action (VLA) models provide a unified paradigm for connecting visual perception, language understanding, and robotic control. However, existing VLA models still face major challenges in long-horizon tasks: sparse expert demonstrations constrain cross-task compositional generalization; the non-Markovian nature of long-horizon tasks makes it difficult for policies conditioned only on current observations to maintain temporal consistency; limited closed-loop error correction allows execution errors to accumulate; and end-to-end action fine-tuning may weaken the high-level semantic representations of vision-language model (VLM) backbones. To address these issues, we propose a hierarchical long-horizon VLA architecture with an explicit language-memory module. The central idea is to convert discrete temporal observations into a coherent textual memory sequence with temporal logic. The system is decoupled into a high-level VLM and a low-level VLA: the high-level VLM performs semantic reasoning through a visual question answering training paradigm, while the low-level VLA executes precise continuous control conditioned on subtask instructions and visual observations. The high-level VLM recursively updates both language memory and subtask instructions using the previous memory as a contextual anchor, enabling persistent temporal tracking and dynamic correction during long-horizon execution. We evaluate the proposed method in multiple simulation environments and conduct sim-to-real experiments on a real robotic platform. The results demonstrate that explicit language memory improves the success rate and robustness of VLA models on complex long-horizon tasks while providing an interpretable semantic account of the decision process.

## 1. 论文的核心问题与整体含义（研究动机和背景）

视觉-语言-行动（VLA）模型将视觉感知、语言理解与机器人控制统一到一个策略框架中，是具身智能领域的重要方向。然而，现有VLA模型在**长时程（long-horizon）任务**中面临四个关键挑战：

- **稀疏专家演示限制组合泛化**：跨任务、跨阶段的组合泛化能力受限于有限的高质量演示数据。
- **非马尔可夫性导致时序不一致**：长时程任务的决策依赖于历史状态（如之前的抓取是否成功、按钮是否已按下），而仅基于当前观测的策略无法区分"相同画面、不同状态"的场景，容易跳过阶段、重复已完成动作或在未观测到失败时提前进入后续动作。
- **闭环纠错能力不足**：执行误差在动作序列中逐步累积，缺乏有效的检测与恢复机制。
- **端到端动作微调削弱高层语义**：直接用动作目标微调VLM，可能破坏其预训练中的高层语义表征。

论文的核心思想是：用**显式的自然语言记忆**来替代原始视觉历史的拼接，将离散时序观测压缩为具有时间逻辑的文本记忆序列，从而为长期规划提供紧凑、可解释、可监督的历史状态表示。

## 2. 论文提出的方法论

### 2.1 核心架构：分层VLM-VLA策略

论文将长期策略分解为两个解耦的子模块：

- **高层VLM（π_HL）**：负责语义推理，递归更新语言记忆 `m_t` 和子任务指令 `s_t`。输入为全局指令 `l`、当前观测 `o_t` 和上一时刻的显式语言记忆 `m_{t-1}`。训练范式为视觉问答（VQA）。
- **低层VLA（π_LL）**：基于当前观测 `o_t` 和子任务指令 `s_t`，生成固定视界 `H=30` 的连续动作块 `a_{t:t+H}`。

整体策略的概率分解为：

```
π(a_{t:t+H}, s_t, m_t | o_t, m_{t-1}, l) = π_LL(a_{t:t+H} | o_t, s_t) · π_HL(s_t, m_t | o_t, m_{t-1}, l)
```

### 2.2 递归语言记忆机制

记忆 `m_t` 是一个结构化的自然语言摘要，包含：**已完成阶段（过去时）、完成证据、相关物体属性、观测到的失败、下一步待办里程碑**。其更新遵循**滚动压缩规则（rolling-compression）**：

- 子任务完成前：保留有助于识别目标的细节（类别、颜色、位置等）；
- 子任务完成后：将细节压缩为简短的过去时陈述，注意力转移到下一动作。

示例（收音机任务）：
- `m_t`：I am moving to the red radio on the coffee table.
- `m_{t+1}`：I moved to the radio, and I am going to pick up the red radio.

### 2.3 自动化记忆监督管线

- 输入：专家视频 + 技能级标注（技能名称、描述、起止时间戳）
- 流程：视频分帧 → 时间戳定位当前技能 → 通用VLM（Gemini 3.5 Flash API 或本地 Qwen3.5-9B）生成：
  1. 简洁子任务（动宾结构+上下文，无动作主体）
  2. 第一人称语言记忆（已完成技能用过去时，下一步用未来式）
- 输出：帧对齐的 `(m_t, s_t)` 监督目标

### 2.4 独立分支训练

- **高层**：基于PaliGemma，自回归预测更新的记忆和子任务，损失函数为负对数似然。
- **低层**：基于π0.5动作专家，采用流匹配（flow-matching）动作目标，均方误差损失。
- 两分支独立训练，**避免了在单一端到端目标中手动权衡语义生成与连续控制的损失权重**。

### 2.5 闭环推理流程

- 记忆初始化为空；每步循环执行：观测 → 更新记忆与子任务 → 生成动作块 → 执行 → 检查终止条件；记忆和子任务均为可见文本，可输出可解释的决策日志。

## 6. 论文的主要结论与发现

1. **显式语言记忆提升长时程任务成功率**：收音机任务平均成功率从30.0%提升至40.0%；单包裹分拣从41.7%提升至63.9%；连续分拣从31.3%提升至46.9%；真实机器人任务从62.5%提升至66.3%。
2. **提升阶段一致性**：记忆模型仅在观测到当前里程碑完成的证据后才推进阶段，减少了跳过步骤和过早推进。
3. **支持上下文内失败恢复**：记忆可将"抓取失败"作为文本上下文供后续预测使用，无需单独的恢复控制器。
4. **语义规划与运动控制的边界清晰**：语言记忆能解决"该做什么、当前处于哪一阶段"的问题，不能解决"如何精确执行接触丰富的动作"（如PressOn成功率仍很低）。
5. **可解释性**：记忆和子任务均为可读文本，可定位失败是高层的语义错误还是低层的控制错误。

## 7. 优点

- **简洁有效的记忆机制**：以自然语言作为历史状态载体，避免了拼接全部视觉历史的上下文与计算成本，具备紧凑性和可扩展性。
- **自动化监督管线**：将专家视频+技能标注转化为帧对齐的记忆/子任务目标，使分层训练可落地、可复现。
- **层级解耦设计**：高层语义决策与低层连续控制分离，各自有清晰的优化目标和损失函数，避免了端到端多目标平衡的困难。
- **可解释性强**：全过程决策日志可读，便于诊断、调试和用户信任。
- **验证场景多元**：涵盖基准仿真、高保真人形仿真和真实低成本机器人，并进行了sim-to-real迁移。
- **诚实的局限性分析**：论文明确指出的不足（语义记忆不解决运动控制问题）有助于建立合理的预期。

## 8. 不足与局限

### 8.1 实验覆盖不足

- **真实实验规模过小**：仅25条训练、20次评估，且任务只有4个阶段，无法验证"数分钟乃至十余分钟"的长时程真实任务表现。
- **无统计置信度**：未报告方差、置信区间或多随机种子结果，改进的稳健性缺乏数据支撑。
- **无消融研究**：无法量化各组件的贡献（如记忆粒度、更新频率、VLM选型）。
- **基线单一**：未与HAMLET、MemoryVLA、MAP-VLA等其他记忆增强方法对比，也未与原生π0.5之外的方法（如RT-2、OpenVLA）对比。

### 8.2 偏差风险

- 自动化标注VLM（Gemini 3.5 Flash / Qwen3.5-9B）生成的记忆质量直接影响高层训练，存在标注偏差风险，论文未分析标注质量对最终效果的影响。
- 分阶段成功率指标对各阶段等权平均，可能掩盖关键阶段（如PressOn）的严重失败。

### 8.3 应用限制

- **延迟增加**：每个决策循环需额外调用一次高层VLM，增加了端到端延迟和部署复杂度，不利于实时控制。
- **对低层控制能力无帮助**：在接触丰富、精度敏感的任务（如按钮按压）中，即使语义正确，动作执行仍可能失败。
- **失败恢复依赖数据**：鲁棒恢复需要覆盖多样失败与恢复轨迹的演示数据，论文仅初步验证，尚未系统化。
- **未来方向**：多模态记忆（语言+视觉+触觉/力反馈）有待探索，以解决纯视觉对接触状态判别模糊的问题。
