## 摘要
从人类视频中学习操作技能对于可扩展的机器人学习具有前景。然而，人类与机器人之间的具身差异使这一任务具有挑战性。一个有前景的解决方案是学习与具身无关的、以物体为中心的可操作可供性。在这项工作中，我们提出一个框架，利用自我中心人类视频，结合最先进的3D运动恢复结构和手部网格重建，提取视觉、抓取和轨迹等可操作可供性，这些可供性明确编码了在哪里交互、如何抓取以及如何移动。我们构建了EgoAffordance，一个大规模数据集，包含204K个片段，具有5.6M视觉可供性和11.6M抓取与轨迹可供性。在此基础上，我们引入VLAff，一个基于大型视觉-语言模型的统一基础模型，学习所有可操作可供性之间的跨模态相关性。给定视觉观察和指令，VLAff生成视觉可供性热图、抓取姿态和轨迹，然后利用3D场景信息将其转换为可直接执行的动作。通过大量实验，我们证明VLAff不仅在视觉可供性预测上达到了最先进的性能，而且还可以有效应用于真实机器人应用，如零样本操作和可供性引导的机器人学习。

## Abstract
Learning manipulation skills from human videos is promising for scalable robot learning. However, the embodiment mismatch between humans and robots makes this challenging. One promising solution is to learn object-centric actionable affordances that are embodiment-agnostic. In this work, we propose a framework that leverages egocentric human videos with state-of-the-art 3D Structure-from-Motion and hand mesh reconstruction to extract actionable affordances such as visual, grasp, and trajectory affordances that explicitly encode where to interact, how to grasp, and how to move. We construct EgoAffordance, a large-scale dataset comprising 204K episodes with 5.6M visual affordances and 11.6M grasp and trajectory affordances. Building on this, we introduce VLAff, a large vision-language model-based unified foundation model that learns cross-modal correlations across all actionable affordances. Given a visual observation and instruction, VLAff generates visual affordance heatmaps, grasp poses, and trajectories, which are then converted into directly executable actions by utilizing 3D scene information. Through extensive experiments, we demonstrate that VLAff not only achieves state-of-the-art performance on visual affordance prediction, but can also be effectively applied to real robot applications such as zero-shot manipulation and affordance-guided robot learning.

## 2. 论文提出的方法论

### 2.1 核心思想
- 提出 **VLAff（Vision-Language-Affordance model）**：基于大型视觉-语言模型（VLM）的统一基础模型，输入视觉观察与自然语言指令，同时输出三类互补的可操作可供性：
  - 视觉可供性热图 \(A_v \in \mathbb{R}^{H \times W}\)：指示场景中交互区域的概率分布；
  - 抓取姿态 \(A_g \in \mathbb{R}^{96}\)：MANO 手部参数（全局腕部旋转 + 15 个局部关节旋转，采用 6D 旋转表示）；
  - 轨迹 \(A_t \in \mathbb{R}^{T \times 6}\)：交互后手部的 3D 平移 + 3D 旋转轨迹序列。

### 2.2 可供性数据提取流程（EgoAffordance 数据集构建）
- **数据准备**：对自我中心视频数据集的片段进行采样，利用预训练 VLM 提取接触关键帧、动作标签、物体类别和交互手信息。
- **手-物交互提取**：
  - 使用手-物检测器获取手和物体的边界框；
  - 生成物体掩码并提取 2D 手部关键点；
  - 通过指尖关键点与物体掩码的交集确定接触区域；
  - 3D 手部重建提取 MANO 参数；
  - 进行自我分割与图像修复（inpainting），消除自我视角带来的视觉偏差。
- **自我中心 SfM（运动恢复结构）**：
  - 对修复后的帧进行单目深度估计；
  - 估计相机内参和相机位姿，并过滤动态区域；
  - 利用相机位姿和深度图，跟踪 3D 手部轨迹，捕获接触前后的运动模式。
- **以物体为中心的空间变换**：从视觉热图中找到峰值交互点，结合深度信息投影到 3D 获得锚点，再将抓取姿态和轨迹相对于该锚点进行变换，形成物体坐标系下的可供性表示，从而支持跨具身迁移。

### 2.3 VLAff 模型架构
- 基于预训练 VLM（Qwen2.5-VL），引入三类特殊 token：
  - `<SEG>` token：通过分割解码器生成像素级视觉可供性热图（参考 LISA 的设计）；
  - `<GRASP>` token：通过抓取解码器输出 96 维 MANO 参数；
  - `<p0>...<pN-1>` 轨迹 token：采用空间分箱（spatial binning）量化 6D 位姿空间，以自回归方式生成轨迹 token 序列。
- **双视觉编码器**：除 VLM 自带的视觉编码器外，额外集成 **DINOv2** 视觉编码器，提供细粒度的空间特征，弥补 VLM 在精确视觉接地任务上的不足。
- **轨迹推理策略**：
  - **上下文轨迹引导**：利用 GPT 等高性能 VLM 作为高层规划器，提供粗略的 3D 方向向量，约束首个轨迹 token 的采样分布；
  - **基于采样的轨迹选择**：通过 nucleus sampling 采样 K 个候选轨迹，结合碰撞检测（体素化场景）和方向对齐目标，选择最优轨迹。

### 2.4 训练目标
- 总损失为三部分加权和：\(L_{total} = \lambda_v L_{visual} + \lambda_g L_{grasp} + \lambda_t L_{traj}\)
- 视觉可供性使用 **Soft Dice Loss** 以应对热图预测中的类别不平衡；
- 抓取姿态使用 **Smooth L1 Loss**；
- 轨迹 token 使用 **交叉熵损失**（标准自回归语言建模目标）。

## 6. 主要结论与发现

- **视觉可供性预测达 SOTA**：VLAff 在 IoU（0.121）、NSS（1.542）、SIM（0.142）、KLD（2.517）四个指标上均优于 VRB、UAD、3DOI、LISA 等基线方法，生成的预测更细粒度、更自然。
- **性能优势来源**：DINOv2 的部件级视觉特征 + 大规模多样化 EgoAffordance 数据集 + 多模态联合学习的跨模态相关性。
- **零样本操作**：
  - 模拟环境平均成功率 83.0%，接近 VidBot 的 85.0%（VidBot 可利用深度空间输入）；
  - 真实环境平均成功率 68.0%（VidBot 为 52.0%），VLAff 显著领先 16 个百分点。这表明在真实世界的复杂操作场景中，基于大规模真实自我中心视频训练的可供性模型更具优势。
  - 失败案例主要源于轨迹生成中初始方向采样的错误。
- **可供性引导的操作学习**：
  - 完整模型学习效率最高；
  - **视觉热图是最关键的信号**——移除后模型完全无法学会任务；
  - 抓取姿态作用较小，原因是人类手部与机器人夹爪存在形态差异，手部精确构型难以直接迁移。

## 7. 优点

- **统一建模的创新性**：首次将视觉、抓取、轨迹三类可供性纳入单一 VLM 框架中联合学习，捕获跨模态相关性，而非像以往方法那样孤立处理单一模态。
- **大规模数据集贡献**：EgoAffordance 数据集规模显著，覆盖 20.4 万片段、578 万视觉热图、1161 万轨迹序列，为后续研究提供了宝贵资源。
- **完整的自动化数据提取管线**：结合 SfM、手部网格重建、分割修复和 3D 轨迹跟踪，从无标注的自我中心视频中大规模提取可操作可供性，技术栈先进。
- **“以物体为中心”的表示设计**：将可供性变换到物体坐标系，天然支持跨具身迁移，有效缓解人-机形态差异问题。
- **轨迹推理策略实用**：利用 VLM 高层推理提供方向引导 + 采样加碰撞检测的轨迹筛选，工程上解决了一定程度的物理合理性问题。
- **实验维度完整**：同时验证了感知质量（视觉评估）、直接迁移（零样本操作）和学习加速（可供性引导 RL）三个层面的有效性。
