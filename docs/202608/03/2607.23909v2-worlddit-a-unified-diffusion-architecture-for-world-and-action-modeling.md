## 摘要
许多最新的机器人策略尝试通过使用大型预训练视觉-语言模型（VLM）作为动作骨干来追求更强的控制能力。我们引入了WorldDiT，一种统一的扩散Transformer架构，它将动作生成与视觉世界建模相结合，并且在没有大型预训练VLM动作骨干的情况下实现了强大的性能。在训练过程中，一个单一的扩散Transformer生成连续的动作片段，并从未来的摄像头帧预测归一化的RGB图像块目标。在四个LIBERO仿真套件中，WorldDiT在报告所有四个套件的方法中，处于总模型参数和平均成功率所报告的帕累托前沿上。这些结果为未来的规模扩展研究提供了一个强大的十亿参数以下基线。

## Abstract
Many recent robot policies pursue stronger control by using large pretrained vision-language models (VLMs) as the action backbone. We introduce WorldDiT, a unified diffusion transformer architecture that couples action generation with visual world modeling and achieves strong performance without a large pretrained VLM action backbone. During training, a single diffusion transformer generates continuous action chunks and predicts normalized RGB patch targets from future camera frames. Across four LIBERO simulation suites, WorldDiT lies on the reported Pareto frontier for total model parameters and mean success among methods reporting all four suites. These results provide a strong sub-billion-parameter baseline for future scaling studies.

## 2. 方法论：核心思想、关键技术与算法流程

### 2.1 核心思想
- **统一扩散骨干**：采用**一个共享的 DiT（Diffusion Transformer）骨干**，同时建模两类目标——**连续机器人动作块**（action chunk）与**未来相机帧的归一化RGB补丁**（normalized RGB patch target）。
- **训练-推理不对称**：在训练时引入未来视觉预测作为**辅助监督信号**，而在推理时仅保留动作生成路径，**丢弃视觉预测头**，不增加部署开销。
- **无需大型VLM骨干**：不将预训练VLM作为动作生成的主干，而是使用**冻结的视觉/语言编码器**（MAE、CLIP文本编码器）与**可训练的机器人状态编码器**来构建条件信息。

### 2.2 关键技术细节
1. **输入表示与轨迹窗口**：
   - 轨迹段定义为 \( W_u = \{(o_i, s_i, a_i)\}_{i=u}^{u+N-1} \)，其中 \( o_i = [I_i^p, I_i^w] \) 为主相机 + 腕部相机图像，\( s_i \) 为机器人状态，\( a_i \in \mathbb{R}^{d_a} \) 为动作。
   - 采用**C步观测上下文**（C = 3），预测**H步动作块**（H = 7）；完整窗口长度 N = 10。
   - 未来RGB补丁目标来自**时间偏移 H 之后**（即步骤 \( i+H \)）的主相机与腕部相机帧。

2. **RGB补丁目标构造**：
   - 每帧经 CLIP 预处理为 224×224，划分为 16×16 补丁，每个补丁为 768 维向量。
   - 每个补丁向量按**自身均值与方差归一化**，每个相机保留 **64 个等间距补丁**。
   - 双相机拼接后得到 \( Y_{rgb} \in \mathbb{R}^{128 \times 768} \)，仅对**最终时间槽**计算损失。

3. **动作与状态编码**：
   - 动作/补丁通过**可训练的线性输入投影**映射到骨干隐藏维度。
   - 机器人状态的手臂与夹爪组件分别编码、拼接后再投影为每个时间槽的**单一状态token**。
   - 条件信息由冻结的 MAE 图像编码器、共享 Perceiver Resampler、冻结 CLIP 文本编码器和可训练机器人状态编码器共同生成。

4. **流匹配（Flow Matching）训练目标**：
   - 定义插值路径：\( x_\tau = (1-\tau)\epsilon + \tau y \)，\( \tau \sim U[0,1] \)。
   - 流匹配损失：\( \mathcal{L}_{\text{flow}} = \mathbb{E}[\|v_\theta(x_\tau, \tau, c) - (y - \epsilon)\|_2^2] \)。
   - **总损失**为动作流损失与RGB补丁流损失的加权和：\( \mathcal{L}_{\text{total}} = w_{\text{action}} \mathcal{L}_{\text{action}}^{\text{flow}} + w_{\text{rgb}} \mathcal{L}_{\text{rgb}}^{\text{flow}} \)，权重分别为 0.1 与 0.001。

5. **推理流程**：
   - 从高斯噪声初始化动作块 \( x_{t,0}^{\text{act}} \sim \mathcal{N}(0, I) \)。
   - 通过 **20 步欧拉积分**求解动作速度场，得到预测动作块 \( \hat{A}_t \)。
   - **执行前3个动作**，滑动上下文窗口，重新规划（receding-horizon control）。

### 2.3 模型规模
- 骨干配置：深度 4，隐藏维度 1024，16 个注意力头，4 个寄存器token（register tokens）。
- **总参数 399.084M**（含推理必需的冻结模块），**可训练参数 135.107M**。

## 6. 主要结论与发现

1. **统一架构可行性**：一个单一的扩散 Transformer 可以同时学习连续动作生成与未来视觉补丁预测，且在**推理时不依赖视觉预测分支**也能保持强控制性能。
2. **无需大型VLM骨干**：WorldDiT 在总参数 399M（可训练参数仅 135M）的条件下达到 94.9% 的平均成功率，处于所报告对比的**参数-成功率帕累托前沿**。
3. **长时任务仍具挑战**：LIBERO Long 套件成功率最低（91.8%），与需要多阶段扩展行为的任务难度一致。
4. **基线价值**：作为亚十亿参数的强基线，为后续扩展研究（模型规模、数据多样性、部署场景）提供了参考点。

## 7. 方法亮点与优点

- **架构统一性**：动作与视觉预测共享同一骨干和同一流匹配框架，设计简洁、优雅，避免了额外的世界模型模块或自回归动作解码器。
- **训练-推理不对称设计**：视觉预测仅提供训练监督，推理时零额外开销，实现了“免费”的表示学习信号。
- **高参数效率**：可训练参数仅 135M，总参数 399M，显著低于依赖数十亿参数 VLM 的方法，同时保持有竞争力的性能。
- **诚实评估声明**：作者明确披露了评估协议中非严格 held-out 的部分（300/500 回合用于 checkpoint 选择），这种透明度值得肯定。
- **对社区的价值**：为“世界模型 + 动作策略”这一方向提供了一个紧凑、可复现的基线和清晰的扩展路径（包括未来可分解为独立专家模型的潜力，呼应 Paris / Paris 2.0 的方向）。

## 8. 不足与局限

- **缺乏消融实验**：未单独验证未来 RGB 补丁预测对动作性能的因果贡献，核心设计选择（如损失权重、目标格式、补丁采样策略）缺少敏感性分析。
- **评估偏差风险**：所报成功率包含用于模型选择的 300 回合，并非完全不可见测试集结果；作者自己也指出不应将 94.9% 视为无偏估计。
- **单一模拟基准**：仅评估 LIBERO，缺少真实机器人平台、其他操作基准或开放世界场景的验证。
- **对比公平性受限**：不同方法的训练数据、协议与实现细节存在差异，且无法完全复现所有对比方法，帕累托前沿结论依赖于引用报告的可比性。
- **扩展性证据不足**：仅测试一个配置，未展示模型规模或数据规模变化时的行为趋势，因此文章结论不能直接外推至更大规模或更复杂场景。
- **代码与权重公开不完整**：文中提到“不完全公开可用性”限制了复现与第三方验证。
- **潜在应用限制**：连续动作流 + 辅助视觉预测的联合训练对计算资源的实际需求（8×RTX Pro 6000、大 batch 512）仍非所有研究团队可承受；且未涉及真实硬件部署中的延迟与稳定性问题。
