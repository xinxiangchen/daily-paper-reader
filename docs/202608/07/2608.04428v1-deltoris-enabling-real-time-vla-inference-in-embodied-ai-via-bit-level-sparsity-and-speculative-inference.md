## 摘要
视觉-语言-动作（VLA）模型已成为具身AI中的关键组成部分。在现有方法中，基于扩散的VLA模型实现了优越的运动质量和泛化能力。然而，基于扩散的VLA模型计算密集，且必须以高控制频率（例如50-200 Hz）运行。因此，这对边缘设备施加了严格的延迟和能量约束。在这项工作中，我们提出了Deltoris，一种用于高效基于扩散的VLA推理的算法-硬件协同设计框架。首先，我们利用连续输入的时间相似性，提出了一种	extit{时间感知的位稀疏性}算法，该算法仅计算连续输入之间的差异，消除了冗余的位级操作。为了进一步解决我们算法引入的额外片外流量，我们提出了一种	extit{推测性推理}技术，该技术将数据加载分摊到多个控制步骤中。最后，为了支持这些技术，我们协同设计了一个专用的加速器，采用定制的1D脉动位串行PE阵列，消除了PE工作负载不平衡。我们的评估表明，Deltoris相比移动GPU实现了高达34.2$	imes$的加速，相比先前加速器实现了6.1$	imes$的加速，同时保持了相当的准确性。

## Abstract
Vision-language-action (VLA) models have emerged as a key component in embodied AI. Among existing approaches, diffusion-based VLA models achieve superior motion quality and generalization. However, diffusion-based VLA models are compute-intensive and must run at high control frequency, e.g., 50-200 Hz. Thus, it imposes strict latency and energy constraints on edge devices.   In this work, we present Deltoris, an algorithm-hardware co-design framework for efficient diffusion-based VLA inference. First, we exploit the temporal similarity of consecutive inputs and propose a \textit{temporal-aware bit-sparsity} algorithm that computes only the differences between consecutive inputs, eliminating redundant bit-level operations. To further address the extra off-chip traffic introduced by our algorithm, we propose a \textit{speculative inference} technique, which amortizes data loading across multiple control steps. Lastly, to support these techniques, we co-design a dedicated accelerator with customized 1D systolic bit-serial PE arrays that eliminate PE workload imbalance. Our evaluation shows that Deltoris achieves up to 34.2$\times$ speedup over mobile GPUs and 6.1$\times$ over prior accelerators, while maintaining comparable accuracy.

  2. **连续控制步之间存在强时间相似性**：机器人以高频控制运行时，相邻控制步的传感器输入高度相似。在PushT数据集中，**超过98.5%的像素在连续帧间保持不变**，平均像素值差异仅为1.3，这是巨大的计算冗余来源。
- **整体意义**：Deltoris是面向扩散式VLA模型的**首个算法–硬件协同设计**框架，尝试利用控制环路固有的时间冗余，从根本上减少冗余计算和片外数据流量，为边缘端实时VLA推理铺平道路。

## 2. 论文提出的方法论：核心思想、关键技术细节

### 2.1 核心思想

Deltoris的核心理念是：既然相邻控制步的输入高度相似，就不必每步都做全量推理，只需计算输入的**差异**并更新上一帧的缓存结果，从而大幅削减计算量。

### 2.2 技术一：时序感知位稀疏算法（Temporal-Aware Bit-Level Sparsity）

- **基本思想**：将线性投影 `y_t = W x_t` 改写为差分形式：
  - `y_t = y_{t-1} + W · Δx_t`，其中 `Δx_t = x_t − x_{t-1}`
- **位级稀疏执行**：对差分激活 `Δx_t` 采用**符号-数值（sign-magnitude）二进制表示**（而非二进制补码），仅对值为"1"的有效位执行乘法累加运算，跳过所有"0"位：
  - `W·Δx_t = (−1)^s × Σ W × v_{t,b} × 2^b`，仅处理 `v_{t,b} = 1` 的位。
- **效果**：相比仅利用权重稀疏性（约跳过50%计算），时间感知的位稀疏性可达到**超过90%的位级稀疏度**，最高实现92.9%的操作数削减。
- **适用范围**：输入投影、MLP投影、Q/K/V投影、交叉注意力投影、输出投影等线性算子均可应用。
- **设计抉择**：
  - **选择帧间相似性而非去噪步间相似性**：帧间相似性带来更高的位稀疏度，且对未来的扩散模型蒸馏趋势（减少去噪步数）更具鲁棒性；两者正交可叠加。
  - **自注意力的简化处理**：由于Q和K均随输入变化，差分展开（`Q_t K_t^T = Q_{t−1}K_{t−1}^T + ΔQ_t K_{t−1}^T + Q_t ΔK_t^T`）效率低下，因此自注意力仅使用传统位稀疏（跳过零位），不做时序差分。由于自注意力仅占执行时间的约5.9%，此简化对整体性能影响很小。

### 2.3 技术二：推测推理（Speculative Inference）

- **解决的问题**：差分计算虽削减了算术操作，但引入额外片外数据流量——非线性操作前后需要反复恢复和缓存全值中间激活，使数据流量增加约1.8倍，工作负载从计算受限转为内存受限。
- **实现流程**：
  1. **候选生成**：轻量级小VLA模型（使用原模型的1/5去噪计算量，无需单独训练）递归预测未来k步的观测与状态，生成推测轨迹。
  2. **批式验证**：大VLA模型一次性批量验证多个推测候选；模型权重只需加载一次即可用于所有候选帧，输入激活也可被多帧共同重用，从而**摊销全片外数据加载成本**。
  3. **接受/丢弃策略**：逐帧对比大模型验证输出与小模型预测，若误差 `ΔS = |S − S′|` 低于阈值 `θ_th = 0.01` 则接受；否则丢弃当前及后续候选，从当前帧重新开始推测。
- **关键保障**：推测候选在验证通过前**不会作用于机器人**，保证安全性。

### 2.4 技术三：定制加速器架构

- **1D脉动位串行PE阵列**：
  - 采用**输出固定（output-stationary）数据流**，稀疏激活位流经阵列，部分积留在PE寄存器中。
  - 所有PE共享同一控制信号（`read` 和 `sign`），由**调度器**统一派遣稀疏位并确定移位量、权重读取和加减控制，**消除了传统位串行加速器常见的负载不均衡问题**。
- **权重共享**：每M=16行PE阵列共享一次SRAM权重读取，减少片上SRAM访问流量。
- **编码器/解码器**：混合压缩方案——首帧和权重用向量量化（VQ），后续帧用CSR稀疏格式编码，进一步降低片外数据量；与计算/取数流水线重叠，不增加延迟。

## 6. 论文的主要结论与发现

- **实时性突破**：Deltoris相比移动GPU实现**最高34.2倍加速**（各基准具体为34.8×/46.1×/24.4×/31.5×），相比先前专用加速器（Pragmatic、BBS、Cambricon-D、Exion、Ditto）分别提升**4.6×/3.2×/6.1×/4.3×/3.3×**。

- **计算量削减**：平均约**93%的操作数减少**，主要来自时间感知位稀疏算法。
- **精度保持**：时间感知位稀疏本身**逐位精确**；结合推测推理后，平均精度损失仅**约0.2%**，而简单使用小模型替代则造成超过7.7%的精度损失，验证了推测推理的必要性和有效性。
- **关键技术归因**：时间感知位稀疏是计算削减的主力；推测推理缓解了内存瓶颈——将Base+Temp的片外流量显著降低，实现3.5×额外加速；压缩编码进一步补充优化。

## 7. 优点

- **算法–硬件深度协同**：三项核心技术（位稀疏算法、推测推理、专用PE阵列架构）环环相扣、互为支撑，不是简单的架构堆叠，而是针对具体瓶颈逐一击破。
- **新颖的优化维度**：跳出传统的权重稀疏和步级相似性，首次系统性地挖掘控制帧间的时间冗余，且论证了该方法的鲁棒性和长远价值（相比步级相似性更抗蒸馏趋势）。
- **硬件设计巧妙**：
  - 1D脉动位串行PE阵列配合统一的调度器信号，**从根本上消除位串行加速器最常见的负载不均衡问题**；
  - 输出固定数据流结合权重共享，有效降低片上SRAM访问；
  - 编码器/解码器的混合压缩方案进一步压制片外流量。
- **零成本蒸馏方案**：小模型采用训练无关的蒸馏（减少去噪步数），避免训练开销，使推测推理落地更便捷。
- **评估严谨**：RTL实现、cycle-accurate模拟器、统一工艺节点归一化、统一的吞吐和缓存配置，提升了对比公平性。

## 8. 不足与局限

- **自注意力处理受限**：时间感知位稀疏无法有效扩展到自注意力模块，仅退回传统权重位稀疏。虽然自注意力占比小，但随着VLA模型规模增大或架构变化，这一限制可能更加明显。
- **推测窗口的精度–性能权衡**：推测窗口增大会导致接受率下降和精度轻微降低，窗口过大反而降低加速比。系统需要在运行前选定窗口大小，缺乏自适应调节机制。
- **快速运动场景下的退化**：当运动速度增大导致帧间相似性减弱时，Deltoris的精度和加速比均会下降。虽然2×加速场景仍保持鲁棒，但更高速度（如4×）下的表现未充分展示。
- **阈值敏感性**：推测阈值θ_th是经验设定的（0.01），并需要预设"小模型预测误差可阈值化比较"这一条件。不同机器人平台或任务可能对阈值更敏感，论文对此的讨论较有限。
- **数据集的局限**：评估使用的PushT、Meta-World、LIBERO均为仿真或桌面级操作任务，未在真实物理机器人平台上验证。
- **模型规模的局限**：评估的PAD、DP、UVA均为中等规模模型；近年来大规模VLA（数十亿参数级别）的适用性尚未验证，其权重加载和内存压力可能改变现有瓶颈分布。
- **未报告训练资源**：论文未说明原始模型的训练资源、训练时长或微调成本，这在可复现性方面稍显不足。
- **硬件验证深度**：虽然做了RTL综合和布局布线，但未进行流片验证；加速器的实际硅片性能、功耗与模拟结果之间可能存在偏差。
