## 摘要
最近的视觉-语言-动作（VLA）模型几乎普遍将机器人本体感觉状态作为输入，但以不兼容的方式接入——序列化为文本提示、投影到视觉-语言前缀中，或直接馈送给动作专家——且几乎总是作为单帧当前状态。三个问题仍然悬而未决：（1）当前状态是否以及在哪类任务上真正改善了闭环控制；（2）状态历史有多大帮助，其收益是否反映了真实的时间变化而非额外的条件化容量；（3）状态应进入模型何处——视觉-语言骨干还是动作生成模块。我们通过在流匹配VLA上进行受控实验来回答这些问题，全程固定骨干网络、训练数据、动作表示和评估协议。我们在匹配的实现细节下实现了五种代表性接口——离散状态提示、VLM前缀、动作前缀、状态专家和特征调制——并在涵盖三个任务族共45个原子任务及20个复合任务上进行了评估；随后我们扫查了状态历史长度从1帧到96帧，以考察历史状态信息如何影响模型性能。实验为所有三个问题提供了系统性的答案，并凝练为可测试的、针对状态感知VLA的设计原则。

## Abstract
Recent Vision-Language-Action (VLA) models almost universally take robot proprioceptive state as input, yet wire it in incompatible ways -- serialized into text prompts, projected into the vision-language prefix, or fed directly to the action expert -- and almost always as a single current frame. Three questions remain open: (1) whether, and on which tasks, current state actually improves closed-loop control; (2) how much state history helps, and whether its benefit reflects genuine temporal variation rather than added conditioning capacity; and (3) where state should enter the model -- the vision-language backbone or the action-generation module. We answer these questions through controlled experiments on a flow-matching VLA, fixing the backbone, training data, action representation, and evaluation protocol throughout. We implement five representative interfaces -- discrete state prompt, VLM prefix, action prefix, state expert, and feature modulation -- under matched implementation details, and evaluate them on 45 atomic tasks spanning three task families plus 20 composite tasks; we then sweep the state-history length from 1 to 96 frames to examine how historical state information affects model performance. The experiments yield systematic answers to all three questions, distilled into testable design principles for state-aware VLAs.

### 1. 核心问题与整体含义（研究动机与背景）

- **问题背景**：近来的视觉-语言-动作（VLA）模型几乎都将机器人本体感觉状态（关节角、末端执行器位姿、夹爪开度等）作为输入，但接入方式高度不统一——有的离散化为文本标记，有的投影为连续嵌入，有的直接送入动作专家；且绝大多数仅使用单帧当前状态。
- **核心开放问题**：（1）当前状态是否真正提升闭环控制，在何种任务上有效？（2）状态历史有多大帮助，其收益源自真实时间变化还是额外的条件化容量？（3）状态应注入模型何处——视觉-语言骨干还是动作生成模块？
- **研究意义**：视觉与语言已在VLM中大规模预训练，而本体感觉缺少对应预训练，是VLA中最不受审视的输入。既有研究因骨干网络、数据、协议各不相同而互不可比，本文首次在完全受控条件下系统性回答这三个问题，为状态感知VLA的设计提供可测试的设计原则。

### 2. 方法论

- **核心思想**：以流匹配VLA（π0.5）为统一测试平台，固定骨干网络、训练数据、动作表示、优化配方与评估协议，只改变状态的设计（表示方式、历史长度、注入位置），由此将性能差异全部归因于状态设计本身。
- **状态表示**：每帧状态为16维向量（末端执行器位置+四元数、移动基座位置+四元数、两个夹爪关节位置）。连续接口通过两层投影器逐帧编码为连续状态标记：$h_i = \phi_2(\text{Swish}(\phi_1(s_i)))$，维度对齐宿主管道的隐藏宽度。
- **五种状态接口**：
  - **离散状态提示（sp）**：将当前状态量化为256个bin并序列化为约66个文本标记，加入语言提示。无新增可训练参数，仅支持单帧。
  - **VLM前缀（vp）**：状态标记插入双向VLM前缀（图像与语言标记之后），参与多模态上下文建模，间接影响动作生成。
  - **动作前缀（ap）**：状态标记放入因果动作后缀、位于噪声动作标记之前，在每个去噪步直接参与速度场预测（从状态到动作最直接的路径）。
  - **状态专家（se）**：为状态单独建立专用Transformer流，与动作模块在生成过程中交换信息，容量最大（新增约199M参数）。
  - **特征调制（fm）**：状态作为条件记忆，动作专家每一层通过交叉注意力读取并预测逐特征缩放γ与平移β来调制动作特征：$\text{Mod}(z; S) = (1+\gamma(z, S)) \odot z + \beta(z, S)$。
- **状态历史控制**：从1帧扫到96帧，并对每个历史模型配备同插槽数、反复当前帧的对照组，以分离时间内容收益与额外容量收益。

### 3. 实验设计

- **基准环境**：RoboCasa365模拟平台（基于RoboCasa），包含多样厨房场景、机器人初始配置、物体实例。每个任务使用三视角视觉观测（左外部相机、右外部相机、腕部相机）。
- **原子基准**：45个原子任务，按操作语义预分为三个任务族：A（重排/抓放，15个）、B（关节物体交互，15个）、C（旋钮/开关精确控制，15个）。每个任务族训练独立类别专家，每任务50次闭环rollout评估，固定任务列表与种子计划。
- **复合基准**：采用`lifelong_learning_phase2`设置，20种任务类型，每种串联2-3个原子子目标。每个接口联合训练一个策略，每任务25次闭环rollout。除默认的末端执行器位姿状态外，还在相同协议下用关节角状态重复关键对比。
- **对比方法**：无状态基线 vs 五种状态接口（sp、vp、ap、se、fm）；历史长度1/4/8/16/32/48/64/96帧。辅助实验包括固定检查点探针（状态开/关对比）、PrepareToast配对案例研究。
- **评估指标**：闭环任务成功率（SR）。配对任务bootstrap 95%置信区间报告统计不确定性。

### 5. 实验数量与充分性

- **实验规模**：原子45个任务×（无状态+5接口）×（K=1和K=8等历史档位）均有独立训练系统；历史深度扫描覆盖9个档位（1/4/8/16/32/48/64/96帧），涉及ap、vp、se、fm四种连续接口；复合20任务对比两种状态表示（EEF姿态、关节角）；另有45任务×4上下文的固定检查点探针、PrepareToast案例研究（50个配对episode种子）。

- **客观性与公平性**：固定种子、固定任务列表与种子计划、共享优化配方保证了比较公平。但作者坦承大部分点估计为单训练种子，历史深度扫描为探索性分析未做多重性校正，因此微观排序不宜过度解读。

### 6. 主要结论与发现

- **RQ1（当前状态是否有用）**：单帧状态总体上带来收益——sp增益+3.1点为唯一置信区间排除零的结果（57.7% vs 无状态54.6%）。但不存在任务无关的最优接口：族A（重排）sp最优（+7.0），族B（关节）vp最优（+6.1），族C（精确控制）se最优（+3.3）而vp反而退化（-1.2）。
- **RQ2（状态历史是否有用）**：短历史（约8帧）提供稳定收益，长原始历史（≥32帧）无益甚至有害，族C（精密控制）退化最明显。8帧为实际推荐操作点。插槽匹配的“重复当前帧”对照显著低于真正排序的历史，证明收益来自真实时间变化而非额外条件化容量。该结论在EEF姿态与关节角两种状态下均稳健。
- **RQ3（状态应注入何处）**：路由偏好随时间预算切换——单帧时VLM侧占优（vp₁ 34.4% vs ap₁ 28.2%于复合任务），短历史（K=8）时动作侧逆转并大幅领先（ap₈ 39.0% vs vp₈ 33.8%）。端到端设计规则：**单帧注入VLM前缀，短历史路由到动作专家**。
- **计算成本洞察**：sp性能最好但训练代价高出两个数量级；se/fm接近相同性能仅需零头计算量。

### 7. 优点

- **严格受控的实验方法论**：首次在统一框架下隔离状态设计变量，排除了骨干、预训练、数据、协议等混淆因素，归因干净可信。
- **插槽匹配思想**：用“重复当前帧”对照把“时间变化的收益”与“额外条件化容量”分离，是对行为克隆中历史捷径问题的重要方法论贡献。
- **任务族预划分**：按控制语义（而非性能后验）划分任务族，揭示接口间的排名逆转，避免了单一宏观均值的误导。
- **多维度三角验证**：系统级对比（独立训练）、固定检查点探针（数据流追踪）、配对案例研究（里程碑分析）三层证据互为补充，结论稳健。
- **理论计算核算**：区分标记计数、参数量与语义算术，为状态接口的可扩展性评估提供了可复用的分析框架。

### 8. 不足与局限

- **缺乏真实机器人验证**：所有实验均在RoboCasa365仿真中完成，未验证从仿真到真实的迁移。
- **状态模态有限**：仅包含运动学状态（关节角/位姿/夹爪），未纳入力/力矩、触觉等更丰富的本体觉模态，结论对“本体感觉”一般性的外推受限。
- **统计强度有限**：大部分结论为单种子点估计；历史深度扫描未作多重性校正；“se/fm因硬件曝光略低”引入了轻微的不公平因素。
- **路由规则的适用范围受限**：作者明确表示路由交叉规律为方向性模式而非因果机制，且在关节角状态下K=8时ap/vp差异落入噪声带，说明该规则可能不具极端通用性。
- **状态定义含混**：基座位姿携带世界坐标系定位信息，故“本体感觉”效应无法被纯粹解读为内部运动反馈。
- **潜在发布偏差**：多数接口增益的置信区间包含零，可能暗示统计功效不足；若效果更弱的设计存在但未发表，领域结论可能有系统性偏乐观。
