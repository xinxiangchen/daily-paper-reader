## 摘要
具身智能既需要长时程推理，也需要实时闭环响应。最近的双系统视觉-语言-动作（VLA）架构结合了快速反应控制与慢速深思推理，以平衡推理速度与任务成功率。然而，现有的双过程VLA将快速模块与慢速模块的中间表示紧密耦合，需要端到端联合训练，限制了模块化、可扩展性和灵活的系统切换。在本文中，我们提出环境感知模型选择（EMS），一种自适应VLA推理框架，通过环境感知模型选择在两个完全解耦的不同规模系统之间切换。大规模深思系统提供全局一致的轨迹规划以确保任务成功，而轻量级反应系统则实现高频闭环控制。基于强化学习的切换策略根据实时反馈动态选择调用哪个系统，从而实现对慢速系统的稀疏使用，并因此在预训练知识利用与运行时效率之间取得平衡。与先前的层级VLA框架相比，我们的设计具有三个关键优势：（1）完全解耦且模块化的双系统架构，支持即插即用的模型替换；（2）自适应的环境感知切换策略；（3）用于响应式闭环控制的高频推理。我们在仿真和真实环境中广泛评估了EMS。在LIBERO基准上，EMS在达到与大规模基线相当的成功率的同时，将有效动作频率提高到93.4 Hz。该框架在真实世界的双臂操作任务中进一步展现出强大的可扩展性，在保持稳健性能的同时加速了任务完成。

## Abstract
Embodied intelligence demands both long-horizon reasoning and real-time closed-loop responsiveness. Recent dual-system Vision-Language-Action (VLA) architectures combine fast reactive control with slow deliberative reasoning to balance inference speed and task success rate. However, existing dual-process VLAs tightly couple the fast module to intermediate representations of the slow module, necessitating end-to-end joint training and limiting modularity, extensibility and flexible system switching. In this paper, we propose Environment-aware Model Selection (EMS), an adaptive VLA inference framework that switches between two fully decoupled systems of different scales through environment-aware model selection. The large-scale deliberative system provides globally consistent trajectory planning to ensure task success, while a lightweight reactive system enables high-frequency closed-loop control. A reinforcement-learning-based switching policy dynamically selects which system to invoke based on real-time feedback, enabling sparse use of the slow system and thereby balancing pretrained knowledge utilisation with runtime efficiency. Our design offers three key advantages over prior hierarchical VLA frameworks: (1) a fully decoupled and modular dual-system architecture that supports plug-and-play model replacement; (2) an adaptive, environment-aware switching strategy; (3) high-frequency inference for responsive closed-loop control. We extensively evaluate EMS in both simulation and real-world environments. On the LIBERO benchmark, EMS achieves success rates comparable to the large-scale baseline while increasing the effective action frequency to 93.4 Hz. The framework further demonstrates strong extensibility in real-world dual-arm manipulation tasks, where it accelerates task completion while maintaining robust performance.

## 1. 核心问题与整体含义

- **研究动机**：具身智能（Embodied AI）需要同时满足长时程推理（如任务规划、空间理解）与实时闭环控制（如高频反馈、动态响应）的需求。大型 VLA 模型（如 RT-2、OpenVLA、PI0）具备强大的语义先验和推理能力，但推理延迟高（通常仅 1–10 Hz），难以胜任接触丰富、动态变化场景中的实时控制。虽然动作分块（action chunking）能提高有效动作频率，但会降低重规划频率，削弱对突发反馈的响应能力。
- **现有局限**：已有的双系统（fast–slow）VLA 架构（如 DP-VLA、FiS-VLA）通常在慢速系统的中间表示（特征层）上耦合快速系统，导致两者必须端到端联合训练，无法独立部署、升级或灵活切换，且快速模块的推理仍受制于大模型的骨干网络。
- **核心问题**：如何构建一个双系统 VLA，既能支持即插即用的模块化升级（避免昂贵的联合重训练），又能根据实时环境反馈动态选择恰当的计算层级，实现高频闭环控制与任务成功率之间的平衡？

## 2. 方法论

### 核心思想
- 提出 **EMS（Environment-aware Model Selection）** 框架：构建两个**完全解耦**的策略系统（大规模慢速系统 System 2 与轻量级快速系统 System 1），两者仅通过**动作层**交互，不使用中间特征共享；由轻量级切换模块基于实时机器人状态动态选择调用哪个系统。

### 系统构成
- **System 2（慢速深思系统）**：大型预训练 VLA 模型（如 PI0），生成动作块（action chunk），为全局轨迹提供规划，运行频率约 10 Hz。
- **System 1（快速反应系统）**：轻量级反应式策略（如 BCVILT、ACT），支持端到端独立推理，单步频率约 100 Hz，负责高频闭环控制。
- **切换模块**：轻量级网络（如多层全连接网络），输入为机器人状态 \(s_t\)（不含完整多模态观测），输出二值选择动作 \(\hat{a}_t \in \{0,1\}\)（0 选快速，1 选慢速），开销可忽略。

### 问题形式化
- 将系统选择建模为**二元动作马尔可夫决策过程（MDP）**：状态为机器人状态 \(s_t\)，动作 \(\hat{a}_t\) 为系统选择，奖励为任务成功/失败的稀疏奖励（均匀分配到每个时间步）。
- 优化目标：最大化任务成功率，同时抑制不必要的慢系统调用。

### 训练流程（三阶段）
1. **Stage I：System 2 微调**——在遥操作轨迹 \(D_{\text{tele}}\) 上通过模仿学习微调预训练大模型，保留预训练先验并适配目标任务。
2. **Stage II：System 1 蒸馏**——使用微调后的 System 2 生成成功轨迹 \(D_{\text{distill}}\)，用模仿学习从零训练 System 1，使其行为分布与 System 2 对齐，减少切换时的轨迹不连续。
3. **Stage III：切换模块训练**——采用强化学习训练切换策略：
   - **在线训练**：使用增强 DQN（双 Q 学习、优先经验回放、Dueling 网络、NoisyNet）在真实交互中实时更新。
   - **离线训练**（用于真实场景）：采用 IQL（隐式 Q 学习），通过期望回归和优势加权行为克隆学习离线切换策略。

### 切换执行流程
- 每个决策边界处，切换模块选择系统 → 被选策略生成动作（单步或动作块）→ 执行完当前动作序列后进入下一个决策边界。
- **动作融合**：在切换时刻，将快慢系统各自的一个动作取平均（公式 \(a_t = (a^{\text{fast}}_t + a^{\text{slow}}_t)/2\)），以减小控制不连续性。

## 6. 主要结论与发现

- **仿真（LIBERO）**：EMS 平均成功率 92.40%，高于 BCVILT（70.85%）、OpenVLA（76.50%）、BCTransformer（70.85%）和 Fixed Switching（90.35%），接近 PI0（94.15%）；同时有效动作频率达 93.37 Hz，显著高于 PI0（50 Hz）和 OpenVLA（6.3 Hz）；切换比仅 0.153，远低于固定切换的 0.33。
- **切换行为分析**：慢系统被稀疏但关键地调用——在初始规划、精细操作（抓取）、任务阶段过渡、错误纠正时被激活，证明切换策略是环境感知的、任务相关的。
- **消融**：蒸馏轨迹训练 System 1 优于遥操作轨迹训练（平均成功率提升 4.80%）；先遥操作后蒸馏的初始化并未带来明显改进；动作融合在长时程任务（LIBERO-10）上带来 3% 的提升。
- **Realman 仿真**：简单单臂任务中 EMS 成功率超过 System 2；困难任务中 EMS 接近 System 2，但通过增加慢系统调用实现。双臂模拟中 EMS 成功率超越 System 2。
- **真实世界**：System 2（PI0）成功率 100%，System 1（ACT）成功率 60%，EMS 成功率 70%（主要受快速系统在右臂上的偏差影响）；任务完成时间从 29 秒缩短至 23 秒，而单独使用 System 1 虽然理论更快（18 秒），但因轨迹质量差常需重新规划，实际执行时间反而更长（30 秒以上）。

## 7. 优点

- **模块化与解耦**：快慢系统仅在动作层交互，支持独立训练、部署、升级，避免了昂贵的联合重训练，具有即插即用特性。
- **自适应切换**：强化学习切换策略基于实时状态动态选择系统，非固定调度，能根据任务状态（如关键动作、阶段变化、错误检测）智能调用慢系统，实现稀疏但精准的干预。
- **效率与性能兼得**：有效动作频率高达 93.4 Hz，同时成功率与大规模慢系统相当，在简单任务中甚至超过慢系统。
- **可扩展性**：在单臂、双臂、不同快速策略（BCVILT、ACT）、不同机器人平台（Franka、Realman）上均验证了框架的通用性。
- **工程细节完善**：离线/在线强化学习结合（DQN/IQL）、动作融合、优先级经验回放等技巧增强了实用性。

## 8. 不足与局限

- **切换决策的输入受限**：切换模块仅使用机器人状态 \(s_t\)，未利用视觉或语言信息，可能无法捕捉需要视觉语义识别的关键决策时机（例如视觉目标变化、复杂场景理解）。
- **依赖 System 2 的轨迹质量**：System 1 完全从 System 2 的蒸馏轨迹学习，若 System 2 在某任务上本身性能不佳，System 1 也可能继承其错误模式。
- **真实世界性能与快速系统强相关**：在真实双臂场景中，EMS 成功率（70%）显著低于 System 2（100%），说明快速系统的性能上限制约了整体框架的表现；切换策略在真实环境中并未完全弥补快系统的不足。
- **实验统计强度不足**：真实实验仅有 10 次测试，且未报告方差或置信区间；仿真实验未提供多次运行的标准差，难以评估性能的稳定性。
- **与最新双系统方法的直接对比缺失**：未与 DP-VLA、FiS-VLA 等现有双系统方法做同条件比较，仅与简单的固定切换基线对比，削弱了“优于现有技术”的说服力。
- **算力信息不透明**：未说明训练所需的 GPU 数量、型号、时长，难以评估框架的资源成本与可复现性。
- **任务范围有限**：主要聚焦于桌面操作（抓取、放置、堆叠），未涉及移动操作、长距离导航、人机交互等更复杂具身任务；动作空间为较低的 7 维（或双臂对应维数），对高自由度灵巧操作未做验证。
- **切换时机粒度较粗**：决策边界仅在动作块或单步动作完全执行后才发生，无法在动作执行中途打断，可能限制在极端动态环境中即时响应的能力。
