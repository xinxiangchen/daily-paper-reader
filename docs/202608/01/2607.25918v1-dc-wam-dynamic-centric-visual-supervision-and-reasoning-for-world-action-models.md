## 摘要
世界-动作模型（WAM）通过未来视觉预测增强机器人策略，但视觉模态应学习什么以服务于控制仍不明确。虽然逼真的未来预测提供了密集监督，但也带来了大量计算，并可能将容量分配给与动作选择关联较弱的纹理、光照和背景变化。近期高效的WAM变体表明，视频分支的主要益处可能不在于渲染的未来本身，而在于训练过程中诱导出的与控制相关的视觉表示。在这项工作中，我们从动态中心的视角重新审视未来视频预测，并探究现有的基于RGB的WAM能否从外观主导的重建转向交互诱导的视觉动态，而无需在部署时引入额外的模态特定预测或在线输入。我们提出DC-WAM，一种动态中心的WAM框架，它重新分配了RGB视频分支中的监督与计算。在监督层面，DC-WAM结合了时间差分流匹配与轨迹引导加权，强调密集的时间变化以及夹爪、操作对象和接触区域移动的局部区域。在推理层面，DynaRoute预测词元级别的动态相关性并将其转换为注意力偏置，引导模型关注与控制相关的未来词元。在仿真和真实世界操作任务上的实验表明，DC-WAM持续提升策略性能，尤其在光照、物体外观和背景纹理的分布外扰动下。

## Abstract
World-Action Models (WAMs) augment robot policies with future visual prediction, but it remains unclear what the visual modality should learn for control. While photorealistic future prediction provides dense supervision, it also incurs substantial computation and can allocate capacity to texture, illumination, and background variations that are only weakly related to action selection. Recent efficient WAM variants suggest that the main benefit of the video branch may not lie in the rendered future itself, but in the control-relevant visual representations induced during training. In this work, we revisit future video prediction from a dynamic-centric perspective and ask whether an existing RGB-based WAM can be redirected from appearance-dominated reconstruction toward interaction-induced visual dynamics without introducing additional modality-specific predictions or online inputs at deployment. We propose DC-WAM, a dynamic-centric WAM framework that redistributes supervision and computation in the RGB video branch. At the supervision level, DC-WAM combines temporal-difference flow matching with trajectory-guided weighting, emphasizing dense temporal changes and localized regions where the gripper, manipulated objects, and contact areas move. At the reasoning level, DynaRoute predicts token-wise dynamic relevance and converts it into an attention bias, guiding the model toward control-relevant future tokens. Experiments in simulation and on real-world manipulation tasks show that DC-WAM consistently improves policy performance, especially under out-of-distribution perturbations in lighting, object appearance, and background texture.

## 一、核心问题与整体含义

- **研究背景**：世界-动作模型（World-Action Models, WAMs）将未来视觉预测与机器人动作生成耦合，通过让模型预测场景如何随动作演变，提供超越纯动作模仿的密集时间监督。然而，标准的 RGB 视频预测将操作动力学与纹理、光照、背景、传感器噪声等外观因素纠缠在一起，模型容量被大量消耗在与动作选择弱相关的外观重建上，且在视觉分布偏移下表现脆弱。
- **核心问题**：视觉模态到底应该学什么，才能真正服务于机器人控制？现有 WAM 的 RGB 视频分支是否可以从"外观主导的重建"转向"交互诱导的视觉动态"，同时不引入额外的模态特定预测或部署期在线输入？
- **核心论点**：未来预测的价值不在于渲染出的未来画面本身，而在于训练过程中诱导出的、与控制相关的视觉表征。因此，应该将监督和计算重新分配到与操纵动态（夹爪运动、物体位移、接触变化）相关的区域上，而非均匀地重建整个画面。
- **整体意义**：提出一种**动态中心（dynamic-centric）**的世界-动作模型训练范式，在不改变部署时输入、不增加额外预测模态的前提下，显著提升策略在分布外扰动下的鲁棒性，同时保持甚至略微提升干净条件下的性能。

## 二、方法论

### 2.1 整体思路

DC-WAM 建立在 Wan2.2 骨干和视觉-动作 MoT（Mixture-of-Transformers）架构之上，包含 RGB 视频分支（未来潜在视频预测）和动作分支（动作块生成）。**两个关键设计**：

- **动态中心视觉监督**：通过互补的"密集+稀疏"两个监督信号，将视觉重建损失从外观主导重定向到交互诱导的动态变化上。
- **DynaRoute 推理机制**：一个轻量模块，预测每个视觉 token 的动态相关性，转化为注意力偏置，引导视觉注意力聚焦于与控制相关的未来 token。

### 2.2 轨迹导出的动态图（Tracker-Derived Dynamic Map）

- 离线地从训练数据集中构建，**仅在训练时使用**，部署时无需任何跟踪器或分割模型。
- 具体构建流程：
  1. **采点**：在图像上均匀采样候选点，或在 SAM 分割的前景区域内采样。
  2. **跟踪**：使用现成点跟踪器（CoTracker3）估计所有点在整条 episode 上的轨迹。
  3. **运动量计算**：第 n 个点在第 t 时刻的运动幅度为相邻帧位移的 L2 范数：`d_{t,n} = ||p_{t,n} - p_{t-1,n}||₂`。
  4. **动态点筛选**：运动幅度超过阈值 `δ_mot` 的点被选为动态点。
  5. **栅格化**：将动态点通过高斯核响应映射到 VAE 视觉 token 网格上，聚合得到每个 token 的未归一化动态响应 `b_{t,k}`。
  6. **归一化**：在整个 episode 和每个相机视角内做归一化，得到 `m*_{t,k} ∈ [0,1]`，同时保留空间和时间显著性。

**关键性质**：动态图基于**帧间位移**而非 RGB 重建误差，因此对静态或缓慢变化的光照、背景纹理变化天然不敏感——这正是 OOD 鲁棒性的自然来源。

### 2.3 动态中心视觉监督（两级）

#### （1）时间差分流匹配（Temporal-Difference Flow Matching，密集监督）

- 流匹配目标：对样本 x 和噪声 ε，线性插值 `x_τ = (1-τ)x + τε`，目标流速为 `u = ε - x`。
- 在 VAE 潜在分辨率上施加时间差分损失，惩罚相邻帧之间预测流速变化与目标流速变化之间的不一致：

```
L_TD = E[ Σ_t ||(û_t^V - û_{t-1}^V) - (u_t^V - u_{t-1}^V)||₂² ]
```

- **作用**：抑制时间不变的外观成分，强调时间变化；但不显式定位任务关键区域。

#### （2）轨迹引导流匹配（Tracker-Guided Flow Matching，稀疏监督）

- 使用轨迹导出的动态图 `m*` 对原始视觉流匹配误差进行重加权：

```
L_TrackFM = E[ (Σ_{t,p} m*_{t,p} · e^V_{t,p}) / (Σ_{t,p} m*_{t,p} + ε) ]
```

其中 `e^V_{t,p} = ||û_{t,p}^V - u_{t,p}^V||₂²` 是每个潜在帧单元 p 的视觉流速误差。

- **作用**：将重建损失集中到夹爪、操作物体、接触区域等强跟踪运动区域上，使损失更稀疏、聚焦于交互动力学。

#### （3）总训练目标

```
L = L_FM^A + L_TD^V + L_TrackFM^V + L_Route
```

分别监督动作生成、密集时间动态、稀疏交互区域和 DynaRoute 相关性预测。

### 2.4 DynaRoute：动态感知注意力偏置

- 输入：当前扩散时间步 τ 下的视觉 token 序列 V_τ（包含干净观测 token 和未来视觉 token）、动作 token A_τ、以及语言+本体感觉条件 token S。
- 流程：
  1. 轻量网络 G_ψ 预测每个 token 的动态相关性分数：`z_τ = G_ψ(sg(V_τ), sg(A_τ), S, τ)`（sg 表示 stop-gradient）。
  2. 经 sigmoid 得到 `g_τ ∈ (0,1)`，用下采样的动态图 `m̃*` 通过 BCE + soft Dice 损失监督。
  3. 将相关性转换为对数空间偏置：`b_i = α · log(max(g_i, ε))`，低相关 token 获得更强的负偏置。
  4. 在视觉 token 上做中心化稳定偏置尺度。
  5. 在每一层 MoT 的视觉-视觉注意力中注入加性 key 侧偏置：

```
Attn = softmax( QV(KV)^T / √d + B̄ ) · VV
```

- **推理（部署）**：Fast-WAM 风格的动作-仅推理——视频分支只执行一次构建路由视觉 KV 缓存 C_V，DynaRoute 在初始高噪声时间步 τ_init=1 评估一次，之后视频分支被禁用，动作分支复用缓存完成后续去噪。这保证了训练与推理的一致性（高噪声域为主）。

## 六、主要结论与发现

1. **动态中心监督显著提升 OOD 鲁棒性**：在 LIBERO-Plus 上，DC-WAM 平均成功率达 60.9%，比 FastWAM-AC 高 7.1 个百分点，比 FastWAM 高 9.4 个百分点；ID-OOD 下降幅度最小（37.2 vs 42.9 vs 46.1）。7 个扰动维度中有 6 个得到改善，最大的提升出现在语言、背景和光照变化上。
2. **ID 性能不受损害**：在 LIBERO 上达到 98.1%，比 FastWAM-AC 高 1.4 个点，比 FastWAM 高 0.5 个点，说明动态中心重定向不会牺牲干净条件下的控制能力。
3. **PSNR 与控制性能不匹配**：更高的未来帧 PSNR 并不对应更好的策略性能——DC-WAM 的 PSNR 低于若干变体，但成功率最高。这表明标准的视频质量指标无法完整衡量 WAM 中未来预测的控制效用。
4. **密集与稀疏监督互补**：单独使用时间差分监督（Dense）或轨迹引导加权（Sparse）均能提升性能，但二者联合效果最佳（98.1% ID / 60.9% OOD）。
5. **DynaRoute 的空间对齐非常重要**：将相关性打乱后性能下降（96.8% ID / 57.8% OOD），证明动态相关性必须与视觉 token 的空间位置正确对齐；将偏置用于动作查询而非视觉注意力会导致明显退化（95.8% ID / 49.2% OOD），说明动态中心线索应引导视频分支而非动作分支。
6. **视频分支到动作分支的梯度通路有实质贡献**：用 stop-gradient 阻断视频目标到动作分支的梯度后，LIBERO 下降 1.1 个点、LIBERO-Plus 下降 3.9 个点，证明视频监督通过动作条件视觉计算路径确实有助于动作学习。
7. **注意力更稳定**：随着扰动增强，FastWAM-AC 的注意力变得弥散并漂移到无关背景，而 DC-WAM 保持对操作相关动态区域的集中注意力。

## 七、优点

1. **视角新颖且问题精准**：从"外观主导"转向"交互诱导动态"的视角重新审视 WAM 中的视频预测，抓住了当前 WAM 计算浪费与泛化脆弱的关键症结。
2. **无需修改架构或增加部署开销**：不引入新的预测模态、不需要部署期在线输入，仅通过重新分配 RGB 视频分支已有的监督和计算来实现，工程上可嵌入现有 WAM 框架。
3. **监督信号与外观无关**：基于帧间位移而非重建误差构建监督，天然对光照、背景等外观级别变化不敏感，理论上具有鲁棒性基础。
4. **密集+稀疏互补设计严谨**：时间差分流的全局时间一致性监督与轨迹引导的局部高动态区域监督形成互补，消融实验验证了二者各自的贡献。
5. **推理高效**：沿用 Fast-WAM 风格的动作-仅推理，视频分支仅执行一次构建缓存，兼顾了 OOD 鲁棒性和推断效率。
6. **实验验证扎实**：仿真（LIBERO + LIBERO-Plus）+ 真实世界双灵巧臂实验 + 系统消融 + 注意力可视化 + PSNR 与控制解耦分析，多角度验证了方法的有效性。
