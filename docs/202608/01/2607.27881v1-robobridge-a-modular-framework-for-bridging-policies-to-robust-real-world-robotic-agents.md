## 摘要
视觉-语言-动作（VLA）模型作为机器人操作的一种可扩展方法引起了越来越多的关注。虽然这些模型是有效的动作预测器，但将它们部署为机器人代理时暴露出关键缺陷：缺乏故障恢复机制、长时程执行不一致，以及对观测、任务或本体变化的鲁棒性有限。现有解决方案通过模型重训练或环境特定模块来单独解决这些限制，但需要的是一种通用框架，能够系统地将预训练的VLA转变为机器人代理。我们提出了RoboBRIDGE，一个模块化框架，在五个协调模块之上提供编排层，即监控器、感知器、规划器、控制器和机器人接口，以从现成组件（包括预训练的VLA）组合出稳健的机器人代理。监控器将快速故障检测与层次化恢复相结合，在错误级联之前进行纠正。当环境偏离当前计划时，规划器触发重新规划，而感知器异步更新场景理解，避免执行停顿。在控制器内部，原始技能微调将操作分解为具有专用LoRA适配器的域不变原始技能，从而减少使用VLA时对域偏移的敏感性。在跨越多个机器人平台和VLA骨干的LIBERO、RoboCasa以及真实世界案例研究中，RoboBRIDGE持续优于独立策略和先前增强的VLA部署。这些结果表明，可靠的机器人代理能力并非仅来自扩展动作预测器，而是来自围绕它们的结构化编排。

## Abstract
Vision-Language-Action (VLA) models have attracted growing interest as a scalable approach to robotic manipulation. While these models are effective action predictors, deploying them as robotic agents exposes critical gaps: no mechanism for failure recovery, inconsistent execution over long horizons, and limited robustness to shifts in observations, tasks, or embodiments. Existing solutions address these limitations individually through model retraining or environment-specific modules, yet what is needed is a general framework that systematically transforms a pretrained VLA into a robotic agent. We present RoboBRIDGE, a modular framework that provides an orchestration layer over five coordinated modules, namely Monitor, Perceptor, Planner, Controller, and Robot Interface, to compose robust robotic agents from off-the-shelf components, including pretrained VLAs. The Monitor pairs rapid failure detection with hierarchical recovery to correct errors before they cascade. When the environment diverges from the current plan, the Planner triggers replanning while the Perceptor updates scene understanding asynchronously, avoiding execution stalls. Within the Controller, primitive skill fine-tuning factors manipulation into domain-invariant primitives with dedicated LoRA adapters, reducing sensitivity to domain shifts when a VLA is used. Across LIBERO, RoboCasa, and real-world case studies spanning multiple robot platforms and VLA backbones, RoboBRIDGE consistently outperforms both standalone policies and prior augmented VLA deployments. These results suggest that reliable robotic agency does not arise from scaling action predictors alone, but from structured orchestration around them.

## 2. 论文提出的方法论

### 2.1 总体框架

RoboBRIDGE 是一个政策无关（policy-agnostic）的模块化编排框架，由五个协同模块构成：

- **Monitor（监控器）**：闭环检测执行结果，触发分级恢复；
- **Perceptor（感知器）**：将原始感官观测转换为以物体为中心的语义状态（身份、3D 位姿、语义属性等）；
- **Planner（规划器）**：根据感知状态和语言指令，将任务分解为有序的原始技能序列；
- **Controller（控制器）**：承载动作生成策略的槽位，可插入任意策略（VLA、经典 IK 控制器等）；
- **Robot Interface（机器人接口）**：抽象机器人特定的 API、时序、安全限制与坐标变换，使上游逻辑跨机器人和仿真器通用。

### 2.2 两大核心机制

**（a）两阶段监控与层次化恢复**

- **阶段一（轻量级成功检查）**：使用低成本的成功检查器 D_check 对当前观测与计划上下文进行评估，生成二元成功标志和置信度，采用受限输出格式抑制扩展推理，以约 5Hz 频率在控制循环外运行，不阻塞执行：D_check: (o_t, c_t) → (suc_t, con_t)
- **阶段二（失败诊断与恢复）**：当检测到高置信度失败时，立即停机并调用诊断模型推断根因、选择恢复目标：D_diag: (o_t, c_t) → (r_t, reason_t)
- **四级层次恢复策略**（按重计算范围递增）：
  1. **retry**：重新执行当前原始技能；
  2. **regenerate**：保留当前计划和感知状态，重新生成轨迹；
  3. **replan**：基于最新异步感知结果重新规划；
  4. **re-perceive**：强制完整重新感知后再规划（感知状态不可靠时）。

**（b）异步感知 + 发散触发的反应式规划**

- 采用**生产者-消费者架构**：感知线程持续将最新检测结果写入线程安全缓冲区 B，隐藏感知延迟；执行线程顺序执行原始技能，不被感知阻塞。
- **发散度量公式**：每个原始技能完成后，比较当前计划的感知观测与缓冲区中最新观测，计算位置位移与物体出现/消失的加权和：

Δ(ō_a, ō_b) = max_{i∈O_a∩O_b} ‖p_a⁽ⁱ⁾ - p_b⁽ⁱ⁾‖₂ + λ·|O_a △ O_b|

- 当 Δ ≥ τ 时触发重规划：保留高层动作序列（如 PICK → PLACE），仅基于最新观测重新生成当前和后续技能的时空参数，避免冗余的高层推理。

### 2.3 原始技能微调（Primitive Skill Fine-tuning）

- **核心思想**：将操纵分解为域不变的原始技能集合 P = {MOVE, GRIP, ROTATE, ...}，每个原始技能对应一个**专用的 LoRA 适配器**（而非共享同一组权重处理所有操纵阶段）。
- **公式表达**：冻结 VLA 骨干 f_θ，训练轻量 LoRA 模块 Δθ_k：f_{θ+Δθ_k}: (i, s_t, p_t) → aₜ⁽ᵏ⁾
- **控制器切换机制**：当请求的原始技能有对应适配器时直接选用；否则回退到所有已注册 LoRA 适配器的平均：RESOLVE(p_t) = Δθ_pₜ（若存在），否则 (1/|P|)Σ_p Δθ_p。LoRA 切换就地完成，无需重新加载骨干。
- **动作执行**：适配器预测 7-DoF delta 动作 a_t = (δx, δφ, g)，转化为笛卡尔速度指令；当 IK 求解器可用时转换为绝对目标并求解关节位置，否则回退到速度控制，实现跨机器人运动学接口的通用。

## 6. 主要结论与发现

### 6.1 定量结果

- **LIBERO**：RoboBRIDGE 将平均成功率从 35.5% 提升至 39.7%，其中 **LIBERO-Long（长时程）提升最显著（+9.4%）**，Object 套件 +5.3%，Spatial 和 Goal 套件提升较小（+1.1% 和 +1.2%）。
- **RoboCasa**（更具挑战性、长时程且执行漂移频繁）：
  - SmolVLA：3.4% → 6.9%（+3.5%）
  - π0.5：3.4% → 5.9%（+2.5%）
  - GR00T-N1.5：4.2% → 9.8%（+5.6%）
  - 排除 pick-and-place 任务后：6.2% → 14.7%（+8.5%，GR00T-N1.5）
- **LLM 骨干效应**（表 III）：无监控时各骨干差异很小（1.8%–8.0%）；启用监控后显著分化，Claude Opus 4.6 提升最大（+8.1%，达 14.7%），GPT-5 mini 次之（+6.2%），小模型（如 Gemini-3 Flash、Claude Haiku 4.5）增益微弱。表明**有效的失败诊断需要足够推理能力，规划与监控缺一不可**。
- **控制器配置**（表 IV）：
  - LoRA FT + RoboBRIDGE：15.3% → 27.1%（+11.8%），逼近独立 Full FT（31.9%）但参数量远少；

  - IK 控制器在框架内达 22.1%，验证政策无关性；
  - CycleVLA 独立部署仅 7.5%，表明**模型内部自校正不如外部结构化编排有效**。

### 6.2 定性发现

- 两阶段监控能早期检测并对齐执行偏差，以最小恢复动作介入而不重启完整计划，防止局部错误级联；
- **两大主要失败模式**：感知错误（遮挡/相似物体导致的误识别和错定位）和不可恢复的操控失败（接触丰富交互中环境状态被不可逆改变），指向感知鲁棒性和接触丰富行为的显式验证/校验的改进方向。

## 7. 优点

- **政策无关的通用编排**：主张并实现了“围绕策略编排”的通用范式，而非针对特定策略或特定失败模式定制，框架可嵌入任意动作生成器（VLA、IK 控制器），无需重训练或架构改动；
- **模块化设计清晰**：Monitor、Perceptor、Planner、Controller、Robot Interface 五模块职责分离明确，模块间通过标准接口组合，便于替换和扩展；
- **两阶段监控的高效性**：轻量成功检查与深度诊断分离，避免对每个控制步都运行完整诊断带来的延迟，在性能与检测深度间取得平衡；
- **异步感知隐藏延迟**：生产者-消费者架构将感知推理从执行关键路径中解耦，同时通过发散触发的重规划在环境变化时保持计划最新，无需持续重规划；
- **分级恢复策略**：从 retry 到 re-perceive 四级恢复按重计算成本递增排列，用最小代价纠正错误，避免不必要的重规划或全盘重启；
- **LoRA 原始技能微调**：将操纵分解为域不变原始技能并配以专用适配器，减少域偏移敏感性，且切换开销极低（就地替换适配器，无需重载骨干）；
- **类比说服力强**：借用 LLM 代理化演进的类比，为“VLA 需要编排而非仅规模化”提供了有说服力的论点；
- **跨骨干一致改进**：在三种不同规模的 VLA 骨干上均获得一致增益，增强了结论的普适性。

## 8. 不足与局限

- **真实世界评估不足**：真实世界实验仅以案例演示呈现，缺乏系统性成功率统计和大规模用户研究，证据强度弱于仿真中系统性的多任务评测；
- **LIBERO 骨干覆盖单一**：LIBERO 上仅测试了 GR00T-N1.5 一种骨干，未覆盖多种 VLA 在该基准上的表现，跨骨干结论主要依赖 RoboCasa；
- **任务类型有限**：论文自身承认原始技能词汇表主要覆盖单臂桌面行为，对**接触丰富交互、可变形物体、双臂任务**需要更丰富的原始技能和状态表示；
- **超参数手动设定**：监控阈值（γ、τ）和恢复规则目前为人工设定，未实现从交互数据中学习这些参数；
- **P&P 任务几乎全失败**：RoboCasa 中多项 pick-and-place 任务在所有条件下成功率均为 0%（如 PnPCounterToMicrowave 等），框架对这些任务无法提供改进，说明存在框架能力边界；
- **样本量较小**：以 5.9%、11.8% 等颗粒度的百分比推断，每任务测试轮次不多（约 17 轮），部分任务 w/o 和 w/RB 差异仅有 1 个样本的差别，统计显著性存疑；
- **未报告算力成本**：未量化框架本身的开销（监控频率、LLM 诊断调用的 token 成本、延迟等），实际部署成本不透明；
- **对比基准不全面**：虽然对比了 CycleVLA，但未与 DoReMi、SAFE、Code-as-Monitor 等其他增强 VLA 部署方法直接对比，框架的增量优势缺乏全面的同类基准参照。
