## 摘要
通用机器人策略旨在将多模态观测和语言任务指令映射为跨多样任务的动作。然而，现有方法通常将未来表示为固定的短时视频-动作块。这种短期未来捕获了用于动作执行的局部场景演变，但并未显式描述规定任务应如何从当前阶段推进到下一阶段的分阶段未来。因此，我们区分了机器人操作中两种互补的未来：用于捕获局部场景演变的短期物理未来与表示任务进度的分阶段语义未来。我们引入了JEPA-WAM，它通过Stage-JEPA（一种目标条件化的联合嵌入预测架构（JEPA）预测器）增强了基于Motus的世界动作模型（WAM）。给定当前观测和任务指令，Stage-JEPA使用冻结的V-JEPA2编码器提取当前状态表示，并预测下一推断阶段的潜在目标。在干净和随机化环境中的50个RoboTwin 2.0任务上，JEPA-WAM实现了90.25%的总体成功率，并在成功执行中相对于最强基线将平均执行步数减少了5.97%。

## Abstract
Generalist robot policies aim to map multimodal observations and linguistic task instructions to actions across diverse tasks. However, existing methods typically represent the future as a fixed, short video-action chunk. This short-term future captures local scene evolution for action execution, but it does not explicitly describe the stage-level future that specifies how a task should progress from its current stage to the next. We therefore distinguish two complementary futures for robot manipulation: a short-term physical future to capture local scene evolution and a stage-level semantic future to represent task progress. We introduce JEPA-WAM, which augments a Motus-based World Action Model (WAM) with Stage-JEPA, a goal-conditioned Joint-Embedding Predictive Architecture (JEPA) predictor. Given the current observation and task instruction, Stage-JEPA uses a frozen V-JEPA2 encoder to extract the current-state representation and predicts the latent target of the next inferred stage. Across 50 RoboTwin 2.0 tasks in clean and randomized environments, JEPA-WAM achieves 90.25% overall success and reduces the mean number of execution steps in successful rollouts by 5.97% relative to the strongest baseline.

- 核心问题：**机器人策略如何在生成本地动作之前，预测下一个有意义的任务进度阶段？**

**核心洞见：**
论文区分了两种互补的未来：
1. **短期物理未来（Short-term Physical Future）**：捕获局部场景演变、物体运动、接触动力学；
2. **阶段级语义未来（Stage-level Semantic Future）**：表示任务应达到的下一个对象状态或关系变化（如空间对齐、物体所有权转移），不纠结于像素细节或transition时长。

**整体含义：** 显式建模"阶段级语义未来"可以弥补WAM在任务推理上的盲区，使机器人在做局部动作之前就"知道"任务应该朝什么方向进展，从而提升操作成功率与执行效率。

## 2. 方法论

### 2.1 整体架构

JEPA-WAM由两个顺序训练阶段组成，核心组件包括：
- **Stage-JEPA**：目标条件化的JEPA预测器，基于冻结的V-JEPA2编码器；
- **Motus-based WAM**：混合Transformer架构，包含视频生成专家、动作专家和视觉语言理解专家。

**总体流程：** 当前观测+任务指令 → Stage-JEPA预测下一阶段潜在表征 → 门控接口注入 → WAM条件化生成局部视频和动作块。

### 2.2 Stage I：训练JEPA预测器

**(a) 阶段对构建（Stage-pair Construction）**
- 无需人工阶段标注，采用**JEPA特征变化启发式**自动检测阶段边界；
- 每个episode每8帧采样候选中心，用冻结V-JEPA2编码64帧片段；
- 计算clip级别和token级别的表示变化分数，经min-max归一化后取两者较大值；
- 使用时序NMS（半径r=3，最多K=5个关键帧）选取得分最高的transition关键帧；
- 关键帧与首尾帧构成阶段边界序列B=(b₀,...,b_L)；
- 每个当前帧t与其所在阶段的下一边界b_{i+1}配对，形成密集训练对(t, b_{i+1})。

**(b) 目标条件化阶段预测**
- 每个对(t, b_{i+1})转换为64帧当前切片S_t和64帧目标切片S_target（分别以t和b_{i+1}为中心）；
- 同一冻结V-JEPA2编码器E分别产生当前潜在z_t和目标潜在z_target；
- 可训练的V-JEPA2预测器（从预训练权重初始化）+ 指令适配器生成token级下一阶段预测，经池化和归一化得到ẑ_target；
- 损失函数为余弦相似度损失：L_stage = 1 - (ẑ_target)ᵀ z_target。

### 2.3 Stage II：训练阶段条件化的WAM

- **WAM实例化**：采用Motus，一种Mixture-of-Transformers架构：
  - 视频专家（从Wan2.2初始化）：建模局部视觉演变；
  - 动作专家：表示机器人状态与稠密动作块；
  - 理解专家（冻结Qwen3-VL编码器）：提取指令与观测相关特征；
  - **Tri-modal Joint Attention**：三个流在每个Transformer层交换信息。
- **条件注入机制**（关键创新）：
  - 对Stage-JEPA输出的token进行mean-pooling，经MLP P_ψ映射到视频token维度；
  - 通过**全局标量门控** α = 0.2σ(β) 控制注入强度；
  - 注入公式：X_vt' = X_vt + α·h_t；
  - 门控α为所有样本、层、token共享的可训练标量，初始化为0.02。
- **训练目标**：L = L_video + L_action + L_reg，其中：
  - L_reg包含两项正则化：λ_g·α²（biased门控趋向小残差更新）+ λ_ρ(ρ-ρ₀)²（控制注入相对幅度，ρ₀=0.08）。

### 2.4 闭环推理

- 维护因果64帧观测缓冲（不足时用最早帧重复填充，不用未来帧）；
- 每次查询：Stage-JEPA从缓冲和指令预测阶段潜在 → 经条件接口注入WAM → WAM预测短时视觉未来和动作块；
- 环境执行动作块后追加观测，循环往复；
- 阶段边界和目标切片仅为训练监督，推理时完全由模型自行预测阶段条件。

## 6. 主要结论与发现

1. **主实验结果**：JEPA-WAM在干净环境达到91.42%成功率、随机化环境89.08%，**总体90.25%**，超过最强基线Motus（88.66%/87.02%）。

2. **类别层面**：在干净设置下7类中5类最优、随机化下6类最优。在手势交接、目标放置、容器装箱等依赖显式任务进度变化的任务上提升最显著。

3. **消融发现**：
   - 移除JEPA分支是最大性能下降来源 → 阶段条件化通道提供了超越短时WAM的额外信息；
   - 防止未来潜在注入也降低性能 → 直接注入WAM视频token比仅修改当前观测表征更好；
   - 无Stage-I训练仍具竞争力但非最优 → 预训练V-JEPA2预测器提供通用结构，但任务特定训练仍有益；
   - 移除门控正则化影响较小 → sigmoid有界门控本身已稳定残差更新。

4. **执行效率**：
   - 全体rollout平均步数从156.28降至132.80（**-15.02%**）；
   - 成功轨迹平均从79.57降至74.82（**-5.97%**），表明阶段指导减少冗余纠正动作。

5. **定性分析**：案例显示Motus在成功前反复上下移动物体，而JEPA-WAM快速推进到下一个任务相关状态。

6. **真实机器人**：JEPA-WAM平均任务进度评分48.00 vs π0.5的41.50，Cube_Grasp提升显著（45.00 vs 33.50）。

## 7. 优点

1. **问题定义清晰**：首次明确区分"短期物理未来"与"阶段级语义未来"，提供更细粒度的未来建模层级划分。

2. **免人工标注的阶段监督**：通过JEPA特征变化的自动阶段检测+时序NMS，从演示中自动构建阶段边界，避免了昂贵的语义阶段标注。

3. **表示空间预测优于像素预测**：JEPA天然避免像素级重建的外观偏置，保留任务相关的语义结构，解决了"直接预测遥远目标图像不匹配"的问题。

4. **两阶段训练设计合理**：先学"任务应发生什么变化"，再学"如何实现"，冻结Stage-JEPA防止细节损失干扰语义目标。

5. **门控注入机制精致**：全局有界标量门控（0.2σ(β)）+ 双重正则化（λ_gα²和λ_ρ(ρ-ρ₀)²），在"注入充分"与"不扰乱原始视频token"之间取得平衡。

6. **广泛的任务覆盖**：50个任务、7类语义技能的验证范围在同类工作中较全面。

7. **效率分析加分**：不只报告成功率，还报告执行步数减少，直接证据表明阶段指导减少了无效运动。

8. **闭环推理设计干净**：训练时的阶段边界仅用于监督，推理时完全自预测，避免了部署时的信息泄露。

## 8. 不足与局限

1. **基线公平性风险**：主要对照数字（GO-1、π0.5、X-VLA、Motus）来自Motus论文发表结果，不同模型可能涉及不同的数据过滤、训练协议和评估细节，虽然论文声称采用相同闭环协议，但跨论文数字对比固有偏差风险。

2. **V-JEPA2输入约束**：要求64帧输入切片，导致推理时存在冷启动问题（前63帧需重复填充），且64帧窗口比多数阶段间隔（平均44.74帧）更长，可能限制对短阶段变化的区分能力。

3. **阶段检测启发式的潜在问题**：自动阶段检测使用V-JEPA2特征距离和NMS，但在某些任务上（如连续平滑操作而非离散阶段变化），阶段边界可能不准确或缺乏意义。

4. **实验覆盖缺口**：
   - 真实机器人仅2个任务，缺乏多样化验证；
   - 未在更多benchmark（如LIBERO、RLBench等）上验证泛化性；
   - 未涉及跨具身（不同机器人形态）的泛化测试。

5. **推理延迟**：论文自己也承认WAM的推理延迟限制了高频闭环控制，这是未来工作方向。

6. **限制类别**：在Acquisition & lifting和Articulated/device interaction上未超越Motus或提升有限，说明阶段指导并非普适——需要细粒度接触和精确时序的任务，当前的间接阶段信号不够。

7. **统计严谨性**：未报告方差/置信区间、无多种子评估（各阶段仅seed 0训练一次），在100-episode规模下的性能差异可能缺乏统计显著性验证。

8. **诊断数据显示监督模糊性**：86.77%（clean）/86.34%（randomized）的当前-目标切片对存在重叠，84.67%/82.97%的切片跨越阶段边界，说明阶段监督本身存在一定模糊性，可能影响训练信号的精确性。
