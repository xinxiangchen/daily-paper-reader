## 摘要
具身视觉运动模型，包括扩散策略（DP）和视觉-语言-动作（VLA）模型，已在机器人操作基准测试中展现出良好的性能。然而，其潜力仍从根本上受限于大规模具身轨迹数据的稀缺，导致在分布外（OOD）场景中组合泛化能力不足，且捕获可复用技能结构的能力有限。为解决这一局限，我们提出基于技能的记忆（SkillMemo）框架，该框架将长时程演示隐式分解为潜在原子技能，并将技能级特征整合到动态情景记忆库中，以解决组合任务。具体而言，我们首先引入一个基于专家混合（MoE）架构的专家引导轨迹分割模块，该模块通过学习的门控系数将轨迹隐式划分为不同的技能原语。我们进一步设计了一种技能级情景记忆架构，将紧凑的技能表示存储为可检索的键值对。在推理阶段，记忆库检索最相关的技能原语，并将其与模型当前的门控分布融合，为细化动作预测提供稳健的上下文先验。在仿真基准和真实世界操作任务上的大量实验表明，SkillMemo能持续增强DP和VLA骨干模型，实现最先进的性能并优于π₀.₅，同时展现出对未见任务配置的强组合泛化能力。

## Abstract
Embodied visuomotor models, including Diffusion Policy (DP) and Vision-Language-Action (VLA) models, have demonstrated promising performance on robotic manipulation benchmarks. However, their potential remains fundamentally constrained by the scarcity of large-scale embodied trajectory datasets, leading to insufficient compositional generalization in out-of-distribution (OOD) scenarios with limited capability to capture reusable skill structures. To address this limitation, we propose Skill-Based Memory (SkillMemo) framework that implicitly decomposes long-horizon demonstrations into latent atomic skills and integrates skill-level features into a dynamic episodic memory bank for solving compositional tasks. Specifically, we first introduce an expert-guided trajectory segmentation module built upon a Mixture-of-Experts (MoE) architecture, which implicitly partitions trajectories into distinct skill primitives represented by learned gating coefficients. We further design a skill-level episodic memory architecture that stores compact skill representations as retrievable key-value pairs. During inference, the memory bank retrieves the most relevant skill primitives which are subsequently fused with the model's current gating distribution, providing a robust contextual prior to refine action predictions. Extensive experiments on the simulation benchmark and real-world manipulation tasks demonstrate that SkillMemo consistently enhances both DP and VLA backbones, achieving state-of-the-art performance and outperforming $π_{0.5}$, while exhibiting strong compositional generalization to unseen task configurations.

## 1. 论文的核心问题与整体含义（研究动机和背景）

具身视觉运动模型（如扩散策略 Diffusion Policy、视觉-语言-动作模型 VLA）在机器人操作任务中已取得显著进展，但其性能从根本上受到大规模具身轨迹数据稀缺的制约。在训练数据不足的情况下，模型往往学习到的是**整体式（monolithic）策略**，难以捕获**可复用的行为结构**（即原子技能），从而导致在**分布外（OOD）场景**中——即已知物体、容器和指令的新组合——泛化能力严重不足。

现有解决方案中，强化学习、运动原语库、记忆增强策略等方法各有局限。尤其是近期的记忆增强方法（如 MemoryVLA、HAMLET）虽然引入了记忆机制，但**缺乏对行为显著的技能级特征的显式记忆机制**，导致对先前经验的复用效率低下，无法充分支撑未见任务的组合泛化。

为此，论文提出 **SkillMemo**（Skill-Based Memory）框架，其核心思想是：将长时程演示**隐式分解**为潜在原子技能（latent atomic skills），并将技能级特征存入**动态情景记忆库**中，在推理时检索并融合相关技能，从而解决组合操作任务并提升分布外泛化能力。

## 2. 论文提出的方法论

### 2.1 核心思想

SkillMemo 采用“**分解-存储-检索-融合**”的流程，将原本由单一网络整体编码的行为轨迹，转化为可结构化存储和组合调用的技能原语集合。

### 2.2 关键技术细节

**（1）专家引导的轨迹分割（Expert-Guided Trajectory Segmentation, EGTS）**

- 采用**混合专家（Mixture-of-Experts, MoE）** 架构，包含 N 个专家网络和一个门控网络 G。
- MoE 层输出为：$y_t = \sum_{i=1}^{N} g_i(h_t) \cdot E_i(h_t)$，其中 $g_i(h_t)$ 为门控权重，$h_t$ 为中间特征。
- 门控权重随时间的变化**隐式定义了轨迹的分割边界**——每个专家捕获一种局部运动原语，从而自适应地发现与任务结构对齐的技能边界。
- 引入基于**部分信息分解（Partial Information Decomposition, PID）** 的协同信息损失：$L_{PID} = -[I(\{A,B\};G) - I(A;G) - I(B;G)]$，促使专家之间的联合表示包含比个体表示之和更多的任务相关信息，从而驱动专家实现互补技能特化和高阶协调。
- 辅以**负载均衡损失**和 **top-k 路由策略**防止专家坍塌。

**（2）技能级记忆架构（Skill-Level Memory Architecture, SLMA）**

- **存储（Memory Storage）**：将每个隐式分割出的技能段的轨迹特征做时间聚合，得到紧凑质心特征作为记忆键 $k_m = \frac{1}{L}\sum_{t \in \tau_m} h_t$；将完整的门控权重序列作为记忆值 $v_m = \{g(h_t)\}_{t \in \tau_m}$。记忆库 $M = \{(k_m, v_m)\}_{m=1}^{M}$。
- **检索（Memory Retrieval）**：推理时计算当前观测特征 $q_t$ 与每个记忆键的余弦相似度，检索 top-N 最相关记忆条目；通过与置信度阈值 $\delta$ 对比进行可靠性检查；若可靠，则融合检索到的门控分布与当前门控分布：$g'(q_t) = \lambda g(q_t) + (1-\lambda) \frac{1}{N}\sum_{n=1}^{N} v_n[t']$。
- **更新（Memory Update）**：设计了基于使用追踪的**有限容量动态剪枝策略**，按三条标准淘汰低效用记忆：时间戳过时、长期未被检索、始终未达可靠性阈值。
