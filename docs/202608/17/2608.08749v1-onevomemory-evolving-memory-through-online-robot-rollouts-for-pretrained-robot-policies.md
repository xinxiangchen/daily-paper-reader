## 摘要
长期视野的机器人操作要求策略跟踪已完成的子任务和关键交互事件。然而，现有的记忆机制严重依赖外部模型或预定义的更新规则。为解决这一问题，我们提出了OnEvoMemory，一种用于预训练机器人策略的价值引导记忆模块。它维护近期上下文、高价值经验和显著的状态转换，同时从轨迹结果中学习哪些经验应被保留。离线演示初始化记忆先验，而成功和不成功的在线轨迹则优化记忆选择，帮助策略识别任务阶段转换并避免重复已完成子任务。在长期操作基准上的实验表明，OnEvoMemory通过离线初始化和在线记忆演化提升了基础VLA策略的性能。

## Abstract
Long-horizon robot manipulation requires policies to track completed subtasks and critical interaction events. However, existing memory mechanisms heavily rely on external models or predefined update rules. To address this, we propose OnEvoMemory, a value-guided memory module for pretrained robot policies. It maintains recent context, high-value experiences, and salient transitions, while learning which experiences should be retained from trajectory outcomes. Offline demonstrations initialize the memory prior, whereas successful and unsuccessful online rollouts refine memory selection, helping the policy recognize task-stage transitions and avoid repeating completed subtasks. Experiments on long-horizon manipulation benchmarks show that OnEvoMemory improves the performance of the base VLA policy through both offline initialization and online memory evolution.

## 2. 方法论

### 核心思想
- 基于价值引导的层次化记忆系统，在动作查询（action-query）层面组织历史信息，通过门控交叉注意力注入当前决策。
- 离线阶段用专家演示训练记忆模块；在线阶段利用真实轨迹结果（成功/失败）更新价值估计器和记忆写入器，实现记忆演化。
- 基础策略（VLA策略）完全冻结，仅更新价值估计器和记忆相关模块。

### 关键技术细节
- **输入表示**：当前观测 \(o_t = (I_{1:V_t}, s_t, \ell)\)，其中多视角图像、本体感受状态和语言指令；基础策略产生动作查询表示 \(Q_t = E_\theta(o_t) \in \mathbb{R}^{H \times d}\)。
- **记忆读取**：
  - 短期缓冲 \(M^S\)：固定容量的FIFO队列，保存最近的动作查询表示，保留局部上下文。
  - 精英经验库 \(M^E\)：保留高价值状态–动作经验（如稳定抓取、成功完成中间阶段）。
  - 转换库 \(M^T\)：保留轨迹质量显著变化的事件（如任务进展、接触丢失、失败与恢复）。
  - 检索方式：对长时记忆库，综合采用TopK语义相似检索和最近写入检索：\(R_b^t = \text{TopK}_{\text{sim}}(Q_t, M_b^t) \cup \text{RecentK}(M_b^t)\)，其中 \(b \in \{E, T\}\)。
  - 最终形成记忆上下文 \(C_t\)，通过门控交叉注意力与当前查询融合：\(\tilde{Q}_t = Q_t + g_t \text{MHA}(Q_t, C_t, C_t)\)。
  - **记忆读取在写入之前进行**，避免当前经验被立即检索。
- **记忆写入**：
  - 动作条件价值估计器 \(F_\phi(\tilde{Q}_t, A_t)\) 输出 \((V_t, k_t, v_t)\)，其中 \(V_t\) 表示轨迹结果对齐的写入分数，\(k_t\) 和 \(v_t\) 分别表示检索键和存储表示。
  - 高价值经验写入精英库 \(M^E\)；大幅价值变化（\(|V_t - V_{t-1}|\) 大）的经验写入转换库 \(M^T\)。
  - 该机制取代人工定义的事件规则，完全学习得到。
- **离线初始化**：按时间顺序回放专家演示，使先前经验填充记忆库，后续观测可从累积记忆中检索；通过动作监督和轨迹结果联合初始化记忆先验，训练读写与注入模块。
- **在线演化**：收集成功和不成功的完整轨迹，作为新的结果监督信号，更新价值估计器和记忆写入器，使模型不断修正哪些经验应被保留和重用。基础策略完全冻结。

## 6. 主要结论与发现

- 离线记忆初始化可在不改变预训练策略的情况下提升长期操作成功率。
- 在线记忆演化进一步改善性能，尤其利用了不成功轨迹的“纠正性监督”，帮助系统修正被高估的经验并保留更有信息量的事件。
- 记忆在**任务阶段转换**时最有效：保留已完成子任务的高价值经验，减少策略“忘记进度”和“重复已完成子任务”的现象。
- 整体表明“记忆选择”可以从成功与失败的交互体验中持续进化，而无需重新训练或微调基础策略。

## 7. 优点

- **学习式记忆写入**：价值引导机制取代固定时间窗口、人工规则或外部VLM，使记忆选择能随任务和交互结果自适应调整。
- **层次化记忆设计**：短期缓冲、精英库和转换库分别处理上下文、高价值经验和显著转换，结构清晰且互补。
- **冻结基础策略的在线演化**：能够利用在线rollout反馈优化记忆，而不会破坏预训练操作能力，实际部署安全性更好。
- **离线与在线结合**：离线演示提供了良好的记忆初始化，在线数据则提供持续改进，形成完整的记忆生命周期。
- **实验结果初步正向**：两个基准上均有提升，尤其RMBench从0%的失败状态实现非零成功率，展示了一定潜力。
