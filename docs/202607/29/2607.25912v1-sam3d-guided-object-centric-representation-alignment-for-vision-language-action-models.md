## 摘要
视觉-语言-动作（VLA）模型在通用机器人操作中展现出强大潜力，但大多数现有模型依赖二维视觉-语言骨干网络，缺乏对目标物体的细粒度三维理解，特别是在遮挡、姿态变化、尺度变化和精确空间交互场景下。我们提出了一种基于π₀的物体中心三维表示对齐框架，利用SAM3D作为冻结的三维教师模型，在训练过程中提供目标物体的三维先验。具体而言，我们使用物体识别模型定位任务相关物体，生成对应物体掩码，并利用SAM3D提取密集的物体级三维表示，这些表示与π₀的中间视觉特征进行对齐。这使得策略能够内化目标物体的三维信息，同时保留原始RGB-语言-动作推理流程，在测试时无需深度图、点云、掩码、SAM3D或额外的三维模块。仿真实验显示该方法持续改进，在LIBERO上达到99.1%，在CALVIN上平均长度为4.11。真实世界实验进一步表明，我们的方法在需要机器人跨多个子任务关注不同目标物体的长时域操作场景中尤为有效。

## Abstract
Vision-Language-Action (VLA) models have shown strong potential for general robot manipulation, but most existing models rely on 2D visual-language backbones and lack fine-grained 3D understanding of target objects, especially under occlusion, pose variation, scale changes, and precise spatial interaction. We propose an object-centric 3D representation alignment framework built upon $π_0$, using SAM3D as a frozen 3D teacher to provide target-object 3D priors during training. Specifically, we localize task-relevant objects with object recognition models, generate corresponding object masks, and use SAM3D to extract dense object-level 3D representations, which are aligned with intermediate visual features of $π_0$. This enables the policy to internalize target-object 3D information while preserving the original RGB-language-to-action inference pipeline without requiring depth, point clouds, masks, SAM3D, or additional 3D modules at test time. Simulation experiments show consistent improvements, achieving 99.1\% on LIBERO and an average length of 4.11 on CALVIN. Real-world experiments further demonstrate that our method is particularly effective in long-horizon manipulation scenarios where the robot must focus on different target objects across multiple subtasks.

## 2. 方法论

### 核心思想
- 基于π₀ VLA模型，使用**SAM3D**作为冻结的3D教师模型，在训练时为任务相关目标物体提取密集3D特征（形状、表面结构、空间布局），并与π₀中间视觉表示进行对齐（alignment），使策略能够内化物体级3D先验。
- 对长时域任务，将高层指令分解为子任务，每个子任务关联对应的目标物体掩码，提供阶段特定的3D监督。
- 测试时完全移除教师模块和物体检测/分割流程，仅使用原始RGB图像和语言指令进行动作预测。

### 关键技术细节
1. **物体定位与掩码生成**：利用Grounding DINO/YOLO进行开放词汇物体检测→SAM2生成二进制掩码。
2. **SAM3D特征提取**：将多视图图像和掩码输入冻结SAM3D，输出密集3D特征（last transformer block输出），包含物体级几何先验。
3. **空间重采样与对齐**：
   - 将SAM3D特征网格通过双线性插值重采样到π₀视觉token分辨率（$H_S \times W_S$）。
   - 从π₀的Gemma层提取中间视觉特征$S_t$，通过投影网络$P_\phi$映射到SAM3D特征空间得到$\hat{T}_t$。
   - 构建token级掩码$\mathbf{m}_t$（来自物体掩码），仅对目标物体token进行对齐。
   - 对齐损失采用**掩码归一化均方误差**（Masked Normalized MSE）：先对$\hat{T}_t$和教师特征$\bar{T}_t$进行ℓ2归一化，再计算MSE。
4. **训练目标**：$ \mathcal{L} = \mathcal{L}_{\text{action}} + \alpha \mathcal{L}_{\text{align}} $，其中$\mathcal{L}_{\text{action}}$为π₀原有的条件流匹配动作损失，$\alpha$控制3D监督强度。
5. **冻结表示探测实验**：训练后冻结整个VLA骨干，仅训练一个轻量MLP探头$P_\omega$来预测SAM3D特征，以验证对齐是否使3D先验更易恢复。

### 公式/算法流程（文字说明）
- 动作预测：条件流匹配，从高斯噪声积分到真实动作。
- 对齐：$ \mathcal{L}_{\text{align}} = \text{MSE}\big( \text{Norm}(\hat{T}_t)[\mathbf{M}_t], \text{Norm}(\bar{T}_t)[\mathbf{M}_t] \big) $。
- 总体：$ \mathcal{L} = \mathbb{E}_{\tau,\epsilon}\|v_\theta(A^\tau_t,\tau,o_t) - (A_t-\epsilon)\|^2 + \alpha \mathcal{L}_{\text{align}} $。

3. **基于先进模型π₀和SAM3D**：利用大规模预训练视觉语言模型和3D分割模型，数据效率高，泛化潜力大。

## 8. 不足与局限

1. **对数据预处理依赖**：训练时依赖自动生成的子任务标注和物体掩码，如果LLM分解、物体检测或分割出现错误，会引入噪声监督，降低训练质量。
