## 摘要
具身人工智能日益依赖于从预训练的视觉-语言模型构建的可查询语义地图，以实现零样本目标导航（ObjectNav）。然而，现有方法通常依赖于纯文本查询，随着语义特异性向细粒度对象类别的增加，这种查询的可信度会下降。我们提出了IMPRINT，一种零样本的即插即用框架，该框架通过从网络获取的图像来丰富文本对象查询，以改善在可查询地图中的定位。检索到的图像使用视觉-语言模型进行编码，与语义地图匹配生成相似度图，并聚合以产生上下文感知的定位。值得注意的是，这无需训练或修改底层导航策略。为了明确评估长尾行为，我们提出了HSSD-rare，这是一个基于Habitat合成场景的新ObjectNav基准，具有语义上特定的子类别。在OVON和HSSD-rare上，基于图像条件的查询一致地改善了对象定位，并带来了端到端的导航增益。进一步分析表明，将定位增益转化为导航性能关键在于下游检测质量，这突显了长尾具身导航中的一个关键系统瓶颈。

## Abstract
Embodied AI increasingly relies on queryable semantic maps built from pre-trained vision-language models to enable zero-shot Object Goal Navigation (ObjectNav). However, existing approaches typically depend on text-only queries, which become less reliable as semantic specificity increases toward fine-grained object categories. We introduce IMPRINT, a zero-shot plug-and-play framework that enriches textual object queries with web-sourced images to improve grounding in queryable maps. Retrieved images are encoded using a vision-language model, matched against the semantic map to produce similarity maps, and aggregated to yield context-aware localization. Notably, this requires no training or modification of the underlying navigation policy. To explicitly evaluate long-tail behavior, we present HSSD-rare, a new ObjectNav benchmark built on Habitat Synthetic Scenes and featuring semantically specific subcategories. Across both OVON and HSSD-rare, image-conditioned queries consistently improve object grounding and yield end-to-end navigation gains. Further analysis reveals that translating localization gains to navigation performance depends critically on downstream detection quality, highlighting a key systems bottleneck in long-tail embodied navigation.

## 2. 方法论

- **核心思想**：模仿人类搜索行为（如查阅图像示例识别不熟悉物体），IMPRINT在查询给定物体类别时，从网络检索若干相关图像，将其编码为视觉嵌入，与预先构建的语义地图进行匹配，聚合多个图像产生的相似度图，最终得到上下文感知的目标定位。
- **关键技术细节**：
  - **Web图像检索**：对长尾类别，在检索时预挂头类别（如“chair, Upholstered Drop Chair”）以提高相关性；通过元数据过滤（ALT文本/URL路径中是否包含头名词）和去重保留有效图像；检索延迟平均0.61±0.16秒/图。
  - **可查询语义地图构建**：沿用VLFM的管线，将RGB观察通过VLM编码为特征，利用深度和位姿投影至全局2D栅格地图，多次观测取平均；对于patch级编码器（如SED），每个patch特征独立投影，实现更精细的语义分配。
  - **查询匹配与聚合**：传统文本查询仅使用一个文本嵌入计算余弦相似度图；IMPRINT则对N个检索图像分别编码，得到N个相似度图，然后通过**算术平均**（经验最优）聚合为最终相似度图。也可可选地将文本嵌入的相似度图一并聚合（称为Both模式）。
  - **两种运行阶段**：
    - **静态阶段**：首先让代理自主探索（目标无关的前沿探索）构建完整语义地图，然后离线评估物体定位性能（与导航解耦）。
    - **在线阶段**：在导航循环中同步构建地图和查询，评估端到端导航效果；IMPRINT仅替换语义定位模块，不改变导航策略和检测器。

## 6. 主要结论与发现

- **静态定位**：在所有编码器和数据集上，图像条件查询（image-only 或 both）一致优于纯文本查询，平均SR提升OVON-syn +10.54%，HSSD-rare +6.37%；HSSD-rare因更细粒度，绝对性能更低，体现了长尾挑战。
- **在线导航**：IMPRINT在OVON-syn上带来可靠提升（如VLFM: SR 23.83%→27.17%）；在HSSD-rare上增益较小（VLFM: 12.74%→13.91%），表明定位改善受到下游组件（特别是物体检测）的瓶颈限制。
- **失效分析**：超时占失败55.3%，仅4%进入目标2米范围，提示语义大规模缺失；误检测占29.8%。增强检测器（用检索图像条件化YOLOWorld）后，TwoMap in HSSD-rare SR从7.05%跃升至11.75%，验证了检测质量是关键瓶颈。
- **消融结论**：算术平均聚合最优；图像数量HSSD-rare需更多（15张）比OVON-syn（10张）效果更佳；文本与图像融合时图像贡献为主。

## 7. 优点

- **即插即用**：无需任何训练或修改导航策略，可集成到现有基于语义地图的导航框架（VLFM、OneMap）中，实用性强。
- **零样本泛化能力**：利用网络图像直接增强查询，对未见过的长尾子类别有效，无需预先收集特定训练数据。
- **新的基准贡献**：提出HSSD-rare，填补了细粒度长尾ObjectNav基准的空白，包含500+子类别和系统化的场景/视点生成流程。
- **系统性分析**：不仅展示性能提升，还深入剖析了从定位到导航的传播瓶颈，指出检测组件的重要性，为后续研究提供方向。
- **实验设计严谨**：静态与在线解耦评估，区分不同瓶颈；消融实验覆盖聚合策略、图像数量、检测增强等关键因素。

## 8. 不足与局限

- **依赖网络图像检索**：对长尾物体，若网络图像质量差或不存在相关图像（如罕见定制商品），检索结果可能引入噪声，导致性能下降。
- **计算开销**：尽管单次检索延迟低，但在线阶段需多次查询（每步或每阶段），可能增加系统延迟；缓存机制能否完全避免重复下载在部分场景下存疑。
- **检测器瓶颈未完全解决**：增强检测器后增益显著，但该方法本身仍依赖YOLOWorld的开放词汇检测能力，对于极端长尾可能仍有限。
- **真实环境验证不足**：仅5个episode的LoCoBot实验，且缺失统计显著性分析，真实世界泛化能力证据较弱。
- **实验覆盖的局限性**：未与基于强化学习的端到端方法（如Habitat-LLM）对比；只用了三种具体导航管线，未测试其他语义地图方法（如VLMaps、OpenFusion）。
- **HSSD-rare局限**：基于合成场景，可能不完全反映真实世界的光照、杂乱度、物体形态变化；室内/室外分区通过手动筛选，可能引入选择偏差。
