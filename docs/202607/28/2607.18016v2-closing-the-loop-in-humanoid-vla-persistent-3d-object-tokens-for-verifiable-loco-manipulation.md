## 摘要
视觉-语言-动作策略是通用机器人控制的一个有前景的基础，但长程仿人移动操控要求机器人将任务物体视为在移动、接触、遮挡和恢复中持久的物理实体。我们将此问题研究为物体状态分歧：用于调节全身动作的物体状态可能与用于判断动作是否达到预期物理关系的状态不同。我们提出了持久化物体标记化（POT），它从RGB-D观测中维护带角色索引的3D物体记录，并将其转换为全身动作专家使用的物体标记。实例化为POT-VLA，相同的物体记录同时调节动作生成并支持几何谓词检查，产生一个闭环执行系统，其中物体状态既是可操作的又是可验证的。在Unitree G1上，POT-VLA将匹配的直接GR00T-N1.7基线从39/80成功率提升至71/80成功率，覆盖八个真实世界任务族。在与外部Being-0对齐的参考中，POT-VLA在对齐的服务任务上取得了44/50的成功，而Being-0论文报告的成功率为37/50。最大的改进出现在需要维持3D关系的任务上，这表明以物体为中心的持久状态是可验证仿人VLA执行的一个有用抽象。

## Abstract
Vision-language-action policies are a promising foundation for general robot control, but long-horizon humanoid loco-manipulation requires the robot to treat task objects as persistent physical entities across movement, contact, occlusion, and recovery. We study this problem as object-state divergence: the object state used to condition a whole-body action can differ from the state used to decide whether the action achieved the intended physical relation. We propose \emph{Persistent Object Tokenization} (POT), which maintains role-indexed 3D object records from RGB-D observations and converts them into object tokens for a whole-body action expert. Instantiated as \emph{POT-VLA}, the same object records condition action generation and support geometric predicate checks, yielding a closed-loop execution system in which object state is both actionable and verifiable. On a Unitree G1, POT-VLA improves a matched direct GR00T-N1.7 baseline from 39/80 to 71/80 successes over eight real-world task families. In an external Being-0-aligned reference, POT-VLA achieves 44/50 successes on aligned service tasks, compared with the 37/50 success reported by the Being-0 paper. The largest gains occur on tasks requiring maintained 3D relations, suggesting that persistent object-centered state is a useful abstraction for verifiable humanoid VLA execution.

## 1. 核心问题与整体含义（研究动机和背景）
- **问题**：人形机器人执行长时程移动操控（loco-manipulation）时，任务物体需要在运动、接触、遮挡和恢复过程中被视为持久的物理实体。现有VLA策略通常基于当前观测隐式编码物体状态，而任务验证则可能依赖独立的状态检查，导致**物体状态发散**——用于生成动作的物体状态与用于验证动作是否达到预期物理关系的状态不一致。
- **关键挑战**：杯子、篮子、支撑面等任务物体必须能在机器人行走、抓取、放置、失败和恢复过程中持续可寻址。物体在度量3D空间中移动、接触手或支撑面、进入容器、部分遮挡，因此需要**以物体为中心的持久状态**，且该状态必须可由策略操作、可在动作块执行后验证。
- **研究意义**：解决物体状态发散的物理本质问题，提升人形机器人长时程任务的成功率与可靠性。

## 2. 方法论：核心思想、关键技术细节
- **核心思想**：提出**持久化物体标记化（Persistent Object Tokenization, POT）**，从RGB-D观测中维护带角色索引的3D物体记录，并将其序列化为**持久化3D物体标记**，供全身动作专家使用。同一物体记录同时用于条件化动作生成和几何谓词验证，形成**感知-动作-验证闭环**。
- **关键技术细节**：
  - **任务角色物体记录**：由VLM规划器或人工任务文件提供类型化子任务计划，每个子任务指定角色、接地查询、成功谓词等。基于当前RGB-D和本体感知，POT构建角色索引的物体记忆`M_t^{τ_i}`，每个记录存储实体角色、语义短语、2D框、3D质心与范围、置信度、可见性、空间关系特征。
  - **持久化标记模式**：默认分配K=8个槽，每个槽F=33个特征。有效槽携带角色ID（如TARGET、DESTINATION、SUPPORT、HANDOVER_PARTNER）。槽特征包括可见性、置信度、归一化2D框坐标、3D质心、3D范围、可选朝向、空间关系。持久性体现在：任务实体绑定到角色槽，每个动作块后刷新度量证据；若物体遮挡或低置信度，角色槽仍保留但标记为不确定。
  - **动作头插入**：将POT标记作为对象令牌插入DiT动作头的自注意力序列中，布局为`[state_tokens, object_tokens, action_tokens]`。对象令牌通过可学习投影层（LayerNorm→Linear→GELU→Dropout→Linear）嵌入到DiT隐藏维度，并与角色嵌入、上下文嵌入相结合。动作专家预测全身动作块`̂a_{t:t+H}`。
  - **训练**：使用与基础动作专家相同的动作块预测目标，无额外物体记忆或谓词损失。微调时，演示数据配合同样的RGB-D对象令牌侧车，梯度更新对象令牌分支和动作头参数。
  - **闭环执行与安全**：每执行一个短时域块后刷新感知，更新物体记忆，重新生成令牌。应用命令平滑、关节/速度限制、平衡检查、碰撞约束和紧急停止。
  - **谓词级验证与恢复**：几何谓词监督器读取角色索引物体记忆，检查子任务准备状态，验证执行后刷新记忆。每个谓词包含类型、参数、比较操作符、阈值、稳定窗口。返回状态包括`in_progress`、`done`、`blocked`、`failed`、`uncertain`，并输出诊断信息，触发继续、重试、重新观测、重新接地或重新规划等恢复策略。

## 7. 优点
- **方法创新**：提出**持久化3D物体令牌**作为动作生成与验证的共享状态表示，直接解决物体状态发散问题，而非依赖隐式特征或分离的验证模块。
- **闭环整合**：将感知、动作、验证复用同一物体记忆，无需显式物理引擎或动力学模型，实用性强。
- **兼容现有策略**：POT可插入现有VLA动作专家（如GR00T-N1.7）的动作头，不改变主体架构，便于推广。
- **实验设计**：真实人形机器人上多任务、多偏移的全面评估，消融和泛化实验分离组件贡献，对比基线公平。
- **可解释性**：角色索引物体记忆和几何谓词提供明确物理关系检查与失败诊断，支持结构化恢复。
