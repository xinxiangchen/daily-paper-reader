## 摘要
世界动作模型（WAM）通过联合建模视觉状态转换和机器人动作，为机器人操作提供了一种有前景的范式。然而，现有的WAM受限于有限的时间上下文、粗粒度的回合级语言监督以及以文本为主的调节方式，这阻碍了任务进度追踪和细粒度的语言-视频-动作对齐，同时限制了视觉上下文推理和跨实体迁移。在本文中，我们提出了WorldScape Policy 2.0，一种具有推理增强长短期记忆的可控WAM。其因果短期视觉记忆将最近的观察作为DiT预填充提供，以保留局部交互动态；而其长短期事件记忆将历史VLM输出组织为全局历史、局部活跃和事件边界表示，用于进度感知检索。检索到的历史增强了感知和自回归生成的规划标记，为自主规划提供了隐式子目标条件；语义强制进一步将事件级指令语义转移到这一潜在规划路径中。为了建立细粒度多模态可控性，我们构建了ManipEvent-5M，一个基于事件的具身预训练数据集，包含近500万个事件段，带有对齐的动作轨迹、回合级任务指令、段级子任务描述、目标图像和视频演示。这些设计提供了一个统一接口，用于从高层指令进行自主规划以及从细粒度文本、目标图像或视频上下文提示进行可控执行。在仿真和真实世界平台上的实验展示了在长时域自主规划、细粒度指令跟随和上下文适应方面的优越能力。

## Abstract
World Action Models (WAMs) offer a promising paradigm for robotic manipulation by jointly modeling visual state transitions and robot actions. However, existing WAMs are constrained by limited temporal context, coarse episode-level language supervision, and predominantly text-only conditioning, which hinder task-progress tracking and fine-grained language-video-action grounding while limiting visual-context reasoning and cross-embodiment transfer. In this paper, we introduce WorldScape Policy 2.0, a controllable WAM with reasoning-augmented long short-term memory. Its causal short-term visual memory supplies recent observations as DiT prefill to preserve local interaction dynamics, while its long short-term event memory organizes historical VLM outputs into global-history, local-active, and event-boundary representations for progress-aware retrieval. The retrieved history augments perception and autoregressively generated planning tokens, yielding an implicit subgoal condition for autonomous planning; semantic forcing further transfers event-level instruction semantics into this latent planning pathway. To establish fine-grained multimodal controllability, we construct ManipEvent-5M, an event-grounded embodied pretraining dataset containing nearly 5 million event segments with aligned action trajectories, episode-level task instructions, segment-level subtask captions, goal images, and video demonstrations. These designs provide a unified interface for autonomous planning from high-level instructions and controllable execution from fine-grained text, goal-image, or video-context prompts. Experiments in both simulation and real-world platforms demonstrate superior capabilities in long-horizon autonomous planning, fine-grained instruction following and in-context adaptation.

## 1. 论文的核心问题与整体含义

- **研究动机**：现有世界动作模型（World Action Models, WAMs）存在三个关键限制：
  - 时间上下文有限：大多只依赖当前观测或短时历史窗口，无法感知任务进度（如不同阶段视觉相似时难以决策）。
  - 语言监督粗糙：一个长回合通常只有一个任务级指令，缺乏对原子动作的细粒度语言-视频-动作对齐，导致模型对细粒度指令变化不敏感。
  - 交互模态单一：仅支持文本控制，无法利用目标图像、演示视频等更自然的表达方式，限制了视觉推理和跨实体迁移。
- **整体含义**：本文提出 WorldScape Policy 2.0，通过引入**推理增强的长短期记忆**和**事件级多模态数据集**，将WAM从短时预测模型升级为可长期可控的策略，能够同时支持从高层指令自主规划、细粒度文本/图像/视频条件执行以及上下文适应，为具身智能提供统一框架。

## 2. 方法论

### 核心思想
- 将时间上下文分为两个互补层次：
  - **事件级语义记忆**（通过VLM推理）：追踪任务进度，推断当前子目标。
  - **帧级视觉记忆**（通过DiT）：保留局部交互动态。
- 二者结合实现隐式子目标规划，配合**语义强制**将显式事件语义转移到隐式规划路径。

### 关键技术细节

1. **统一动作表示**：采用末端执行器相对第一帧的增量位姿（位置 + 连续6D旋转 + 1自由度夹爪指令），双机械臂共20维。每个实体有专用动作编码器/解码器，共享视频-动作DiT骨干。

2. **多模态提示编码**：
   - 细粒度语言：T5编码。
   - 高层指令：VLM分支推理产生隐式条件。
   - 目标图像/视频演示：VAE编码作为持久视觉prefix。

3. **推理增强长短期记忆**：
   - **短期视觉记忆**：保持最近4个观测块的VAE隐变量作为DiT的因果prefix。
   - **长短期事件记忆**：利用Qwen3-VL-4B作为VLM推理骨干，每个动作块产生感知token和规划token，构建三种记忆视图：
     - 全局历史记忆：压缩后的完整历史。
     - 局部活跃记忆：最近若干块的全token。
     - 事件边界记忆：通过相邻块语义变化检测（余弦距离+TopK）选取的高变化块。
   - **检索与门控融合**：将当前推理token作为query，对三种记忆视图和压缩全历史进行交叉注意力检索，再通过可学习门控决定注入量。

4. **隐式子目标规划**（语义强制）：
   - 训练时，将VLM推理得到记忆增强token与T5细粒度子目标嵌入进行余弦相似度对齐（stop-gradient固定T5目标），使推理路径学会预测子目标语义。
   - 推理时，仅使用高层指令，模型自主推断子目标并生成动作。

5. **ManipEvent-5M数据集**：包含近500万事件段，来源包括人臂自中心视频、无机器人UMI数据、仿真数据和真实机器人数据。每个事件段对齐有：
   - 动作轨迹（相对增量形式）
   - 回合级任务指令
   - 细粒度子任务描述（通过Qwen3-VL四阶段层次化标注：两阶段标注、层次帧采样、具身提示约束、多视图冲突解决）
   - 目标图像（第一视角和第三视角）
   - 跨实体演示视频

6. **三阶段训练策略**：
   - Stage1：事件级多模态WAM预训练（ManipEvent-5M，仅T5条件+视觉记忆，无VLM事件记忆）。
   - Stage2：记忆感知中间训练（引入VLM分支和事件记忆，使用语义强制对齐）。
   - Stage3：下游交互后训练（适配具体任务和实体，支持所有交互模式）。

7. **训练目标**：联合视频-动作流匹配损失 + 语义强制损失（λ_s=0.001）。

### 算法流程（文字说明）
1. 编码当前多视图观测（VAE隐变量），维护最近帧视觉buffer。
2. 根据交互模式：
   - 细粒度模式：T5编码子目标嵌入，直接作为DiT交叉注意力条件。
   - 自主规划模式：将当前头视图像+任务指令作为VLM前缀，生成感知token和K个自回归规划token（贪心解码），构成当前推理token `q_t`。
3. 从记忆队列检索：将`q_t`与三种记忆视图（全局历史、局部活跃、事件边界）及压缩全历史进行交叉注意力，经门控融合得到增强推理token `\hat{q}_t`。
4. 将增强token（或T5嵌入）作为条件，连同视觉prefix（目标图像/视频、历史帧）输入DiT，预测未来H步视频隐变量和相对动作增量。
5. 使用流匹配积分从噪声到干净动作，执行动作，更新观测和记忆。
